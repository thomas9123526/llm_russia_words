## Грамматика

### 1. Десятичные дроби: целая, десятая, сотая

**Как писать.** В русском языке целую часть отделяет **запятая**, а тысячи — **пробел** (띄어쓰기): 0,5 (не 0.5); 50 000; 1 300 000,25. В коде и в английских статьях вы видите точку. Но в русском тексте всегда пишите запятую.

**Как читать.** Десятичную дробь читаем как дробь (분수). Сначала целая часть + слово **це́лая** (ж. р., потому что «часть» — ж. р.). Потом дробная часть + **деся́тая / со́тая / ты́сячная**. Эти слова изменяются, как существительные после чисел:

| Число | «целая» | «десятая» и др. |
|---|---|---|
| 1, 21, 31… | одна́ це́лая | одна́ деся́тая |
| 2, 3, 4 | две / три / четы́ре це́лых | две деся́тых |
| 0, 5–20… | ноль / пять це́лых | пять деся́тых |

Не забудьте: одна́ и две (ж. р.).

| Пишем | Читаем |
|---|---|
| 0,5 | ноль це́лых пять деся́тых |
| 1,2 | одна́ це́лая две деся́тых |
| 2,35 | две це́лых три́дцать пять со́тых |
| 3,14 | три це́лых четы́рнадцать со́тых |
| 0,01 | ноль це́лых одна́ со́тая |
| 0,001 | ноль це́лых одна́ ты́сячная |
| 12,7 | двена́дцать це́лых семь деся́тых |

**Существительное после дроби всегда стоит в родительном падеже единственного числа**: 0,5 секу́нды, 2,5 проце́нта, 1,3 миллиа́рда, 87,5 проце́нта. Последняя цифра не важна.

**В разговоре** говорят короче: 0,5 — «ноль пять»; 2,5 — «два и пять». Программисты, когда читают код, говорят и так: «ноль то́чка ноль ноль оди́н» (0.001). На семинаре лучше полная форма. Для 1,5 есть особое слово: полтора́ (+ Р. п. ед. ч.): полтора́ часа́, полтора́ миллио́на.

**Степени десяти** (10의 거듭제곱) часто встречаются в машинном обучении: 10⁻⁴ — де́сять в ми́нус четвёртой сте́пени; 10⁹ — де́сять в девя́той сте́пени. Слово «сте́пень» — ж. р., поэтому порядковое числительное тоже ж. р., П. п. (в четвёртой).

### 2. Проценты и сравнение

**проце́нт** изменяется по обычному правилу (урок 3): 1, 21, 31 → проце́нт; 2–4, 22–24 → проце́нта; 5–20, 25–30 → проце́нтов; после дроби → проце́нта.

| | |
|---|---|
| 1 % | оди́н проце́нт |
| 3 % | три проце́нта |
| 12 % | двена́дцать проце́нтов |
| 21 % | два́дцать оди́н проце́нт |
| 44 % | со́рок четы́ре проце́нта |
| 0,5 % | ноль це́лых пять деся́тых проце́нта |

**Главные выражения для результатов:**
- **на** + В. п. — на сколько: Моде́ль на 3 % (три проце́нта) лу́чше. То́чность вы́росла на 5 % (пять проце́нтов).
- **с** + Р. п. … **до** + Р. п.: То́чность вы́росла с восьми́десяти до девяно́ста проце́нтов.
- **в … раз(а)**: в два ра́за быстре́е, в де́сять раз бо́льше. После 2–4 — ра́за, после 5 и больше — раз.
- **бо́лее / ме́нее** + Р. п. (письменный стиль): бо́лее ста языко́в.

Разница между двумя процентами — это **процентный пункт** (퍼센트포인트): То́чность вы́росла на 2 проце́нтных пу́нкта (п. п.). Так пишут аккуратные авторы в хороших статьях.

**Числительные в Р. п. и П. п.** После «с», «до», «бо́лее», «о» и «на» (место) числительные изменяются. Чаще всего нужны эти формы:

| И. п. | Р. п. | П. п. |
|---|---|---|
| два / три / четы́ре | двух / трёх / четырёх | двух / трёх / четырёх |
| пять, во́семь, де́сять | пяти́, восьми́, десяти́ | пяти́, восьми́, десяти́ |
| два́дцать, три́дцать | двадцати́, тридцати́ | двадцати́, тридцати́ |
| со́рок | сорока́ | сорока́ |
| во́семьдесят | восьми́десяти | восьми́десяти |
| девяно́сто | девяно́ста | девяно́ста |
| сто | ста | ста |

- на восьми́ видеока́ртах (GPU 8개에서)
- в двух экспериме́нтах (두 번의 실험에서)
- бо́лее ста языко́в (100개 이상의 언어)

### 3. Большие числа

| Пишем | Слово | Сокращение |
|---|---|---|
| 1 000 | ты́сяча | тыс. |
| 1 000 000 | миллио́н | млн |
| 1 000 000 000 | миллиа́рд | млрд |
| 1 000 000 000 000 | триллио́н | трлн |

Внимание: английское *billion* — это русское **миллиа́рд**. Слово «биллио́н» не используют. «7B-модель» — это моде́ль на 7 млрд пара́метров (читаем: на семь миллиа́рдов пара́метров) или просто: в моде́ли семь миллиа́рдов пара́метров. Слова миллио́н, миллиа́рд, триллио́н — м. р., ты́сяча — ж. р. Все они изменяются по правилу чисел: два миллиа́рда, пять миллиа́рдов; две ты́сячи, пять ты́сяч. Существительное после них — в Р. п. мн. ч.: семь миллиа́рдов **пара́метров**, два триллио́на **то́кенов**.

### 4. Как читать формулы

| Формула | Читаем |
|---|---|
| a + b | а плюс бэ |
| a − b | а ми́нус бэ |
| a · b | а умно́жить на бэ |
| a / b | а, делённое на бэ (*или:* а раздели́ть на бэ) |
| a = b | а равно́ бэ |
| a ≈ b | а приблизи́тельно равно́ бэ |
| a > b, a < b | а бо́льше бэ, а ме́ньше бэ |
| x², x³ | икс в квадра́те, икс в ку́бе |
| xⁿ | икс в сте́пени эн |
| √x | ко́рень из икс |
| f(x) | эф от икс |
| xᵢ | икс и́тое |
| Σ | су́мма |
| log x | логари́фм икс |

**Названия букв.** Латинские: a — а, b — бэ, c — цэ, d — дэ, e — е, f — эф, i — и, k — ка, L — эль, m — эм, n — эн, p — пэ, q — ку, s — эс, t — тэ, w — дубль-вэ, x — икс, y — и́грек, z — зет. Греческие: α — а́льфа, β — бе́та, ε — э́псилон, η — э́та, θ — тэ́та, λ — ля́мбда, μ — мю, σ — си́гма. Названия букв не склоняются: ко́рень из икс, бо́льше бэ.

**Числа после «равно́», «бо́льше», «ме́ньше».** В аккуратной речи после «равно́» число стоит в Д. п., после «бо́льше / ме́ньше» — в Р. п.: два плюс два равно́ четырём; икс бо́льше нуля́. С буквами проблемы нет: буквы не склоняются.

## Совет

Для корейцев здесь две ловушки (함정). Первая: в корейском языке пишут 0.5 с точкой, а в русском — с запятой. Поэтому в русском тексте 1,500 — это не «천오백», а 1.5! Тысяча пятьсот — это 1 500. Вторая: в корейском языке большие числа делят по четыре цифры (만, 억), а в русском — по три: 70억 = 7 миллиа́рдов, 1조 = 1 триллио́н, 5만 = 50 ты́сяч. Когда читаете статью о LLM, переводите через цифры, а не через слова.

## Повторение

- Вы пишете десятичные дроби с запятой и читаете их со словами це́лая / деся́тая / со́тая / ты́сячная.
- После дроби вы ставите существительное в Р. п. ед. ч.: 2,5 проце́нта, 0,5 секу́нды.
- Вы можете рассказать о результатах: на 3 % лу́чше, с восьми́десяти до девяно́ста проце́нтов, в два ра́за быстре́е.
- Вы знаете тыс., млн, млрд, трлн и помните: *billion* — это миллиа́рд.

# 제17과. 단어 형성: 접두사, 접미사, 국제어 (-ция, -ость, -ние)

> **중급 러시아어** · 수준: B1 · **배울 내용:** 러시아어 단어의 구성 요소(접두사, 어근, 접미사, 어미) · 명사 접미사 -ние, -ость, -ция, -тель과 그 성 · 머신러닝 용어를 만드는 접두사: пред-, до-, пере-, само-, много-, под-

## 대화

민호가 언어 모델에 관한 러시아어 논문을 읽고 있습니다. 긴 단어 몇 개를 안나에게 물어봅니다.

**Минхо:** Анна, в статье есть слово «переобуче́ние». Что оно значит?
*안나, 논문에 "переобучение"라는 단어가 있어. 무슨 뜻이야?*

**Анна:** Это когда модель слишком хорошо запомина́ет обучающие данные и плохо работает на новых данных.
*모델이 학습 데이터를 너무 잘 외워서 새 데이터에서는 잘 작동하지 않는 경우야.*

**Минхо:** А, по-английски это overfitting! А «дообуче́ние»?
*아, 영어로 overfitting이구나! 그럼 "дообучение"는?*

**Анна:** Это fine-tuning. Приста́вка «до-» значит «ещё немного, до конца».
*그건 fine-tuning이야. 접두사 "до-"는 "조금 더, 끝까지"라는 뜻이야.*

**Минхо:** А «предобуче́ние» — это pre-training, да? «Пред-» значит «перед».
*그럼 "предобучение"는 pre-training이지? "пред-"는 "~전에"라는 뜻이고.*

**Анна:** Правильно. Ты уже сам понимаешь, как образу́ются слова.
*맞아. 이제 단어가 어떻게 만들어지는지 스스로 이해하네.*

**Минхо:** Ещё одно слово: «самовнима́ние».
*하나 더: "самовнимание".*

**Анна:** «Само-» — это self, а «внима́ние» — attention. Получается self-attention.
*"само-"는 self, "внимание"는 attention. 그래서 self-attention이 돼.*

**Минхо:** Как просто! Русские слова — как конструктор Лего.
*정말 간단하다! 러시아어 단어는 레고 블록 같아.*

**Анна:** Да, но не все слова такие простые. Например, «разме́тка» — это не «размер»!
*응, 하지만 모든 단어가 그렇게 간단하지는 않아. 예를 들어 "разметка"는 "размер"(크기)가 아니야!*

**Минхо:** А что тогда значит «разметка»?
*그럼 "разметка"는 무슨 뜻이야?*

**Анна:** Разметка данных — это data labeling. Ко́рень здесь «мет-», как в слове «заметка».
*"разметка данных"는 데이터 라벨링이야. 여기서 어근은 "заметка"(메모)에 있는 "мет-"야.*

## 문법

### 1. 단어의 구성 요소

러시아어 단어는 보통 네 종류의 요소로 이루어집니다.

| приставка (접두사) | корень (어근) | суффикс (접미사) | окончание (어미) |
|---|---|---|---|
| пере- | -обуч- | -ени- | -е |
| пред- | -сказ- | -ани- | -е |
| раз- | -мет- | -к- | -а |
| — | -точ- | -ност- | -ь |

**어근**이 기본 의미를 담습니다. 어근 하나에서 단어 가족 전체가 나옵니다: уч- → учи́ть, учёный, уче́бник, обуче́ние, учи́тель. 논문에서 모르는 긴 단어를 만나면 아는 어근을 찾고, 접두사와 접미사를 읽어 보세요. 사전 없이도 뜻을 짐작할 수 있는 경우가 많습니다. 특히 머신러닝 용어는 아주 규칙적입니다.

한자어를 떠올리면 쉽습니다: 학(學) → 학습, 학생, 학자, 과학. 러시아어 어근 уч-도 한자 "學"처럼 여러 단어에 들어갑니다.

### 2. 명사 접미사와 성

접미사를 보면 성과 의미의 종류를 알 수 있습니다. 정확한 뜻을 알기 전에도 새 단어를 올바르게 격변화할 수 있으니 매우 유용합니다.

| 접미사 | 성 | 의미 | 예 |
|---|---|---|---|
| -ние (-ение, -ание) | ср. | 동사의 과정이나 결과 | обуче́ние, реше́ние, предсказа́ние, распознава́ние |
| -ость | ж. | 형용사에서 온 추상적 성질 | то́чность, сло́жность, вероя́тность |
| -ция (-ия) | ж. | 국제어 (*-tion*) | фу́нкция, генера́ция, оптимиза́ция |
| -тель | м. | 사람 (때로는 장치) | исследова́тель, по́льзователь, руководи́тель |
| -ка | ж. | 사물이나 결과 | разме́тка, заме́тка, вы́борка |

**가) -ние: 동사에서.** 거의 모든 동사가 -ние 명사를 만들 수 있습니다. 과학에서 과정을 이름 짓는 기본 방법입니다. 한국어의 "-하다 → -(하기), 학습하다 → 학습"과 비슷합니다.

| 동사 | 명사 | 한국어 |
|---|---|---|
| обуча́ть | обуче́ние | 학습, 교육 |
| реша́ть | реше́ние | 해결, 해, 결정 |
| изуча́ть | изуче́ние | 연구, 학습 |
| испо́льзовать | испо́льзование | 사용 |
| сравни́ть | сравне́ние | 비교 |
| описа́ть | описа́ние | 기술, 설명 |
| предсказа́ть | предсказа́ние | 예측 |
| распознава́ть | распознава́ние | 인식 |
| представля́ть | представле́ние | 표현 (representation) |
| вложи́ть | вложе́ние | 임베딩 |
| иссле́довать | иссле́дование | 연구 |

많은 머신러닝 용어가 "동사 + -ние"입니다: распознава́ние ре́чи(음성 인식), обуче́ние с подкрепле́нием(강화 학습), маши́нное обуче́ние(머신러닝).

**나) -ость: 형용사에서.** 형용사 어간에 -ость를 붙입니다: то́чный → то́чность(정확도), сло́жный → сло́жность(복잡도), вероя́тный → вероя́тность(확률), эффекти́вный → эффекти́вность(효율성), усто́йчивый → усто́йчивость(견고성), безопа́сный → безопа́сность(안전). 한국어의 "-성(性)"과 비슷합니다.

**다) -ция: 국제어.** 영어 *-tion*은 보통 러시아어 **-ция**, *-sion*은 **-сия**가 됩니다. 강세는 -ция 바로 앞 음절에 옵니다.

classification → классифика́ция · optimization → оптимиза́ция · tokenization → токениза́ция · normalization → нормализа́ция · generation → генера́ция · function → фу́нкция · regression → регре́ссия · version → ве́рсия

이에 대응하는 동사는 **-ировать**(때로 -изировать, -овать)로 끝납니다: оптимиза́ция → оптимизи́ровать, генера́ция → генери́ровать, токениза́ция → токенизи́ровать, классифика́ция → классифици́ровать, 그러나 нормализа́ция → нормализова́ть. -ировать 동사는 보통 불완료상과 완료상을 겸하거나, с-나 про-로 완료상을 만듭니다: сгенери́ровать, протести́ровать.

**라) -тель과 다른 "행위자".** -тель은 사람을 나타냅니다: иссле́довать → исследова́тель, по́льзоваться → по́льзователь, руководи́ть → руководи́тель, преподава́ть → преподава́тель. 국제어 행위자는 외래 접미사를 유지하는 경우가 많습니다: оптимиза́тор(옵티마이저), токениза́тор(토크나이저), трансфо́рмер, программи́ст, лингви́ст.

### 3. 형용사 접미사

| 접미사 | 영어 대응 | 예 |
|---|---|---|
| -ивный | -ive | эффекти́вный, генерати́вный, интеракти́вный |
| -альный | -al | норма́льный, оптима́льный, глоба́льный |
| -ический | -ic, -ical | лингвисти́ческий, статисти́ческий, математи́ческий |
| -ный | (다양) | то́чный, нейро́нный, языково́й (강세가 있으면 -ой) |
| -ционный | -tional | оптимизацио́нный, классификацио́нный |

그래서 *generative model*은 генерати́вная моде́ль, *statistical method*는 статисти́ческий ме́тод, *optimal solution*은 оптима́льное реше́ние입니다.

### 4. 과학 용어의 접두사

| 접두사 | 의미 | 예 |
|---|---|---|
| пред- | ~전에, 사전 | предобуче́ние, предсказа́ние, предыду́щий(이전의) |
| до- | 끝까지, 추가로 | дообуче́ние, дописа́ть(다 쓰다), дополни́тельный(추가의) |
| пере- | 다시; 지나치게; 건너 | переобуче́ние, переписа́ть(다시 쓰다), перево́д(번역) |
| не- | 아닌, 불(不)- | нето́чный, непра́вильный, неизве́стный |
| без- / бес- | ~없는, 무(無)- | безопа́сность, бесконе́чный(무한한), беспла́тный |
| само- | 자기(自己)- | самовнима́ние, самообуче́ние |
| много- | 다(多)- | многосло́йный(다층의), многоязы́чный, многозада́чный |
| между- | 국제·상호 | междунаро́дный(국제의) |
| под- | 하위(下位)- | подзада́ча(하위 작업), подсло́во(서브워드), подразде́л(하위 절) |
| раз- / рас- | 나누어, 분해 | раздели́ть, распознава́ние, разме́тка |
| в- / вы- | 안으로 / 밖으로 | ввод(입력), вы́вод(출력; 결론) |

переобуче́ние은 *과적합*과 *재학습* 두 가지 뜻이 있으니 문맥으로 판단하세요. 머신러닝 논문에서는 거의 항상 과적합입니다.

## 문화

**거짓 친구(ложные друзья).** 일부 국제어는 러시아어에서 뜻이 다릅니다. 러시아 대학에서 자주 듣는 단어들입니다.

- аудито́рия — 강의실 (*청중*이라는 뜻도 있지만 대학에서는 주로 강의실)
- фами́лия — 성(姓) (*family*가 아님: 가족은 семья́)
- ко́нкурс — 경쟁, 공모전 (*concourse*가 아님)
- дипло́м — 졸업장 **그리고** 졸업 논문: писа́ть дипло́м
- акаде́мик — 과학 아카데미 정회원 (아무 *학자*나 가리키지 않음)
- магази́н — 가게 (*magazine*이 아님: 잡지는 журна́л)
- аспира́нт — 박사 과정생, 바로 여러분입니다!

## 복습

- 단어를 접두사, 어근, 접미사, 어미로 나누고, 아는 어근으로 새 단어의 뜻을 짐작할 수 있습니다.
- -ние(ср.), -ость(ж.), -ция(ж.), -тель(м.)의 성을 압니다.
- 동사를 명사로(обуча́ть → обуче́ние), 형용사를 명사로(то́чный → то́чность) 바꿀 수 있습니다.
- 국제어의 러시아어 형태를 만들 수 있습니다: -tion → -ция, -ive → -ивный, -ic → -ический, 그리고 -ировать 동사.
- 접두사로 만든 머신러닝 용어를 이해합니다: предобуче́ние, дообуче́ние, переобуче́ние, самовнима́ние, подсло́во.
- 몇 가지 거짓 친구를 압니다: аудито́рия, фами́лия, ко́нкурс, дипло́м.

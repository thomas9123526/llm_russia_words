## 개가 사람을 물다, 사람이 개를 물다

"The dog bit the man"(개가 사람을 물었다)과 "the man bit the dog"(사람이 개를 물었다)은 정확히 같은 토큰으로 이루어져 있습니다. 신문에는 둘 중 하나만 실릴 것입니다. 사람에게는 차이가 분명하지만, 제16장 끝에서 보았듯이 셀프 어텐션에게는 보이지 않습니다.

이를 정확히 말해 봅시다. 셀프 어텐션에서 토큰 $i$의 출력은 $\sum_j \alpha_{ij} v_j$이며, 가중치 $\alpha_{ij}$는 내적 $q_i \cdot k_j$에만 의존합니다. 이 식 어디에도 토큰 $j$가 *어디에* 있는지는 나오지 않습니다. "dog"과 "man"을 바꾸어도 "bit"에 대해 계산된 벡터는 완전히 같습니다. 같은 키와 값 집합에 대한 가중합이기 때문입니다. 다시 말해, 토큰의 표현은 다른 토큰들의 순서에 의존하지 않습니다. 이 성질을 **순열 불변성(permutation invariance)**이라고 합니다. RNN(제11장)에는 이런 문제가 없었습니다. 토큰을 하나씩 읽었으므로 순서가 계산 안에 내장되어 있었습니다. 트랜스포머는 병렬성을 얻기 위해 순차적 읽기를 포기했으므로, 이제 다른 방법으로 순서를 되찾아야 합니다.

해결책은 **위치 정보(positional information)**를 주입하는 것입니다. 크게 두 계열이 있습니다. *절대* 방법은 각 위치 $0, 1, 2, \dots$에 고유한 벡터를 주고 이를 토큰 임베딩에 더합니다. *상대* 방법은 어텐션 계산 자체를 바꾸어 두 토큰 사이의 점수가 둘 사이의 거리에 의존하도록 합니다. 여기서는 절대 방법 두 가지(사인파, 학습형)와 상대 방법 두 가지(RoPE, ALiBi)를 살펴봅니다.

## 절대 위치: 사인파 인코딩

원래의 트랜스포머는 고정된 **사인파 위치 인코딩(sinusoidal positional encoding)**을 사용했습니다. 위치 $pos$와 차원 인덱스 $i$에 대해 폭이 $d$(모델 차원)인 벡터 $PE_{pos}$를 다음과 같이 정의합니다.

$$
PE_{pos,\,2i} = \sin\!\left(\frac{pos}{10000^{2i/d}}\right), \qquad
PE_{pos,\,2i+1} = \cos\!\left(\frac{pos}{10000^{2i/d}}\right)
$$

여기서 $i$는 $0$부터 $d/2 - 1$까지이므로, 각 차원 쌍 $(2i, 2i+1)$은 같은 **주파수(frequency)** $\omega_i = 1/10000^{2i/d}$의 사인과 코사인입니다. 벡터 $PE_{pos}$는 첫 번째 층에 들어가기 전에 위치 $pos$에 있는 토큰의 임베딩에 그냥 더해집니다.

직관적으로는 바늘이 여러 개 달린 시계와 같습니다. 첫 번째 차원 쌍은 빠르게 돕니다. 위치 하나마다 각도가 1라디안씩 커지므로 약 6토큰마다 한 바퀴를 돕니다. 마지막 쌍은 매우 느리게 돕니다. 그 **파장(wavelength)**은 약 $2\pi \cdot 10000$ 위치입니다. 바늘들이 함께 모든 위치에 고유한 "시각"을 부여합니다. 가까운 위치들은 느린 차원에서 비슷한 벡터를 가지며 빠른 차원에서 달라집니다. 3시 15분과 3시 16분이 분침만 다른 것과 같습니다.

저자들이 사인과 코사인을 고른 데는 또 다른 이유가 있습니다. 고정된 오프셋 $k$에 대해 쌍 $(\sin \omega(pos+k), \cos \omega(pos+k))$는 $(\sin \omega\, pos, \cos \omega\, pos)$를 각도 $\omega k$만큼 회전하면 얻어집니다. 즉 "$k$ 위치 뒤"는 $pos$에 의존하지 않는 선형 변환이며, 모델은 원칙적으로 이를 활용하는 법을 배울 수 있습니다. 이 회전을 기억해 두십시오. RoPE에서 다시 등장합니다.

## 절대 위치: 학습형 임베딩

가장 간단한 대안은 모델이 위치 벡터를 학습하게 하는 것입니다. 제5장의 토큰 임베딩 행렬과 똑같이 위치마다 한 행을 가지는 행렬을 만들고 나머지 네트워크와 함께 학습합니다. PyTorch에서는 `nn.Embedding(max_len, d)` 한 줄입니다. BERT와 GPT-2는 **학습형 위치 임베딩(learned positional embeddings)**을 사용하며, 원래의 트랜스포머 논문에서도 사인파 인코딩과 비슷한 성능을 보였습니다.

학습형 위치는 유연하지만 분명한 한계가 있습니다. 표에는 정확히 `max_len`개의 행이 있습니다. 위치 `max_len + 1`에는 벡터가 아예 없으므로 더 긴 텍스트에는 모델을 쓸 수 없고, 표 끝부분의 위치는 학습 중에 덜 자주 등장합니다. 사인파 공식은 어떤 위치에서도 계산할 수 있지만, 실제로는 이 방식으로 학습한 모델도 학습 때보다 훨씬 긴 시퀀스에서는 성능이 떨어집니다. 학습 때보다 긴 시퀀스에서 동작하는 능력을 **길이 외삽(length extrapolation)**이라고 하며, 이것이 상대 방법이 등장한 주요 이유 중 하나입니다.

개념적인 논거도 있습니다. "the dog bit the man"에서 "bit"에게 중요한 것은 "dog"이 *한 토큰 왼쪽*에 있다는 사실이지, "dog"이 위치 1에 있다는 사실이 아닙니다. 같은 문장이 문서의 위치 1001에 나와도 의미는 변하지 않습니다. **상대 위치(relative position)**가 바로 이것을 기술합니다.

## RoPE: 쿼리와 키를 회전하기

**회전 위치 임베딩(rotary position embedding, RoPE)**은 Su 등이 RoFormer 논문에서 제안했으며, 오늘날 LLaMA(제25장) 같은 공개 디코더 모델에서 가장 흔히 쓰입니다. 아이디어는 우아합니다. 입력에 위치 벡터를 *더하는* 대신, 각 쿼리와 키를 위치에 비례하는 각도만큼 *회전*합니다.

먼저 위치 $m$에 있는 2차원 쿼리 $q$와 위치 $n$에 있는 키 $k$를 생각해 봅시다. $R(\phi)$를 각도 $\phi$만큼 회전하는 $2 \times 2$ **회전 행렬(rotation matrix)**이라고 합시다. RoPE는 $q$를 $R(m\theta)\,q$로, $k$를 $R(n\theta)\,k$로 바꿉니다. 여기서 $\theta$는 고정된 주파수입니다. 어텐션 점수는 다음과 같이 됩니다.

$$
\big(R(m\theta)\,q\big)^\top \big(R(n\theta)\,k\big) = q^\top R\big((n-m)\theta\big)\, k .
$$

이것은 회전의 두 가지 성질에서 나옵니다. $R(\phi)^\top = R(-\phi)$이고, 회전은 더해집니다. 즉 $R(-m\theta)R(n\theta) = R((n-m)\theta)$입니다. 결과는 오직 차이 $n - m$을 통해서만 위치에 의존합니다. 절대 위치는 사라지고 상대 거리만 남습니다.

작은 수치 예를 봅시다. $q = k = (1, 0)$, $\theta = 30°$라고 합시다. 위치 $m = 1, n = 0$에서는 쿼리가 $30°$, 키가 $0°$ 회전하며, 내적은 $\cos 30° = 0.866$입니다. 위치 $m = 5, n = 4$에서는 각각 $150°$와 $120°$ 회전하는데, 둘 사이의 각도는 역시 $30°$이므로 내적도 다시 $0.866$입니다.

폭이 $d$인 실제 쿼리의 경우, RoPE는 이를 $d/2$개의 쌍으로 나누고 쌍 $i$를 각도 $m\theta_i$만큼 회전합니다. 주파수는 사인파 인코딩과 같은 $\theta_i = 1/10000^{2i/d}$입니다. 빠른 쌍은 짧은 거리에, 느린 쌍은 긴 거리에 반응합니다. 값 $v$는 회전하지 않으며, 임베딩에는 아무것도 더하지 않습니다. 아래 코드는 사인파 인코딩과 RoPE를 모두 구현하고 상대성 성질을 확인합니다.

```python
import torch

def sinusoidal(T, d):
    pos = torch.arange(T).unsqueeze(1)              # 위치 0..T-1, 모양 (T, 1)
    i = torch.arange(0, d, 2)                       # 짝수 차원 0, 2, 4, ...
    freq = 1.0 / (10000 ** (i / d))                 # 차원 쌍마다 주파수 하나
    pe = torch.zeros(T, d)
    pe[:, 0::2] = torch.sin(pos * freq)
    pe[:, 1::2] = torch.cos(pos * freq)
    return pe

def rope(x, pos):
    # 각 쌍 (x0, x1), (x2, x3), ...을 각도 pos * theta_i만큼 회전
    d = x.size(-1)
    theta = 1.0 / (10000 ** (torch.arange(0, d, 2) / d))
    cos, sin = torch.cos(pos * theta), torch.sin(pos * theta)
    x1, x2 = x[..., 0::2], x[..., 1::2]
    out = torch.empty_like(x)
    out[..., 0::2] = x1 * cos - x2 * sin
    out[..., 1::2] = x1 * sin + x2 * cos
    return out

print(sinusoidal(4, 6).round(decimals=3))
torch.manual_seed(0)
q, k = torch.randn(8), torch.randn(8)
# 점수는 m과 n 자체가 아니라 거리 m - n = 3에만 의존
for m, n in [(5, 2), (10, 7), (103, 100)]:
    print(m, n, round(torch.dot(rope(q, m), rope(k, n)).item(), 3))
```

출력된 $4 \times 6$ 표에서 0행은 `[0, 1, 0, 1, 0, 1]`(0의 사인과 0의 코사인)입니다. 1행은 `0.841, 0.540`, 즉 $\sin 1$과 $\cos 1$로 시작하지만, 마지막 쌍은 거의 변하지 않았습니다(`0.002, 1.0`). 느린 바늘은 거의 움직이지 않은 것입니다. 세 개의 RoPE 점수는 모두 같습니다(이 시드에서는 `1.178`). 절대 위치는 스무 배나 차이 나는데도 말입니다.

## ALiBi: 거리에 대한 벌점

**ALiBi**(Attention with Linear Biases, 선형 편향 어텐션; Press 등, "Train Short, Test Long")는 더 간단합니다. 위치 벡터를 전혀 사용하지 않습니다. 대신 각 어텐션 점수에 토큰 사이의 거리에 비례하는 고정된 벌점을 더합니다.

$$
\text{score}_{ij} = \frac{q_i \cdot k_j}{\sqrt{d_k}} - s \cdot (i - j), \qquad j \le i
$$

여기서 $i$는 쿼리의 위치, $j \le i$는 키의 위치이고(ALiBi는 인과 모델을 위해 설계되었습니다), $s > 0$은 헤드마다 다른 **기울기(slope)**입니다. 헤드가 8개이면 기울기는 등비수열 $\tfrac12, \tfrac14, \dots, \tfrac{1}{256}$을 이룹니다. 기울기가 큰 헤드는 가까운 토큰을 강하게 선호하여 국소적으로 동작하고, 기울기가 작은 헤드는 여전히 먼 과거를 볼 수 있습니다. 기울기는 학습되지 않습니다.

이 편향(bias)은 가까운 토큰이 보통 더 중요하다는 단순한 사전 가정을 표현합니다. 벌점은 어떤 거리에서도 정의되므로, 짧은 시퀀스로 학습한 모델을 긴 시퀀스에서 실행할 수 있습니다. 저자들은 ALiBi가 사인파 인코딩보다 긴 입력으로 훨씬 잘 외삽된다는 것을 보였습니다. RoPE는 그 자체로는 외삽이 잘 되지 않으므로, RoPE를 쓰는 모델은 흔히 **위치 보간(position interpolation)** 및 관련 기법으로 확장됩니다. 이 기법들은 긴 시퀀스를 학습 중에 본 회전 각도 범위 안으로 "압축"합니다(긴 문맥은 제25장에서 다시 다룹니다).

## 방법 고르기

전체 그림을 정리해 봅시다. 사인파 인코딩과 학습형 인코딩은 *절대* 방법이며 입력에서 한 번 더해집니다. RoPE와 ALiBi는 *상대* 방법이며 모든 어텐션 층 안에서 쿼리와 키, 또는 점수에 작용합니다. 대부분의 현대 디코더 전용 LLM은 RoPE를 사용하고, 일부는 ALiBi를 사용합니다. BERT 계열 인코더는 학습형 절대 위치를 유지하는 경우가 많습니다. 어느 선택도 전체 아키텍처를 바꾸지는 않습니다. 입력은 여전히 벡터의 시퀀스이며, 다음 장에서는 어텐션과 다른 부품들을 조립하여 완전한 트랜스포머 블록을 만듭니다.

## 요약

- 위치 정보가 없으면 셀프 어텐션은 문장을 순서 없는 토큰 집합으로 취급합니다.
- 사인파 인코딩은 여러 주파수의 고정된 사인·코사인 벡터를 임베딩에 더합니다. $k$ 위치만큼의 이동은 회전입니다.
- 학습형 위치 임베딩은 학습 가능한 벡터 표입니다. 간단하지만 학습 때 본 최대 길이로 제한됩니다.
- RoPE는 쿼리와 키를 위치에 따른 각도만큼 회전하므로, 어텐션 점수는 상대 거리에만 의존합니다.
- ALiBi는 점수에서 헤드마다 다른 선형 거리 벌점을 빼며, 더 긴 시퀀스로 잘 외삽됩니다.

## 연습 문제

1. 위치 정보가 없는 셀프 어텐션이 "the dog bit the man"과 "the man bit the dog"에서 "bit"에 대해 같은 벡터를 주는 이유를 자신의 말로 설명해 보십시오.
2. $d = 512$일 때 사인파 인코딩의 첫 번째 쌍($i = 0$)과 마지막 쌍($i = 255$)의 주파수 $\omega_i$와 파장 $2\pi/\omega_i$를 계산해 보십시오.
3. $q = k = (1, 0)$, $\theta = 45°$일 때 $(m, n) = (2, 0)$과 $(m, n) = (7, 5)$에 대한 RoPE 점수를 계산해 보십시오. 그다음 $(m, n) = (4, 0)$에 대해서도 계산해 보십시오.
4. $T = 5$, 기울기가 $\tfrac14, \tfrac1{16}, \tfrac1{64}, \tfrac1{256}$인 헤드 4개에 대해 모양이 (헤드, $T$, $T$)인 ALiBi 편향 행렬을 만드는 함수를 작성하고, 대각선 위에는 $-\infty$를 넣어 보십시오.

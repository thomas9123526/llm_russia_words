## 한 문장으로 하는 두 가지 게임

제20장에서 작은 트랜스포머를 만들었지만, 중요한 질문 하나를 남겨 두었습니다. *그 모델은 무엇을 배워야 할까요?* 책, 기사, 웹 페이지 같은 방대한 텍스트가 있고 레이블은 전혀 없다고 해 봅시다. 어떤 문장이 긍정이고 부정인지, 어떤 단어가 이름인지, 질문의 답이 무엇인지 아무도 표시해 두지 않았습니다. 그래도 신경망이 여기서 쓸모 있는 무언가를 배울 수 있을까요?

*"the cat sat on the mat"*(고양이가 매트 위에 앉았다)라는 문장으로 두 가지 게임을 해 봅시다.

- **게임 1 — 다음 단어 맞히기.** *"the cat sat on the"*를 보여 주면 여러분은 *"mat"*을 맞힙니다. 그다음 *"the cat sat on"*을 보여 주면 *"the"*를 맞히는 식입니다.
- **게임 2 — 빈칸 채우기.** *"the cat [?] on the mat"*을 보여 주면 *"sat"*을 맞힙니다.

두 게임 모두 정답은 이미 텍스트 안에 있습니다. 우리는 그 일부를 숨겼을 뿐입니다. 이 간단한 기법을 **자기 지도 학습**(self-supervised learning)이라고 합니다. 학습용 레이블이 데이터 자체로부터 자동으로 만들어집니다. 사람의 주석이 필요 없으므로 수십억 개의 문장으로 학습할 수 있습니다. 이 단계를 **사전 학습**(pre-training)이라고 하고, 우리가 고른 게임을 **사전 학습 목표**(pre-training objective)라고 합니다. 사전 학습이 끝나면 모델은 보통 특정한 **다운스트림 과제**(downstream task)에 맞게 조정되는데, 이는 제31장에서 다룹니다.

게임 1은 **인과적 언어 모델링**(causal language modeling, CLM)으로, GPT와 대부분의 현대 LLM이 사용합니다. 게임 2는 BERT와 함께 소개된 **마스크 언어 모델링**(masked language modeling, MLM)입니다. 이 장에서는 두 가지와 거기서 파생된 변형들을 설명합니다.

## 인과적 언어 모델링: 다음 토큰 예측하기

인과적 언어 모델링은 제1장의 언어 모델을 그대로 트랜스포머로 구현한 것입니다. 모델은 토큰을 왼쪽에서 오른쪽으로 읽으며, 각 위치에서 다음 토큰에 대한 확률 분포를 예측합니다. *인과적*이라는 말은 위치 $t$의 예측이 과거에만 의존할 수 있고 미래에는 절대 의존하지 않는다는 뜻입니다. 원인이 결과보다 먼저 오는 것과 같습니다.

제6장의 확률의 연쇄 법칙을 떠올려 봅시다. 시퀀스 $x = (x_1, \dots, x_T)$의 확률은 조건부 확률의 곱으로 쓸 수 있습니다.

$$P(x_1, \dots, x_T) = \prod_{t=1}^{T} P(x_t \mid x_{<t})$$

여기서 $x_t$는 위치 $t$의 토큰이고, $x_{<t}$는 그 앞의 모든 토큰을 뜻합니다. 파라미터가 $\theta$인 모델은 $P_\theta(x_t \mid x_{<t})$를 제공하며, 학습은 음의 로그 가능도를 최소화합니다.

$$\mathcal{L}_{\text{CLM}}(\theta) = -\sum_{t=1}^{T} \log P_\theta(x_t \mid x_{<t})$$

이것은 제8장의 **교차 엔트로피**(cross-entropy) 손실을 위치별로 더한 것일 뿐입니다. 토큰당 평균을 내고 지수를 취하면 제4장에서 본 퍼플렉서티가 됩니다.

$T$개의 예측을 어떻게 효율적으로 계산할까요? 시퀀스 전체를 한 번에 트랜스포머에 넣고, 제16장의 **인과적 마스크**(causal mask)를 사용하여 위치 $t$가 위치 $1, \dots, t$에만 어텐션할 수 있게 합니다. 입력은 마지막 토큰을 뺀 시퀀스이고, 타깃은 같은 시퀀스를 왼쪽으로 한 칸 민 것입니다.

| 위치 | 1 | 2 | 3 | 4 | 5 |
|---|---|---|---|---|---|
| 입력 | the | cat | sat | on | the |
| 타깃 | cat | sat | on | the | mat |

한 번의 순전파로 다섯 개의 예측과 다섯 개의 손실 항을 얻습니다. 이것은 중요한 실용적 장점입니다. **말뭉치의 모든 토큰이 학습 신호를 제공합니다.** 버려지는 것이 없습니다.

두 번째 장점은 학습 과제가 모델의 사용 방식과 같다는 점입니다. 텍스트를 생성할 때 우리는 토큰을 하나 예측하고, 그것을 입력 뒤에 붙인 뒤, 다시 예측합니다(제24장). CLM으로 학습한 모델은 바로 이 게임을 연습한 셈입니다. 단점은 각 표현이 왼쪽 문맥만 본다는 것입니다. 모델이 *"the bank of the river"*(강둑)에서 *"bank"*를 처리할 때, *"bank"* 위치의 은닉 상태는 아직 *"river"*를 볼 수 없습니다.

## 마스크 언어 모델링: 빈칸 채우기

마스크 언어 모델링은 이 제약을 없앱니다. 일부 토큰을 숨겨 입력을 손상시킨 뒤, 모델에게 그것을 복원하게 합니다. 모델 입장에서 숨겨진 것은 마스크된 토큰뿐이므로, 인코더는 왼쪽과 오른쪽 단어를 모두 활용하는 **양방향 문맥**(bidirectional context)을 쓸 수 있습니다. 인과적 마스크가 없으며, 모든 토큰이 다른 모든 토큰에 어텐션합니다(제19장에서는 이것을 인코더 아키텍처라고 불렀습니다).

BERT(Devlin et al., 2019)에서는 토큰 위치의 15%를 예측 대상으로 고릅니다. 그리고 선택된 각 위치에 간단한 규칙을 적용합니다.

- 80%의 경우 토큰을 특수한 **마스크 토큰**(mask token) `[MASK]`로 바꿉니다.
- 10%의 경우 무작위 토큰으로 바꿉니다.
- 10%의 경우 그대로 둡니다.

왜 항상 `[MASK]`를 쓰지 않을까요? 나중에 모델을 실제 문장으로 미세 조정(fine-tuning)할 때는 `[MASK]`가 전혀 나타나지 않기 때문입니다. 모델이 `[MASK]` 위치에서만 예측해야 한다면, 그 위치에서만 좋은 표현을 만들도록 학습할 수도 있습니다. 무작위 토큰과 변경 없음의 경우가 있으면, 어떤 토큰이든 확인 대상일 수 있으므로 모델은 *모든* 토큰에 대해 유용한 표현을 유지해야 합니다.

$M$을 선택된 위치의 집합, $\tilde{x}$를 손상된 시퀀스라고 합시다. 손실은 다음과 같습니다.

$$\mathcal{L}_{\text{MLM}}(\theta) = -\sum_{i \in M} \log P_\theta(x_i \mid \tilde{x})$$

CLM과의 두 가지 차이점에 주목하십시오. 첫째, 조건이 과거만이 아니라 손상된 시퀀스 전체 $\tilde{x}$입니다. 둘째, 합이 $M$에 대해서만 계산됩니다. 15% 비율이라면 100개 토큰의 문장에서 손실 항은 약 15개뿐이지만, CLM이라면 약 100개를 얻습니다. 따라서 MLM은 데이터를 한 번 훑을 때 얻는 신호가 더 적습니다.

이론적인 미묘함도 있습니다. 마스크된 토큰들은 서로 독립적으로 예측됩니다. *"New"*와 *"York"*가 모두 마스크되면, 모델은 다른 하나를 모른 채 각각을 예측합니다. 그래서 MLM은 문장 전체에 대한 올바른 확률을 정의하지 못하고, 이렇게 학습한 모델은 왼쪽에서 오른쪽으로 텍스트를 쉽게 생성할 수 없습니다. MLM 모델은 훌륭한 *독자*(분류, 태깅, 검색)이지만 서툰 *작가*입니다. 이 점은 제22장에서 자세히 살펴봅니다.

## 코드: 학습 예제 만들기

아래 코드는 같은 토큰 ID로부터 두 목표의 학습 예제를 만드는 방법을 보여 줍니다. 레이블 값 `-100`은 "손실에서 이 위치를 무시하라"는 PyTorch의 관례입니다.

```python
import torch
import torch.nn.functional as F

torch.manual_seed(0)
vocab_size, MASK_ID = 100, 3            # 장난감 어휘; id 3이 [MASK] 역할을 함
tokens = torch.tensor([[12, 45, 7, 88, 23, 61, 9, 30]])   # 문장 하나, 토큰 id 8개

# 인과적 LM: 입력은 tokens[:-1], 타깃은 tokens[1:]
clm_input, clm_target = tokens[:, :-1], tokens[:, 1:]
print("CLM input :", clm_input.tolist())
print("CLM target:", clm_target.tolist())

# 마스크 LM: 위치의 비율 p를 고른 뒤 80/10/10 규칙 적용
def mask_tokens(x, p=0.15):
    labels = x.clone()
    chosen = torch.rand(x.shape) < p
    labels[~chosen] = -100                          # -100 = 손실에서 무시됨
    x = x.clone()
    r = torch.rand(x.shape)
    x[chosen & (r < 0.8)] = MASK_ID                 # 80%: [MASK]로 교체
    rand_pos = chosen & (r >= 0.8) & (r < 0.9)      # 10%: 무작위 토큰으로 교체
    x[rand_pos] = torch.randint(4, vocab_size, (int(rand_pos.sum()),))
    return x, labels                                # 나머지 10%: 그대로 둠

mlm_input, mlm_labels = mask_tokens(tokens, p=0.3)  # 예제에 마스크가 보이도록 p를 크게
print("MLM input :", mlm_input.tolist())
print("MLM labels:", mlm_labels.tolist())

logits = torch.randn(1, 8, vocab_size)              # 모델 출력을 대신하는 값
loss = F.cross_entropy(logits.view(-1, vocab_size), mlm_labels.view(-1), ignore_index=-100)
print("MLM loss:", round(loss.item(), 3))           # 레이블이 있는 위치만 평균
```

이 난수 시드에서 마스크된 입력은 `[12, 45, 3, 3, 23, 61, 9, 30]`이고 레이블은 `[-100, -100, 7, 88, -100, -100, -100, -100]`입니다. 두 위치가 마스크되었고, 그 위치들만 손실에 기여합니다. 무작위 로짓에 대한 손실은 약 4.7로, 100개 토큰 중에서 균등하게 추측할 때의 값인 $\ln 100 \approx 4.6$에 가깝습니다. 유용한 점검 방법입니다.

## 두 고전적 목표를 넘어서

이후 등장한 많은 목표는 이 두 게임의 변형으로 이해할 수 있습니다.

- **스팬 손상**(span corruption; T5, Raffel et al., 2020). 개별 토큰 대신 연속된 토큰 구간(스팬)을 각각 하나의 센티널 토큰으로 바꿉니다. 예: *"the cat `<X>` the mat"*. 인코더가 손상된 텍스트를 읽고, 디코더가 빠진 스팬을 생성합니다: *"`<X>` sat on"*. 인코더는 양방향으로 읽으면서, 디코더는 진짜 생성기로 학습됩니다.
- **잡음 제거**(denoising; BART, Lewis et al., 2020). 마스킹, 삭제, 문장 순서 섞기 등 여러 방식으로 입력을 손상시키고, 인코더–디코더 모델이 원래 텍스트를 복원합니다. 언어를 위한 **잡음 제거 오토인코더**(denoising autoencoder)입니다.
- **접두사 언어 모델링**(prefix language modeling). 시퀀스의 앞부분(접두사)은 양방향으로 읽고, 나머지는 인과적으로 생성합니다. 하나의 마스크 행렬이 접두사 안에서는 전체 어텐션을, 그 뒤에서는 인과적 어텐션을 허용합니다.
- **대체 토큰 탐지**(replaced token detection; ELECTRA, Clark et al., 2020). 작은 생성기가 마스크된 위치를 그럴듯한 토큰으로 채우고, 주 모델은 *모든* 토큰에 대해 원래 토큰인지 대체된 토큰인지 판별합니다. 손실이 모든 위치를 포함하므로 MLM보다 데이터를 효율적으로 사용합니다.

| 목표 | 보이는 문맥 | 손실이 있는 위치 | 생성 가능? |
|---|---|---|---|
| 인과적 LM | 왼쪽만 | 전부 | 예 |
| 마스크 LM | 양쪽 | 약 15% | 직접은 어려움 |
| 스팬 손상 | 양쪽(인코더) | 마스크된 스팬 | 예(디코더) |
| 대체 토큰 탐지 | 양쪽 | 전부 | 아니요 |

왜 인과적 LM이 대형 모델의 표준이 되었을까요? 주된 이유는 세 가지입니다. 모든 토큰을 사용합니다. 학습 과제가 생성과 일치하므로 하나의 모델이 이해와 작문을 모두 할 수 있습니다. 그리고 제23장에서 보겠지만, 충분히 큰 인과적 모델은 가중치를 전혀 바꾸지 않고 입력 속 지시와 예시만으로 새로운 과제를 풀 수 있습니다. 그래도 검색과 분류에 쓰이는 작은 모델에서는 MLM의 양방향성이라는 장점이 여전히 중요하며, 그래서 인코더 모델은 지금도 널리 쓰입니다.

## 요약

- 사전 학습은 자기 지도 방식입니다. 텍스트 일부를 숨기고 모델이 그것을 복원하도록 학습시키므로 사람이 만든 레이블이 필요 없습니다.
- 인과적 언어 모델링은 각 토큰을 이전 토큰들로부터 예측하며, $-\sum_t \log P_\theta(x_t \mid x_{<t})$를 인과적 마스크와 한 칸 밀린 타깃으로 계산합니다.
- 마스크 언어 모델링은 토큰의 약 15%를 숨기고(80/10/10 규칙) 양방향 문맥으로 예측합니다. 손실은 마스크된 위치에서만 계산됩니다.
- CLM은 모든 토큰을 사용하고 생성 방식과 일치합니다. MLM은 더 풍부한 양방향 표현을 주지만 생성이 쉽지 않습니다.
- 스팬 손상, 잡음 제거, 접두사 LM, 대체 토큰 탐지는 두 방식의 장점을 결합한 변형입니다.

## 연습 문제

1. BERT가 선택한 토큰을 항상 `[MASK]`로 바꾸지 않는 이유를 자신의 말로 설명하십시오.
2. 말뭉치에 100억 개의 토큰이 있습니다. CLM에서 한 번 훑을 때 손실 항은 몇 개입니까? 마스킹 비율 15%인 MLM에서는 몇 개입니까? 이것은 데이터 효율에 대해 무엇을 말해 줍니까?
3. `mask_tokens`를 수정하여 단어 전체를 마스크하도록 하십시오. 한 단어가 여러 서브워드 토큰(제3장)으로 나뉘어 있다면 그 조각들을 모두 함께 마스크합니다. 추가 입력으로 어떤 정보가 필요합니까?
4. 처음 2개 토큰이 접두사인 접두사 언어 모델링의 어텐션 마스크($5 \times 5$의 0과 1로 된 행렬)를 쓰십시오.

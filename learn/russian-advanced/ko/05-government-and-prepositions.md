## 문법

**격 지배**(управление)란 어떤 단어가 특정한 격을, 경우에 따라 특정한 전치사와 함께 요구하는 규칙입니다: влиять **на** что, зависеть **от** чего, способствовать **чему**. 한국어 화자에게는 조사 고르기와 비슷합니다. *~에 영향을 미치다*, *~에 따라 달라지다*처럼 말이죠. 문제는 한국어도 영어도 러시아어의 선택을 예측해 주지 않는다는 점입니다. *~에 좌우되다*는 зависеть **от**(글자 그대로는 "~로부터")이고, *~에 주의를 기울이다*는 전치사 **없이** 여격을 쓰는 уделять внимание + 여격입니다. 격 지배는 단어와 함께 한 덩어리로 외워야 합니다.

러시아인들도 격 지배를 의문사로 표시합니다: влиять на **что**, зависеть от **чего**, соответствовать **чему**, пользоваться **чем**, свидетельствовать о **чём**. 새 동사는 이 형태로 외우세요.

### 1. 구조별 핵심 연구 어휘

| 구조 | 동사, 명사, 형용사 | 예 |
|---|---|---|
| **на** + 대격 | влиять / влияние на, указывать на, обращать внимание на, опираться на, рассчитывать на, направлен на, ссылаться / ссылка на, рецензия на, разбивать на | Метод направлен на сокращение вычислений. |
| **на** + 전치격 | основываться на, основан на, сосредоточиться на, обучать на (данных) | Метод основан на механизме внимания. |
| **о** + 전치격 | свидетельствовать о, сообщать о, говорить о | Данные свидетельствуют о высокой точности метода. |
| **от** + 생격 | зависеть от, зависимость от, отличаться от, отказаться от, независимо от | Наш метод отличается от базового числом параметров. |
| **с** + 조격 | сравнивать с, связан с, справляться с, совпадать с, согласен с | Ошибка связана с качеством разметки. |
| **к** + 여격 | интерес к, применять к, приводить к, относиться к, подход к, стремиться к | Это приводит к потере информации. |
| **в** + 전치격 | участвовать в, нуждаться в, сомневаться в, уверенность в, заключаться в | Мы нуждаемся в дополнительных данных. |
| 전치사 없이 여격 | способствовать, препятствовать, соответствовать, противоречить, уступать, уделять внимание, посвящён | Работа посвящена проблеме токенизации. |
| 전치사 없이 조격 | пользоваться, руководить, заниматься, обладать, являться, характеризоваться | Мы пользовались открытой библиотекой. |
| 전치사 없이 생격 | достигать / достичь, избегать / избежать, касаться | Модель достигла точности 92 %. |
| 전치사 없이 대격 | использовать, исследовать, анализировать, учитывать, обсуждать, превосходить | Наша модель превосходит базовую по скорости. |

한 가지만 다른데 자주 헷갈리는 짝들이 있습니다.

- **обращать внимание на** + 대격, 그러나 **уделять внимание** + 여격: обратить внимание на качество данных / уделить внимание качеству данных.
- **пользоваться** + 조격, 그러나 **использовать** + 대격: пользоваться библиотекой / использовать библиотеку.
- **превосходить** + 대격 **по** + 여격, **уступать** + 여격 **по** + 여격: Модель А превосходит модель Б по скорости, но уступает ей по точности.
- **уверенность в** + 전치격, 그러나 **вера в** + 대격: уверенность в успехе / вера в успех.
- **оплатить** + 대격, 그러나 **заплатить за** + 대격: оплатить доступ к кластеру / заплатить за доступ к кластеру.
- **рецензия на** + 대격: рецензия на статью. **отзыв**는 두 가지 모두 씁니다: отзыв о работе, отзыв на автореферат.

전치사 뒤에서 3인칭 대명사는 **н-**을 붙인다는 것도 기억하세요: влиять на **него**, зависеть от **неё**, сравнивать с **ними**. 전치사가 없으면 н-이 붙지 않습니다: соответствовать **им**, пользоваться **ею**.

### 2. 2차 전치사: 원인, 근거, 시간, 비교

학술 러시아어에는 명사, 부사, 부동사에서 생긴 전치사가 많습니다. 각각 정해진 격이 있습니다.

| 전치사 | 격 | 의미와 용법 |
|---|---|---|
| **благодаря** | 여격 | *~ 덕분에*: 좋은 또는 중립적인 결과의 원인. Благодаря этому модель обрабатывает больше текста. |
| **из-за** | 생격 | *~ 때문에*: 대개 나쁜 결과의 원인. Из-за сбоя сервера мы потеряли два дня. |
| **вследствие** | 생격 | *~으로 인해*: 격식체, 중립적 원인. Вследствие ограниченных ресурсов… |
| **в результате** | 생격 | *~의 결과로*. В результате увеличения словаря… |
| **согласно** | 여격 | *~에 따르면, ~에 따라* (데이터, 규칙, 계획). Согласно данным таблицы 3… |
| **вопреки** | 여격 | *~와 반대로, ~에도 불구하고*. Вопреки ожиданиям качество не снизилось. |
| **в соответствии с** | 조격 | *~에 따라, ~에 맞게*. В соответствии с требованиями журнала… |
| **на основе / на основании** | 생격 | *~을 바탕으로, ~에 근거하여*. на основе открытых данных |
| **с помощью / при помощи** | 생격 | *~을 이용하여, ~의 도움으로*. с помощью механизма внимания |
| **в течение** | 생격 | *~ 동안* (기간). в течение всего семестра |
| **в ходе / в процессе** | 생격 | *~ 과정에서*. в ходе дальнейшей работы |
| **с целью / в целях** | 생격 | *~을 목적으로*. с целью проверки гипотезы |
| **в отличие от / независимо от** | 생격 | *~와 달리 / ~와 관계없이*. |
| **по сравнению с / в связи с** | 조격 | *~에 비해 / ~와 관련하여*. |
| **по отношению к** | 여격 | *~에 대하여, ~와 관련하여*. |
| **по** (= *~ 후에*) | 전치격 | по окончании, по завершении, по прибытии, по приезде |

세 가지는 특히 주의해야 합니다.

**Благодаря**는 중립적인 "때문에"가 아닙니다. "감사"의 뉘앙스가 남아 있어서 ~~благодаря ошибке в коде модель обучалась неправильно~~는 우스꽝스럽게(또는 비꼬는 것처럼) 들립니다. 부정적인 원인에는 **из-за**, 격식 있는 글에서는 **вследствие**를 쓰세요. 한국어의 "덕분에"와 "탓에"의 차이와 똑같습니다.

**Согласно**는 **여격**을 지배합니다: согласно данным, согласно плану, согласно правилам. 생격(~~согласно плана~~)은 러시아인들 사이에서도 널리 퍼진 오류이며, 심사자의 눈에 띕니다.

"~ 후에"라는 뜻의 **по**는 **전치격**을 지배하며 **-и** 또는 **-е**로 끝납니다: по окончании экспериментов, по завершении проекта, по приезде в Москву. 일반적인 **по** + 여격과 비교해 보세요: по данным, по точности.

철자도 주의하세요: **в течение**(기간)는 **-е**로 끝나고, **вследствие**는 한 단어입니다. благодаря, согласно, вследствие, в отличие от, независимо от가 이끄는 구는 쉼표로 분리할 수 있는데, 특히 길거나 문장 맨 앞에 올 때 그렇습니다. 하지만 이것은 선택 사항입니다. 이 과의 연습 문제에서는 이런 쉼표를 넣지 않습니다.

### 3. 동사 파생 명사의 격 지배와 절 앞의 то

**동사 파생 명사는 동사의 전치사를 그대로 유지합니다.**

| 동사 | 명사 |
|---|---|
| влиять на качество | влияние на качество |
| зависеть от данных | зависимость от данных |
| интересоваться лингвистикой | интерес к лингвистике (명사는 к + 여격) |
| руководить проектом | руководство проектом |

**타동사의 대격 목적어는 생격이 됩니다**: анализировать результаты → анализ результатов; использовать токенизатор → использование токенизатора. 행위자를 밝히면 조격으로 씁니다: анализ ошибок авторами. 명사에 동사의 주어와 전치사 목적어가 모두 있으면 순서는 "명사 + 생격 + 전치사구"입니다: размер словаря влияет на качество модели → **влияние размера словаря на качество модели**. 한국어의 "어휘 크기가 모델 성능에 미치는 영향"과 구조가 같습니다.

**что절 앞**에서는 전치사가 **что** 바로 앞에 올 수 없습니다. 러시아어는 전치사가 요구하는 격으로 대명사 **то**를 넣습니다.

| 격 지배 | 절 앞 |
|---|---|
| свидетельствовать о + 전치격 | свидетельствует **о том, что**… |
| указывать на + 대격 | указывает **на то, что**… |
| приводить к + 여격 | приводит **к тому, что**… |
| связан с + 조격 | связано **с тем, что**… |
| зависеть от + 생격 | зависит **от того**, какой… / как… |
| заключаться в + 전치격 | заключается **в том, что**… |

전치사 없이 대격을 지배하는 동사에는 **то**가 필요 없습니다: показывать, доказывать, утверждать, считать — Мы показали, что…; Автор доказывает, что… (~~доказывает о том, что~~는 틀린 표현입니다).

**격 지배가 다른 동사들은 목적어 하나를 공유할 수 없습니다.** ~~Мы изучили и опираемся на работы предшественников~~는 틀렸습니다. изучить는 전치사 없는 대격을, опираться는 на + 대격을 요구하기 때문입니다. 각 동사에 따로 목적어를 주세요: Мы изучили работы предшественников и опираемся на них. 한국어로는 "선행 연구를 검토하고 (그것에) 근거한다"처럼 자연스럽게 생략되는 부분이라 특히 실수하기 쉽습니다.

## 학습 팁

**격 지배 노트를 만드세요.** 러시아어 논문에서 유용한 동사를 만날 때마다 "빈자리"와 함께 적어 두세요: соответствовать **чему**, превосходить **что по чему**, рассчитывать **на что**. 논문에서 찾은 실제 문장도 하나 덧붙이세요. 확인할 때는 격 지배 사전(словарь управления)이나 러시아어 국립 코퍼스(Национальный корпус русского языка)의 용례를 이용하세요. 동사를 검색해서 뒤에 무엇이 오는지 보면 됩니다. 한국어에서는 조사가 명사 뒤에 붙지만, 러시아어에서는 전치사가 명사 앞에, 격어미가 명사 뒤에 옵니다. 그러니 구의 양쪽 끝을 모두 확인하세요.

- 전치사 뒤 대명사에 н-: на него, от неё;
- что절 앞: о том, что / на то, что / к тому, что.

## 복습

- 동사를 격 지배와 함께 외웁니다: влиять на что, зависеть от чего, соответствовать чему, пользоваться чем.
- 결과의 의미에 따라 благодаря + 여격과 из-за + 생격을 구별하고, 격식 있는 글에서는 вследствие + 생격을 씁니다.
- согласно данным, по окончании, в течение семестра를 흔한 실수 없이 씁니다.
- 올바른 격 지배로 명사구를 만듭니다: влияние размера словаря на качество модели, анализ результатов.
- что절 앞에 то를 넣고(свидетельствует о том, что…; указывает на то, что…), 격 지배가 다른 동사들을 목적어 하나로 묶지 않습니다.

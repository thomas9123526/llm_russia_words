## 많은 것을 알지만 당신의 과제는 모르는 모델

여러분의 연구실이 러시아어 과학 논문 초록을 물리학, 생물학, 화학, 수학, 컴퓨터 과학의 다섯 분야로 분류하려 한다고 가정해 봅시다. 레이블이 붙은 초록은 2,000개입니다. 이것은 트랜스포머를 처음부터 학습시키기에는 너무 적습니다. 27장에서 보았듯이 좋은 언어 모델에는 수십억 개의 토큰이 필요합니다. 그러나 **사전 학습된 모델**(pre-trained model)은 이미 러시아어를 포함한 방대한 양의 텍스트를 읽었습니다. 이 모델은 러시아어 형태론을 이미 "알고" 있고, 어떤 단어들이 서로 관련되어 있는지, 물리학 논문이 대략 어떤 식으로 쓰이는지도 압니다. 여러분의 2,000개 예제는 모델에게 단 한 가지 새로운 것, 즉 이미 알고 있는 것을 다섯 개의 레이블에 대응시키는 방법만 가르치면 됩니다.

이것이 **전이 학습**(transfer learning)의 핵심 아이디어입니다. 한 과제(*원천* 과제, 여기서는 대규모 코퍼스에서의 다음 토큰 예측)를 풀면서 얻은 지식을 다른 과제(*목표* 과제, 여기서는 분류)에 다시 사용하는 것입니다. 이를 수행하는 가장 일반적인 방법이 **미세 조정**(fine-tuning)입니다. 사전 학습된 가중치를 출발점으로 삼아 목표 과제의 데이터로 학습을 계속하는 것입니다.

전이 학습은 언어에만 해당하는 것이 아닙니다. 컴퓨터 비전에서는 ImageNet으로 사전 학습된 네트워크에서 시작하는 것이 표준 관행이 되었습니다. NLP에서는 2018년 무렵 큰 변화가 일어났습니다. ULMFiT(Howard와 Ruder)는 사전 학습된 언어 모델을 매우 적은 레이블로 텍스트 분류에 미세 조정할 수 있음을 보여 주었고, BERT(22장)는 "한 번 사전 학습하고, 과제마다 미세 조정한다"는 방식을 기본 처방으로 만들었습니다. 오늘날 거의 모든 응용 LLM 프로젝트는 사전 학습된 **체크포인트**(checkpoint)에서 시작합니다.

## 전이가 작동하는 이유

다음 토큰을 예측하도록 학습된 가중치가 왜 초록 분류에 도움이 될까요? 직관은 이렇습니다. 사전 학습은 모델이 범용적인 **표현**(representation)을 만들도록 강제합니다. 다음 단어를 잘 예측하려면 모델은 구문, 일치, 주제, 세상에 대한 사실 등 많은 것을 추적해야 합니다. 이러한 특징은 거의 모든 언어 과제에 유용합니다.

프로빙(probing, 은닉 상태 위에 작은 분류기를 학습시키는 방법) 연구는 대략적인 그림을 보여 줍니다. 아래층은 더 국소적이고 표면적인 정보(단어 조각, 형태론)를, 중간층은 구문을, 위층은 더 의미적이고 과제에 특화된 정보를 담는 경향이 있습니다. 이 그림이 완벽하게 깔끔하지는 않지만, 실용적인 규칙 하나를 설명해 줍니다. 아래층은 대개 더 일반적이어서 잘 전이되고, 위층은 사전 학습 목표에 더 특화되어 있어 더 많은 변화가 필요합니다.

전이는 최적화의 관점에서도 볼 수 있습니다. 무작위 가중치에서 시작하는 학습은 손실 지형(8장)의 임의의 지점에서 출발합니다. 미세 조정은 관련된 문제에 대해 이미 매우 좋은 지점에서 출발합니다. 그곳에서는 작은 학습률로 적은 수의 경사 하강 단계만 밟아도 새로운 과제에 대한 좋은 해에 도달하는 경우가 많습니다. 이런 의미에서 사전 학습된 가중치는 강한 사전 지식처럼 작용합니다. 좋은 해가 어디에 있을 가능성이 높은지를 옵티마이저에게 알려 주는 것입니다.

## 미세 조정 전략

전략에는 사전 학습된 모델을 전혀 바꾸지 않는 것부터 모든 것을 바꾸는 것까지 하나의 스펙트럼이 있습니다.

**1. 특징 추출(고정된 백본).** 사전 학습된 모든 가중치를 **고정**(freeze)하고, 모델은 표현을 계산하는 데만 사용합니다. 예를 들어 BERT의 `[CLS]` 토큰의 은닉 상태나 모든 토큰 상태의 평균을 씁니다. 그 위에 작은 새 **분류 헤드**(classification head)를 학습시키는데, 흔히 선형 층 하나입니다. 이 방법은 저렴하고 안정적이며 과적합되기 어렵지만, 표현이 과제에 맞게 적응할 수 없습니다.

**2. 부분 미세 조정.** 위쪽 $k$개 층과 헤드만 고정을 해제합니다. 위층이 가장 과제 특화적이므로, 이 방법은 더 적은 비용으로 전체 미세 조정 이득의 대부분을 얻는 경우가 많습니다.

**3. 전체 미세 조정.** 모든 파라미터를 갱신합니다. 데이터가 충분하면 대개 가장 좋은 품질을 내지만 비용이 가장 큽니다. Adam으로 학습하는 $N$개 파라미터의 모델이라면, 28장에서 논의했듯이 가중치, 그래디언트, 파라미터당 두 개의 옵티마이저 상태, 즉 대략 $4N$개의 수(그리고 활성값)를 저장해야 합니다. 또한 과제마다 모델의 전체 사본이 하나씩 생깁니다.

**4. 매개변수 효율적 미세 조정.** 모델을 고정하고, 모델 안에 삽입된 소수의 새 파라미터만 학습시킵니다. 이것은 32장(LoRA와 QLoRA)의 주제입니다.

헤드는 과제에 따라 달라집니다. $C$개 클래스 분류의 경우, 헤드는 은닉 벡터 $h \in \mathbb{R}^d$를 로짓으로 변환합니다.

$$z = W h + b, \qquad W \in \mathbb{R}^{C \times d},\; b \in \mathbb{R}^C,$$

그리고 교차 엔트로피 손실(8장)로 학습합니다. 개체명 인식 같은 토큰 단위 과제에서는 같은 헤드를 각 토큰의 은닉 상태에 적용합니다. 디코더 모델을 사용하는 생성 과제에서는 새 헤드가 필요 없습니다. 언어 모델링 헤드를 그대로 두고 (입력, 출력) 텍스트 쌍으로 학습을 계속하면 됩니다. 이것이 33장에서 다룰 지시 튜닝의 기반입니다.

아래 코드는 장난감 "사전 학습" 네트워크에서 처음 두 전략을 보여 줍니다. 백본을 고정하고, 새 헤드를 추가한 다음, 학습 가능한 파라미터가 몇 개인지 확인합니다.

```python
import torch
import torch.nn as nn

torch.manual_seed(0)
d, num_classes = 64, 5
# 사전 학습된 백본의 대용품: 세 개의 층
backbone = nn.Sequential(nn.Linear(32, d), nn.ReLU(),
                         nn.Linear(d, d), nn.ReLU(),
                         nn.Linear(d, d), nn.ReLU())
head = nn.Linear(d, num_classes)          # 무작위로 초기화된 새 헤드
model = nn.Sequential(backbone, head)

# 전략 1: 백본 전체를 고정
for p in backbone.parameters():
    p.requires_grad = False
# 전략 2: 백본의 맨 위층만 고정 해제
for p in backbone[4].parameters():
    p.requires_grad = True

trainable = sum(p.numel() for p in model.parameters() if p.requires_grad)
total = sum(p.numel() for p in model.parameters())
print(f"trainable {trainable} of {total}")   # trainable 4485 of 10757

# 옵티마이저에는 학습 가능한 파라미터만 전달
opt = torch.optim.AdamW([p for p in model.parameters() if p.requires_grad], lr=1e-3)
x, y = torch.randn(8, 32), torch.randint(0, num_classes, (8,))
loss = nn.functional.cross_entropy(model(x), y)
loss.backward()
opt.step()
print(backbone[0].weight.grad is None)        # True: 고정된 층은 그래디언트를 받지 않음
```

숫자를 확인해 봅시다. 첫 번째 층에는 $32 \cdot 64 + 64 = 2112$개, 백본의 나머지 두 층에는 각각 $64 \cdot 64 + 64 = 4160$개, 헤드에는 $64 \cdot 5 + 5 = 325$개의 파라미터가 있습니다. 합계는 $2112 + 2 \cdot 4160 + 325 = 10{,}757$입니다. 학습 가능한 부분은 맨 위층과 헤드로, $4160 + 325 = 4485$개입니다.

## 파국적 망각과 그 회피 방법

미세 조정에는 잘 알려진 위험이 있습니다. 좁은 데이터셋으로 너무 강하게 학습시키면 모델이 원래 가지고 있던 일반적인 능력을 잃을 수 있습니다. 이를 **파국적 망각**(catastrophic forgetting)이라고 합니다. 과제 A를 학습한 뒤 과제 B를 순차적으로 학습한 신경망은 A를 위해 배운 것을 덮어쓰는 경향이 있습니다. 법률 문서로 공격적으로 미세 조정된 모델은 일상 대화를 더 못하게 되거나 전에 알던 지식을 잊을 수 있습니다.

작은 데이터셋에는 두 번째 위험인 **과적합**(overfitting, 10장)이 있습니다. 수억 개의 파라미터를 가진 모델은 2,000개의 예제를 쉽게 암기할 수 있습니다. 몇 가지 실용적인 기법이 두 문제 모두에 도움이 됩니다.

- **작은 학습률.** 미세 조정에는 사전 학습보다 훨씬 작은 학습률을 사용합니다. BERT 크기의 모델에 대해 원 논문은 $2\cdot10^{-5}$에서 $5\cdot10^{-5}$ 정도의 값을 권장했습니다. 가중치를 조금 움직이려는 것이지, 망가뜨리려는 것이 아닙니다.
- **적은 에포크.** 데이터를 2–4번 훑는 것으로 충분한 경우가 많습니다. **검증 세트**(validation set)의 손실을 관찰하다가 더 이상 개선되지 않으면 조기에 멈춥니다.
- **워밍업과 감쇠.** 짧은 **학습률 워밍업**(learning rate warmup)은 새 헤드가 아직 무작위여서 그래디언트가 큰 첫 단계들에서 크고 잡음 섞인 갱신을 막아 줍니다.
- **차등적(층별) 학습률.** ULMFiT는 아래층이 더 일반적이므로 위층보다 작은 학습률을 주자고 제안했습니다. 흔한 규칙은 한 층 내려갈 때마다 학습률에 $\xi < 1$을 곱하는 것입니다. 층 $l$은 $\eta_l = \eta \cdot \xi^{L-l}$을 받는데, 여기서 $L$은 맨 위층, $\eta$는 맨 위층의 학습률입니다.
- **점진적 고정 해제**(gradual unfreezing). 역시 ULMFiT에서 나온 방법으로, 먼저 헤드를 학습시킨 다음 위에서부터 한 층씩 고정을 해제합니다.
- **일반 데이터 섞기.** 생성 모델을 미세 조정할 때 일반 사전 학습 데이터나 일반 지시 데이터를 소량 섞으면 망각이 줄어듭니다.
- **출발점 쪽으로의 정규화.** 일부 방법은 현재 가중치 $\theta$와 사전 학습된 가중치 $\theta_0$ 사이의 거리 $\lVert \theta - \theta_0 \rVert^2$에 벌점을 주어 모델이 출발점 근처에 머물도록 합니다.

PyTorch에서 **층별 학습률**(layer-wise learning rate)은 *파라미터 그룹*으로 구현합니다. 위의 예를 이어 가 봅시다.

```python
# 모두 고정 해제하고 층마다 자신의 학습률을 부여
for p in model.parameters():
    p.requires_grad = True

base_lr, xi = 1e-3, 0.5
groups = [
    {"params": head.parameters(),        "lr": base_lr},
    {"params": backbone[4].parameters(), "lr": base_lr * xi},
    {"params": backbone[2].parameters(), "lr": base_lr * xi**2},
    {"params": backbone[0].parameters(), "lr": base_lr * xi**3},
]
opt = torch.optim.AdamW(groups, weight_decay=0.01)
print([g["lr"] for g in opt.param_groups])   # [0.001, 0.0005, 0.00025, 0.000125]
```

## 언제, 무엇으로 미세 조정할까

미세 조정이 항상 올바른 도구는 아닙니다. 무언가를 학습시키기 전에 세 가지 질문을 해 볼 가치가 있습니다.

**프롬프트로 해결할 수 있는가?** 큰 디코더 모델은 프롬프트 안의 지시와 몇 개의 예시만으로 과제를 해내는 경우가 많습니다(맥락 내 학습, 23장). 이것은 학습 비용이 전혀 들지 않습니다. 미세 조정은 일관된 출력 형식이 필요할 때, 특화된 도메인일 때, 추론 비용을 낮추고 싶을 때(작은 미세 조정 모델이 프롬프트를 쓰는 큰 모델을 대체할 수 있음), 또는 레이블된 예제가 많을 때 매력적입니다.

**문제는 지식인가, 행동인가?** 미세 조정은 *행동*을 가르치는 데 능합니다. 스타일, 형식, 분류 과제의 레이블, 지시를 따르는 방법 등입니다. 많은 새로운 *사실*을 추가하는 수단으로는 덜 믿을 만합니다. 모델이 사실을 부분적으로만 학습하고 환각을 일으킬 수 있습니다. 최신 지식이나 비공개 지식에는 검색(37장)이 더 나은 경우가 많습니다.

**데이터와 연산 자원이 얼마나 있는가?** 예제가 수백 개라면 선형 헤드를 단 고정된 백본이나 매개변수 효율적 방법이 더 안전합니다. 예제가 수만 개이고 GPU 메모리가 충분하다면 전체 미세 조정이 최고의 결과를 낼 수 있습니다.

관련된 개념으로 **도메인 적응**(domain adaptation)이 있습니다. 레이블된 과제로 미세 조정하기 전에, 목표 도메인의 레이블 없는 텍스트(예: 러시아어 물리학 논문의 대규모 모음)로 원래의 언어 모델링 목표에 따라 사전 학습을 계속하는 것입니다. 이 "지속 사전 학습" 단계는 모델이 해당 도메인의 어휘와 문체를 익히도록 돕고, 이후의 레이블 기반 미세 조정을 더 쉽게 만듭니다.

## 요약

- 전이 학습은 원천 과제(사전 학습)의 지식을 목표 과제에 다시 사용합니다. 미세 조정은 사전 학습된 가중치를 목표 데이터로 계속 학습시킵니다.
- 사전 학습이 범용 표현을 만들기 때문에 전이가 작동합니다. 아래층은 더 일반적이고, 위층은 더 과제 특화적인 경향이 있습니다.
- 전략은 고정된 백본을 이용한 특징 추출에서 부분 미세 조정과 전체 미세 조정을 거쳐 매개변수 효율적 방법(32장)까지 이어집니다.
- 주된 위험은 파국적 망각과 과적합이며, 작은 학습률, 적은 에포크, 워밍업, 조기 종료, 층별 학습률, 점진적 고정 해제로 줄일 수 있습니다.
- 미세 조정은 행동과 형식을 가르치는 데 가장 적합하며, 새로운 사실에는 검색이 더 믿을 만한 경우가 많습니다.

## 연습 문제

1. 사전 학습된 모델의 아래층에 위층보다 작은 학습률을 주는 이유를 자신의 말로 설명하십시오.
2. BERT-base 모델의 은닉 크기는 $d = 768$입니다. 5개 클래스를 위한 선형 분류 헤드의 파라미터는 몇 개입니까? 이는 1억 1천만 개 파라미터 모델의 몇 퍼센트입니까?
3. 첫 번째 코드 예제를 수정하여 백본의 위쪽 *두* 층이 학습 가능하도록 하십시오. 학습 가능한 파라미터는 몇 개가 됩니까? 손으로 답을 확인하십시오.
4. 러시아어로 된 레이블된 의료 질문 300개와 GPU 한 대에서 돌아가는 70억 개 파라미터 모델이 있습니다. 이 장의 전략 중 무엇을 먼저 선택하겠습니까? 그 이유는 무엇입니까?

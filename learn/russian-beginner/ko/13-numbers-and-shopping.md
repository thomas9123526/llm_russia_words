# 제13과. 1000까지의 수, 가격, Сколько стоит? 가게와 학생 식당에서

> **초급 러시아어** · 수준: A1 · **배울 내용:** 20부터 1000까지의 수 · Ско́лько сто́ит?로 가격 묻고 말하기 · 가게와 대학 식당에서 음식 사기

## 대화

*В столо́вой* (학생 식당에서). 디마가 민호에게 대학 식당을 보여 줍니다. 민호는 계산대로 갑니다.

**Ди́ма:** Минхо́, вот на́ша столо́вая. Здесь недо́рого.\
*민호야, 여기가 우리 식당이야. 여기는 비싸지 않아.*

**Минхо́:** Отли́чно! Что ты обы́чно берёшь?\
*좋다! 너는 보통 뭘 골라?*

**Ди́ма:** Обы́чно я беру́ борщ, сала́т и чай.\
*나는 보통 보르시, 샐러드, 차를 골라.*

**Минхо́:** Здра́вствуйте! Да́йте, пожа́луйста, борщ и сала́т.\
*안녕하세요! 보르시하고 샐러드 주세요.*

**Касси́р:** Борщ — сто два́дцать рубле́й, сала́т — девяно́сто. Что ещё?\
*보르시는 120루블, 샐러드는 90루블입니다. 또 뭐 드릴까요?*

**Минхо́:** Ско́лько сто́ит ку́рица?\
*닭고기는 얼마예요?*

**Касси́р:** Ку́рица — две́сти со́рок рубле́й.\
*닭고기는 240루블입니다.*

**Минхо́:** Э́то до́рого. Тогда́ чай и бу́лочку, пожа́луйста.\
*비싸네요. 그럼 차하고 빵 주세요.*

**Касси́р:** Чай — три́дцать пять, бу́лочка — со́рок. Всё?\
*차는 35, 빵은 40입니다. 이게 다인가요?*

**Минхо́:** Да, всё. Ско́лько с меня́?\
*네, 다예요. 얼마 드리면 돼요?*

**Касси́р:** Две́сти во́семьдесят пять рубле́й.\
*285루블입니다.*

**Минхо́:** Мо́жно ка́ртой?\
*카드로 계산해도 돼요?*

**Касси́р:** Коне́чно. Спаси́бо!\
*물론이죠. 감사합니다!*

**Ди́ма:** Молоде́ц, Минхо́! Ты уже́ всё понима́ешь по-ру́сски.\
*잘했어, 민호! 너 벌써 러시아어를 다 알아듣는구나.*

## 문법

### 1. 20부터 1000까지의 수

제6과에서 0–20을 배웠습니다. 이제 "십 단위"와 "백 단위" 단어만 더 외우면 됩니다. 나머지는 모두 조립식 블록처럼 조합해서 만듭니다.

| 십 단위 | | 백 단위 | |
|---|---|---|---|
| 20 | два́дцать | 100 | сто |
| 30 | три́дцать | 200 | две́сти |
| 40 | со́рок | 300 | три́ста |
| 50 | пятьдеся́т | 400 | четы́реста |
| 60 | шестьдеся́т | 500 | пятьсо́т |
| 70 | се́мьдесят | 600 | шестьсо́т |
| 80 | во́семьдесят | 700 | семьсо́т |
| 90 | девяно́сто | 800 | восемьсо́т |
| | | 900 | девятьсо́т |
| | | 1000 | ты́сяча |

외울 때 도움이 되는 규칙:

- 20과 30은 11–19(двена́дцать, трина́дцать)처럼 **-дцать**로 끝납니다.
- 50–80은 "오-십, 육-십…"처럼 **пять + десят** 구조입니다. 한국어의 "오십, 육십"과 같은 원리입니다. 연음 부호 **ь**는 끝이 아니라 가운데에 있습니다: пя**ть**деся́т.
- 40(**со́рок**)과 90(**девяно́сто**)은 불규칙입니다. 그냥 외웁시다.
- 200은 **две́сти**, 300과 400은 **-ста**, 500–900은 **-сот**로 끝납니다.
- 강세에 주의하세요. 50, 60, 500–900은 강세가 **뒤**에 있고(пятьдеся́т, пятьсо́т), 70과 80은 **앞**에 있습니다(се́мьдесят, во́семьдесят).

합성수는 한국어처럼 큰 수부터 작은 수 순서로 단어를 나란히 놓기만 하면 됩니다. "그리고(и)"는 넣지 않습니다.

- 21 — два́дцать оди́н
- 45 — со́рок пять
- 99 — девяно́сто де́вять
- 150 — сто пятьдеся́т
- 285 — две́сти во́семьдесят пять
- 412 — четы́реста двена́дцать
- 999 — девятьсо́т девяно́сто де́вять

### 2. оди́н рубль, два рубля́, пять рубле́й

러시아어에서는 수 뒤에 오는 명사의 형태가 바뀝니다. 전체 체계는 나중에(제16과와 중급 책) 배웁니다. 지금은 가게에서 가장 많이 쓰는 단어 **рубль**의 패턴만 익힙시다. 한국어는 "1루블, 2루블, 5루블"처럼 단위 명사가 변하지 않지만, 러시아어는 세 가지 형태가 있습니다.

| 수의 끝이… | 형태 | 예 |
|---|---|---|
| 1 (11은 제외) | **рубль** | оди́н рубль, два́дцать оди́н рубль, сто оди́н рубль |
| 2, 3, 4 (12, 13, 14는 제외) | **рубля́** | два рубля́, три́дцать три рубля́, две́сти со́рок четы́ре рубля́ |
| 5–9, 0, 11–19 | **рубле́й** | пять рубле́й, двена́дцать рубле́й, сто рубле́й, ты́сяча рубле́й |

핵심: **수의 마지막 단어만 보세요.** 243(две́сти со́рок три)은 마지막 단어가 три이므로 **рубля́**입니다. 112(сто двена́дцать)는 마지막 단어가 двена́дцать이므로 **рубле́й**입니다. 40, 100, 500처럼 딱 떨어지는 수도 **рубле́й**를 씁니다.

예문:

- Бу́лочка сто́ит со́рок рубле́й. — *빵은 40루블입니다.*
- Ко́фе сто́ит сто два рубля́. — *커피는 102루블입니다.*
- Хлеб сто́ит пятьдеся́т оди́н рубль. — *빵(식빵)은 51루블입니다.*
- Э́то сто́ит три́ста рубле́й. — *이것은 300루블입니다.*

두 가지 작은 점에 주의하세요. 첫째, **ко́фе**는 남성 명사이고 형태가 절대 변하지 않습니다. 둘째, **сто́ит** 뒤의 가격은 대격(제12과)입니다. 대부분의 수는 형태가 그대로지만 **ты́сяча**는 кни́га → кни́гу처럼 **ты́сячу**가 됩니다: Телефо́н сто́ит ты́сячу рубле́й. — *전화기는 천 루블입니다.*

### 3. 가격 묻기와 물건 사기

**Ско́лько сто́ит…?**는 "~은 얼마예요?"라는 뜻입니다. 동사 **сто́ить**는 제2식 변화 동사입니다. 가게에서는 두 가지 형태만 알면 됩니다.

- **сто́ит** — 물건 하나: Ско́лько сто́ит чай? — *차는 얼마예요?*
- **сто́ят** — 물건 여러 개(복수, 제6과): Ско́лько сто́ят я́блоки? — *사과는 얼마예요?*

대답:

- Чай сто́ит три́дцать пять рубле́й. — *차는 35루블입니다.*
- Я́блоки сто́ят сто рубле́й. — *사과는 100루블입니다.*
- 빠른 말에서는 동사를 빼고 대시(—)로 대신하기도 합니다: Чай — три́дцать пять. Сала́т — девяно́сто.

동사 **брать**(잡다, 고르다)는 식당에서 아주 유용합니다. 제1식 변화이지만 어간이 **бр-** → **бер-**로 바뀌고, 어미에 강세가 옵니다.

| | брать |
|---|---|
| я | беру́ |
| ты | берёшь |
| он, она́ | берёт |
| мы | берём |
| вы | берёте |
| они́ | беру́т |

- Я беру́ суп. — *저는 수프로 할게요.*
- Что ты берёшь? — *너는 뭐 먹을래(뭐 골라)?*
- Ди́ма берёт борщ. — *디마는 보르시를 고릅니다.*

**가게에서 쓰는 표현.** 통째로 외워 두세요.

| 표현 | 뜻 |
|---|---|
| Да́йте, пожа́луйста, … | ~ 주세요 (+ 대격) |
| Что ещё? | 또 필요한 것 있으세요? |
| Всё. / Э́то всё. | 그게 다예요. |
| Ско́лько с меня́? | 얼마 드리면 돼요? |
| Мо́жно ка́ртой? | 카드로 돼요? |
| Мо́жно нали́чными? | 현금으로 돼요? |
| Э́то до́рого. / Э́то недо́рого. / Э́то дёшево. | 비싸요. / 비싸지 않아요. / 싸요. |

**Да́йте, пожа́луйста** 뒤에는 제12과의 대격을 씁니다. 한국어의 "을/를"에 해당합니다. 여성 명사는 **-а → -у**, **-я → -ю**로 바뀌고, 남성·중성 무생물 명사는 그대로입니다.

- Да́йте, пожа́луйста, во́ду. — *물 주세요.*
- Да́йте, пожа́луйста, бу́лочку и сок. — *빵하고 주스 주세요.*
- Да́йте, пожа́луйста, хлеб и молоко́. — *빵하고 우유 주세요.*

**ка́ртой**와 **нали́чными**는 조격 형태입니다. 한국어의 "(으)로"와 비슷합니다. 조격은 제19과에서 배우니, 지금은 질문 전체를 외워 두세요.

## 발음

일상에서 자주 쓰는 몇몇 단어는 쓰인 것보다 짧게 발음됩니다. 러시아 사람들은 실제로 이렇게 말하므로, 따라 하면 자연스럽게 들립니다.

- **пожа́луйста** — [pazhálsta, 빠잘스따], "уй"가 거의 사라집니다.
- **коне́чно** — [kanyéshna, 까녜시나], **чн**을 [shn]으로 읽습니다.
- **ско́лько** — [skól'ka], 끝의 **о**는 강세가 없어서 [a]처럼 들립니다.
- **пятьдеся́т** — [pidd'isyát], **шестьдеся́т** — [shyzd'isyát]: **д** 앞의 **т**가 유성음이 되어 거의 들리지 않습니다.

한국어 화자는 자음이 겹치는 곳에 모음 "으"를 넣기 쉽습니다. **борщ**를 "보르쉬"처럼 세 음절로 말하지 말고, **борщ**와 **рубль**을 짧은 한 음절로 말해 보세요.

## 문화

**столо́вая**는 셀프서비스 식당입니다. 대학 식당에서는 쟁반을 들고, 진열대에서 음식을 고른 뒤, 마지막에 계산대에서 계산합니다. 카페보다 훨씬 쌉니다. 거의 모든 곳에서 카드나 휴대폰으로 계산할 수 있어서 **Мо́жно ка́ртой?**는 형식적인 질문일 때가 많습니다. 슈퍼마켓에서는 계산원이 **Паке́т ну́жен?**("봉투 필요하세요?")라고 물을 수 있습니다. **Да, пожа́луйста** 또는 **Нет, спаси́бо**라고 대답하세요.

## 복습

- 0부터 1000까지 세고 가격을 알아들을 수 있습니다.

- 수의 마지막 단어를 보고 **оди́н рубль, два рубля́, пять рубле́й**를 바르게 말할 수 있습니다.
- 음식을 주문할 수 있습니다: **Да́йте, пожа́луйста, борщ и сала́т.**
- 계산을 마칠 수 있습니다: **Э́то всё. Ско́лько с меня́? Мо́жно ка́ртой?**

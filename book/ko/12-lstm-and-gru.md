## 스위치가 달린 기억

긴 소설을 읽으면서 종이 한 장에 메모를 한다고 상상해 보십시오. 제11장의 단순 RNN은 문장 하나를 읽을 때마다 이전 메모와 새 문장을 바탕으로 종이 전체를 처음부터 다시 쓰는 독자와 같습니다. 백 번쯤 다시 쓰고 나면 첫 장의 세부 내용은 거의 사라집니다. 다시 쓸 때마다 조금씩 흐려지기 때문입니다.

더 현명한 독자는 세 가지 다른 일을 합니다. 더 이상 필요 없는 메모를 **지웁니다**("주인공은 모스크바에 있다" — 그런데 이제 카잔으로 이사했습니다). 새로운 중요한 사실을 **추가합니다**. 그리고 누군가 질문하면 메모 중 관련된 부분만 **읽어 줍니다**. 종이의 대부분은 문장에서 문장으로 넘어가도 그대로 남아 있습니다.

이것이 Hochreiter와 Schmidhuber(1997)가 제안한 **장단기 메모리**(long short-term memory, LSTM) 네트워크의 아이디어입니다. 이름이 이상하게 들리지만, "오랫동안 지속될 수 있는 단기 기억(RNN의 은닉 상태)"이라는 뜻입니다. 망각 메커니즘은 조금 뒤에 Gers, Schmidhuber, Cummins(2000)가 추가했으며, 오늘날 사용하는 LSTM은 이 버전입니다.

지우고, 추가하고, 읽어 주는 스위치를 **게이트**(gate)라고 합니다. 게이트는 시그모이드 함수(제7장)로 만든 0과 1 사이의 숫자로 이루어진 벡터입니다. 다른 벡터에 게이트를 원소별로 곱합니다. 게이트가 1에 가까운 곳에서는 값이 통과하고, 0에 가까운 곳에서는 값이 차단됩니다. 시그모이드는 매끄러운 함수이므로 게이트는 미분 가능하며, 네트워크는 일반적인 경사 하강법으로 게이트를 *언제* 열고 닫을지 배웁니다.

## LSTM 셀의 내부

LSTM은 매 타임 스텝마다 벡터를 하나가 아니라 두 개 유지합니다.

- **셀 상태**(cell state) $c_t$ — "메모 종이", 즉 장기 기억입니다.
- 은닉 상태 $h_t$ — 셀이 바깥 세계와 다음 층에 보여 주는 것입니다.

단계 $t$에서 셀은 입력 $x_t$와 이전 은닉 상태 $h_{t-1}$을 받습니다. 이로부터 게이트 세 개와 후보 벡터 하나를 계산합니다. 두 벡터를 이어 붙인 것을 $[h_{t-1}, x_t]$로, 시그모이드를 $\sigma$로 씁니다.

$$f_t = \sigma\left(W_f [h_{t-1}, x_t] + b_f\right) \quad \text{(망각 게이트)}$$

$$i_t = \sigma\left(W_i [h_{t-1}, x_t] + b_i\right) \quad \text{(입력 게이트)}$$

$$o_t = \sigma\left(W_o [h_{t-1}, x_t] + b_o\right) \quad \text{(출력 게이트)}$$

$$\tilde{c}_t = \tanh\left(W_c [h_{t-1}, x_t] + b_c\right) \quad \text{(후보 값)}$$

그다음 셀은 기억과 출력을 갱신합니다.

$$c_t = f_t \odot c_{t-1} + i_t \odot \tilde{c}_t$$

$$h_t = o_t \odot \tanh(c_t)$$

여기서 $\odot$는 **원소별 곱셈**(element-wise multiplication, 아다마르 곱이라고도 함)을 나타냅니다: $(a \odot b)_k = a_k b_k$. 방정식을 말로 읽어 봅시다.

- **망각 게이트**(forget gate) $f_t$는 기억의 각 성분마다 이전 값 $c_{t-1}$을 얼마나 유지할지 결정합니다.
- **후보 값**(candidate values) $\tilde{c}_t$는 현재 입력으로부터 제안된 새로운 정보이며, 값은 $(-1, 1)$ 범위에 있습니다.
- **입력 게이트**(input gate) $i_t$는 이 후보를 기억에 얼마나 써 넣을지 결정합니다.
- **출력 게이트**(output gate) $o_t$는 기억의 어느 부분을 $h_t$로 드러낼지 결정합니다.

네 개의 $W$ 행렬은 각각 크기가 $d_h \times (d_h + d_{in})$입니다. 실제로는 이들을 크기 $4d_h \times (d_h + d_{in})$인 큰 행렬 하나로 저장하고, 결과를 네 부분으로 나눕니다. 아래 코드가 정확히 그렇게 합니다.

```python
import numpy as np

def sigmoid(z):
    return 1 / (1 + np.exp(-z))

rng = np.random.default_rng(0)
d_in, d_h = 3, 4
# 네 부분 모두를 위한 큰 행렬 하나: 망각, 입력, 출력, 후보
W = rng.normal(0, 0.5, (4 * d_h, d_in + d_h))
b = np.zeros(4 * d_h)
b[:d_h] = 1.0                                # 망각 게이트 편향 = 1: "기본적으로 기억"

def lstm_step(x, h, c):
    z = W @ np.concatenate([x, h]) + b
    f = sigmoid(z[0*d_h:1*d_h])              # 망각 게이트
    i = sigmoid(z[1*d_h:2*d_h])              # 입력 게이트
    o = sigmoid(z[2*d_h:3*d_h])              # 출력 게이트
    g = np.tanh(z[3*d_h:4*d_h])              # 후보 값
    c = f * c + i * g                        # 셀 상태 갱신
    h = o * np.tanh(c)                       # 새 은닉 상태
    return h, c, f

h, c = np.zeros(d_h), np.zeros(d_h)
for x in rng.normal(size=(5, d_in)):
    h, c, f = lstm_step(x, h, c)
    print("forget gate:", np.round(f, 2), " c:", np.round(c, 2))

m, n = 100, 256                              # 파라미터 수: 입력 m, 은닉 n
for name, k in [("RNN", 1), ("GRU", 3), ("LSTM", 4)]:
    print(name, k * (n * (m + n) + n))
```

(이 코드에서는 벡터를 $[x_t, h_{t-1}]$ 순서로 이어 붙입니다. 모든 곳에서 같은 순서를 쓰기만 하면 순서는 상관없습니다.) `b[:d_h] = 1.0` 줄에 주목하십시오. 망각 게이트의 편향을 양수로 초기화하면 $f_t$가 1에 가까운 값에서 출발하므로, 갓 초기화된 LSTM이 기본적으로 기억하게 됩니다. 이 간단한 요령은 널리 쓰이며 대개 학습을 개선합니다.

## LSTM이 더 오래 기억하는 이유

제11장에서 본 기울기 소실의 원인을 떠올려 봅시다. 단순 RNN에서는 매 단계마다 상태가 완전히 다시 계산되고($h_t = \tanh(W_{hh} h_{t-1} + \dots)$), 한 단계 거슬러 갈 때마다 기울기에 행렬 $W_{hh}$와 $\tanh$의 도함수가 곱해집니다.

셀 갱신식 $c_t = f_t \odot c_{t-1} + i_t \odot \tilde{c}_t$를 다시 보십시오. 새 기억은 크기가 조정된 이전 기억에 새로운 무언가를 *더한* 것입니다. $c_{t-1}$에서 $c_t$로 가는 이 직접 경로만 따라가면(게이트를 통한 더 작은 간접 경로는 무시하면), 도함수는 매우 간단합니다.

$$\frac{\partial c_t}{\partial c_{t-1}} \approx \operatorname{diag}(f_t)$$

이 경로에는 가중치 행렬도, $\tanh$의 도함수도 없습니다. 여러 단계에 걸쳐 기울기에는 망각 게이트들만 곱해집니다: $f_{k+1} \odot f_{k+2} \odot \dots \odot f_t$. 네트워크가 어떤 정보를 유지하고 싶으면 $f$의 해당 성분을 1에 가깝게 만드는 법을 배우고, 그러면 기울기는 거의 줄어들지 않은 채 수백 단계를 거슬러 흐를 수 있습니다. 원 논문에서는 이 직접적이고 대체로 덧셈적인 경로를 "상수 오차 회전목마(constant error carousel)"라고 불렀습니다. 정보를 덧셈 경로로 흐르게 한다는 같은 아이디어는 트랜스포머의 **잔차 연결**(residual connection, 제18장)로 다른 형태를 띠고 다시 등장합니다.

1차원 예를 계산해 봅시다. $c_{t-1} = 2.0$, $f_t = 0.9$, $i_t = 0.2$, $\tilde{c}_t = -0.5$라고 합시다. 그러면 $c_t = 0.9 \cdot 2.0 + 0.2 \cdot (-0.5) = 1.8 - 0.1 = 1.7$입니다. 이전 기억의 대부분이 살아남고 작은 보정이 더해집니다. $f = 0.9$로 20단계가 지나면 이전 내용은 $0.9^{20} \approx 0.12$배가 되지만, $f = 0.99$라면 약 $0.82$배가 됩니다. 네트워크가 자기 기억의 길이를 스스로 조절하는 것입니다.

LSTM이 문제를 완전히 없애지는 못합니다. 게이트는 여전히 시그모이드이고, 아주 긴 의존성은 여전히 어렵습니다. 그러나 실제로 LSTM은 단순 RNN이 수십 단계에서 실패하는 곳에서 수백 단계에 걸친 의존성을 학습할 수 있습니다. 기울기 폭발은 여전히 가능하므로 그래디언트 클리핑은 계속 사용됩니다.

## GRU: 더 가벼운 대안

Cho 등(2014)이 제안한 **게이트 순환 유닛**(gated recurrent unit, GRU)은 게이트라는 핵심 아이디어를 유지하면서 설계를 단순화합니다. 별도의 셀 상태 없이 $h_t$만 있으며, 게이트를 세 개 대신 두 개 사용합니다.

$$z_t = \sigma\left(W_z [h_{t-1}, x_t] + b_z\right) \quad \text{(업데이트 게이트)}$$

$$r_t = \sigma\left(W_r [h_{t-1}, x_t] + b_r\right) \quad \text{(리셋 게이트)}$$

$$\tilde{h}_t = \tanh\left(W_h [r_t \odot h_{t-1}, x_t] + b_h\right)$$

$$h_t = (1 - z_t) \odot h_{t-1} + z_t \odot \tilde{h}_t$$

**업데이트 게이트**(update gate) $z_t$는 망각 게이트와 입력 게이트의 역할을 동시에 합니다. 새 상태는 이전 상태와 후보 사이의 보간입니다. $z_t \approx 0$이면 이전 상태가 그대로 앞으로 복사됩니다. LSTM을 돕는 것과 같은 덧셈 경로입니다. **리셋 게이트**(reset gate) $r_t$는 후보를 계산할 때 이전 상태를 얼마나 사용할지 결정합니다. $r_t \approx 0$이면 유닛은 과거를 "잊고" 처음부터 읽기 시작하는 것처럼 동작합니다. (주의하십시오. PyTorch를 포함한 일부 라이브러리는 마지막 식에서 $z_t$와 $1 - z_t$의 역할을 바꿔 씁니다. 모델은 같고 표기 관례만 다릅니다.)

크기는 어떻게 비교될까요? 단순 RNN은 크기 $d_h \times (d_h + d_{in})$인 가중치 블록 하나와 편향을 가지고, GRU는 그런 블록이 세 개, LSTM은 네 개입니다. 코드의 마지막 줄들은 입력 크기 100, 은닉 크기 256일 때(블록마다 편향 벡터 하나) 이 수를 출력합니다. RNN은 91,392개, GRU는 274,176개, LSTM은 365,568개입니다.

무엇을 골라야 할까요? 실험적 비교(예: Chung 등, 2014; Jozefowicz 등, 2015)에 따르면 두 모델 모두 단순 RNN보다 분명히 낫지만, 어느 쪽도 모든 과제에서 이기지는 않습니다. GRU는 더 작고 약간 더 빠르며, LSTM은 조금 더 표현력이 있고 더 흔한 기본 선택이었습니다. 둘 다 제11장에서와 똑같이 여러 층으로 쌓거나 양방향으로 만들 수 있습니다.

## 언어 모델의 역사 속 LSTM

몇 년 동안 게이트가 있는 RNN은 언어를 모델링하는 표준 방법이었습니다. LSTM 언어 모델은 n-그램 모델보다 훨씬 낮은 퍼플렉서티(제4장)를 달성했고, 최초로 성공한 신경망 기계 번역 시스템도 LSTM으로 만들어졌습니다. 이는 제13장에서 보게 됩니다. ELMo(Peters 등, 2018) 같은 문맥적 단어 표현도 깊은 양방향 LSTM에서 나왔습니다.

하지만 게이트는 기억 문제만 해결했습니다. 제11장의 다른 두 문제는 남아 있습니다. 계산은 여전히 순차적입니다. $h_t$에는 $h_{t-1}$이 필요하므로 긴 시퀀스를 병렬로 처리할 수 없습니다. 그리고 과거 전체가 여전히 고정 크기 벡터 하나에 압축됩니다. 다음 두 장에서는 어텐션이 두 번째 한계를 어떻게 없애는지, 그리고 제15장에서는 셀프 어텐션이 첫 번째 한계를 어떻게 없애는지 보여 줍니다.

## 요약

- 게이트는 시그모이드로 만든 $(0, 1)$ 범위 값의 벡터로, 원소별 곱셈을 통해 정보의 흐름을 제어합니다.
- LSTM은 셀 상태 $c_t$를 유지하고 망각·입력·출력 게이트를 사용합니다: $c_t = f_t \odot c_{t-1} + i_t \odot \tilde{c}_t$, $h_t = o_t \odot \tanh(c_t)$.
- 덧셈 형태의 셀 갱신은 기울기에 가중치 행렬이 없는 경로를 제공하므로, 정보가 수백 단계 동안 살아남을 수 있습니다.
- 망각 게이트 편향을 양수로 초기화하면 LSTM이 기본적으로 기억하게 됩니다.
- GRU는 셀 상태와 은닉 상태를 합치고 업데이트 게이트와 리셋 게이트를 사용하며, 파라미터 수는 LSTM의 약 4분의 3입니다.
- 게이트가 있는 RNN은 기억 문제를 고치지만 여전히 순차적이고 과거를 고정 크기 벡터로 압축합니다.

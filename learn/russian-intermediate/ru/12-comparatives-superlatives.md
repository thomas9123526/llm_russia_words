# Урок 12. Сравнительная и превосходная степень (больше, лучше, самый эффективный)

> **Русский язык: средний уровень** · Уровень: B1 · **Вы узнаете:** простую сравнительную степень (быстрее, лучше) и как сравнивать с чем или с родительным падежом · составную сравнительную степень (более эффективный) · превосходную степень (самый точный, лучше всех)

## Диалог

*Семинар. Минхо рассказывает о результатах.*

**Минхо:** На этом слайде вы видите результаты. Наша модель работает быстре́е, чем ба́зовая.
*이 슬라이드에서 결과를 보실 수 있습니다. 저희 모델은 베이스라인보다 빠르게 작동합니다.*

**Анна:** Наско́лько быстрее?
*얼마나 더 빨라요?*

**Минхо:** Приме́рно в два ра́за. И она точне́е старой модели на три проце́нта.
*약 두 배입니다. 그리고 기존 모델보다 3퍼센트 더 정확합니다.*

**Иван Петрович:** А какая модель са́мая точная?
*그럼 가장 정확한 모델은 어느 것인가요?*

**Минхо:** Самая точная — большая модель, но она гора́здо ме́дленнее и доро́же.
*가장 정확한 것은 대형 모델이지만, 훨씬 느리고 비용이 많이 듭니다.*

**Анна:** Значит, ваш метод бо́лее эффекти́вный?
*그러니까 당신 방법이 더 효율적이라는 거죠?*

**Минхо:** Да. Для маленьких данных это самый эффективный метод из тех, которые мы проверили.
*네. 소규모 데이터에서는 저희가 검증한 방법 중 가장 효율적인 방법입니다.*

**Иван Петрович:** Хорошо. Но на русских текстах результаты ху́же, чем на английских. Почему?
*좋아요. 그런데 러시아어 텍스트에서는 결과가 영어보다 나쁘네요. 왜 그렇죠?*

**Минхо:** Потому что русских данных у нас ме́ньше. Чем бо́льше данных, тем лу́чше результат.
*러시아어 데이터가 더 적기 때문입니다. 데이터가 많을수록 결과가 좋아집니다.*

**Иван Петрович:** Это одна из самых важных пробле́м. Попро́буйте собрать больше данных как мо́жно скоре́е.
*그게 가장 중요한 문제 중 하나예요. 되도록 빨리 데이터를 더 모아 보세요.*

**Минхо:** Хорошо, Иван Петрович. Спасибо за сове́т!
*알겠습니다, 교수님. 조언 감사합니다!*

## Грамматика

### 1. Простая сравнительная степень: быстрее, лучше

Простую сравнительную степень (비교급) делаем так: основа прилагательного + **-ее**.

| прилагательное | сравнительная степень |
|---|---|
| бы́стрый | быстре́е |
| но́вый | нове́е |
| то́чный | точне́е |
| сло́жный | сложне́е |
| интере́сный | интере́снее |
| эффекти́вный | эффекти́внее |
| ме́дленный | ме́дленнее |

Три важных правила:
- **Форма не изменяется.** Нет рода, числа и падежа: *модель быстрее, метод быстрее, модели быстрее*.
- **Наречие (부사) — такая же форма:** *быстро → быстрее*. *Модель быстрее* и *модель работает быстрее*.
- **Ударение:** в коротких словах обычно на -е́е (*быстре́е, нове́е, точне́е*). В длинных словах ударение не меняется (*интере́снее, эффекти́внее, ме́дленнее*). В разговоре можно услышать -ей: *быстрей*.

**Особые формы** (불규칙) кончаются на **-е**, согласная меняется. Самые важные нужно выучить:

| прилагательное / наречие | сравнительная степень |
|---|---|
| хоро́ший, хорошо́ | лу́чше |
| плохо́й, пло́хо | ху́же |
| большо́й, мно́го | бо́льше |
| ма́ленький, ма́ло | ме́ньше |
| дорого́й | доро́же |
| дешёвый | деше́вле |
| просто́й | про́ще |
| лёгкий | ле́гче (говорим [ле́хче]) |
| высо́кий | вы́ше |
| ни́зкий | ни́же |
| молодо́й | моло́же |
| ста́рый (о людях) | ста́рше |
| далеко́ | да́льше |
| бли́зко | бли́же |
| ра́но | ра́ньше |
| по́здно | по́зже |
| ча́сто | ча́ще |
| ре́дко | ре́же |
| до́лго | до́льше |
| коро́ткий | коро́че |

### 2. Как сравнивать: чем или родительный падеж

Сказать «~보다» можно двумя способами.

**а) чем + та же форма** (перед чем — запятая):
*Наша модель работает быстрее, чем базовая.*
*Анна говорит по-английски лучше, чем Дима.*
*На русских текстах результаты хуже, чем на английских.*

**б) Родительный падеж без чем** (короче; часто с существительными и местоимениями):
*Наша модель быстрее базовой.*
*Москва больше Казани.*
*Мой брат старше меня.*

Родительный падеж можно, только когда мы сравниваем два существительных или местоимения в именительном падеже. Если сравниваем слова с предлогом (*на русских текстах — на английских*), наречия или части предложения, нужно **чем**.

**Насколько лучше?**
- *гораздо, намного* — 훨씬: *гораздо медленнее, намного лучше*
- *немного, чуть* — 조금: *немного дороже*
- *ещё* — 더욱: *ещё быстрее*
- **на + винительный падеж** — разница (차이): *на три процента точнее; на два года старше*
- **в … раза** — 배: *в два раза быстрее; в три раза больше*

**Чем …, тем …** (~할수록 더 ~하다):
*Чем больше данных, тем лучше результат.*
*Чем больше модель, тем дольше обучение.*

### 3. Составная сравнительная степень: более эффективный

Второй способ: **более** (더) или **менее** (덜) + полное прилагательное. Прилагательное **изменяется** по падежам. Поэтому эту форму говорим **перед существительным** и в любом падеже:

*Нам нужен более эффективный метод.*
*Минхо работает с более современной моделью.*
*Это менее сложная задача.*

После существительного можно сказать и так, и так: *Этот метод эффективнее* = *Этот метод более эффективный*. В разговоре чаще простая форма, в научных текстах — составная.

Нельзя смешивать (섞다) две формы: ~~более лучше~~, ~~более быстрее~~. Говорите *лучше* или *лучший*.

**лучший, худший** — это прилагательные, они изменяются: *лучший результат* (최고의 결과), *в худшем случае* (최악의 경우).

### 4. Превосходная степень: самый точный

**самый + прилагательное** = «가장 ~한». Оба слова изменяются вместе:
*Это самая точная модель.*
*Минхо живёт в самом старом общежитии.*
*Мы говорили о самой новой модели.*

**«Один из самых…»** (가장 ~한 것 중 하나) = **один (одна, одно) из самых + родительный падеж мн. ч.**:
*Это одна из самых важных проблем.*
*BERT — одна из самых известных моделей.*

**«Из тех…»** (~중에서): *самый эффективный метод из тех, которые мы проверили.*

**Сравнительная степень + всех / всего** — превосходная степень для наречий:
- **всех** (все люди): *Анна знает Python лучше всех.* (제일 잘한다)
- **всего** (все вещи): *Больше всего я люблю читать.* (제일 좋아한다)

**как можно + сравнительная степень** (가능한 한): *как можно скорее; как можно больше данных*.

В научных текстах есть книжная (문어체) форма на **-ейший / -айший**: *важнейший, новейший, крупнейший*. Её нужно понимать. А в речи лучше говорить *самый*.

## Совет

**Как сравнивать результаты в статье или в докладе.** Эти фразы помогут описать таблицы и графики (표와 그래프):
- *Модель А работает лучше, чем модель Б.*
- *по сравнению с базовой моделью* (베이스라인 모델과 비교하여; по сравнению с + твор. п.)
- *точность выше на 3 %* (читаем: *на три процента*)
- *в два раза быстрее*
- *лучший результат*
Напишите одно такое предложение о своей работе и скажите его вслух (소리 내어) несколько раз.

## Ответы

**Упражнение 1.** 1. быстрее 2. новее 3. интереснее 4. лучше 5. хуже 6. больше 7. меньше 8. дороже 9. проще 10. легче

**Упражнение 2.** 1. Анна говорит по-английски лучше Димы. 2. Москва больше Казани. 3. Новый метод проще старого. 4. Мой брат старше меня. 5. Эта статья интереснее той статьи.

**Упражнение 3.** 1. более эффективный 2. более простое 3. более современной 4. более сложной 5. более интересные

**Упражнение 4.** 1. самая большая 2. самом старом 3. самой новой 4. самых популярных 5. самого умного

**Упражнение 5.** 1. Русский язык труднее (сложнее), чем английский. (можно: …труднее английского.) 2. Анна говорит по-русски лучше меня. (можно: …лучше, чем я.) 3. Это самый эффективный метод. 4. Новая модель гораздо (намного) быстрее. 5. Чем больше данных, тем лучше. 6. Приходите как можно скорее.

**Упражнение 6.** 1. Примерно в два раза. 2. На три процента. 3. Большая модель. 4. Потому что русских данных меньше. 5. Собрать больше данных как можно скорее.

**Упражнение 7.** 1. всех 2. всего 3. всех 4. всего

## Повторение

- Вы можете сравнивать: *Наша модель быстрее базовой. Анна говорит по-английски лучше, чем Дима.*
- Вы можете сказать, насколько: *в два раза быстрее, на три процента точнее, гораздо дороже.*
- Вы можете сказать составную форму перед существительным: *Нам нужен более эффективный метод.*
- Вы можете сказать о самом лучшем: *самая точная модель, одна из самых важных проблем, лучше всех.*
- Вы можете сказать «чем больше, тем лучше»: *Чем больше данных, тем лучше результат.*
- Вы можете рассказать о результатах эксперимента на семинаре.

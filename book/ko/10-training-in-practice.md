## 답을 외운 학생

풀이가 달린 문제 200개가 실린 책으로 시험을 준비하는 학생을 떠올려 보십시오. 한 학생은 풀이 방법을 이해하고, 다른 학생은 모든 답을 통째로 외웁니다. 연습 문제에서는 둘 다 100점을 받습니다. 하지만 새로운 문제가 나오는 실제 시험에서는 첫 번째 학생만 성공합니다.

신경망은 두 학생 중 어느 쪽도 될 수 있습니다. 매개변수가 많은 신경망은 잡음과 우연한 특징까지 포함해 학습 데이터를 그냥 외워 버린 뒤, 새로운 입력에서는 실패할 수 있습니다. 이것이 머신러닝의 핵심적인 실전 문제입니다. 우리가 진정으로 원하는 것은 **일반화**(generalization), 즉 모델이 한 번도 보지 못한 데이터에서도 좋은 성능을 내는 것입니다. 제8장과 제9장에서는 학습 손실을 작게 만드는 방법을 배웠습니다. 이 장은 학습의 실전적인 측면을 다룹니다. 데이터를 효율적으로 공급하는 방법, 암기를 알아차리는 방법, 그리고 암기를 막는 방법입니다.

## 배치, 반복, 에포크

제8장의 손실은 학습 데이터 *전체*에 대한 평균이었습니다. 그 정확한 그래디언트를 계산하려면 스텝 하나를 밟기 전에 모든 예제를 신경망에 통과시켜야 합니다. 문서가 수백만 개인 데이터셋에서는 너무 느립니다.

대신 우리는 예제의 작은 무작위 묶음에서 그래디언트를 추정합니다. 이 묶음을 **미니배치**(mini-batch)라고 하며, 흔히 그냥 **배치**(batch)라고도 부릅니다. 배치 $B$에 예제가 $|B|$개 있다면 추정값은 다음과 같습니다.

$$\mathbf{g}_B = \frac{1}{|B|} \sum_{i \in B} \nabla_\theta\, \ell(f_\theta(x_i),\ y_i).$$

평균적으로 $\mathbf{g}_B$는 진짜 그래디언트와 같지만, 개별 추정값에는 잡음이 있습니다. 확률적 경사 하강법(제9장)의 "확률적"이라는 말이 바로 이것을 뜻합니다. 잡음은 단점만은 아닙니다. 매개변수를 조금씩 흔들어서 나쁜 평평한 영역을 빠져나오는 데 도움이 될 수 있습니다.

학습의 진행을 나타내는 세 용어가 있습니다.
- **배치 크기**(batch size)는 미니배치 하나에 들어 있는 예제의 수입니다.
- **반복**(iteration) 한 번, 즉 스텝 한 번은 미니배치 하나로 계산한 매개변수 갱신 한 번입니다.
- **에포크**(epoch) 하나는 학습 데이터 전체를 한 번 다 도는 것입니다.

예를 들어 학습 예제가 10,000개이고 배치 크기가 32라면, 한 에포크에는 $\lceil 10000 / 32 \rceil = 313$번의 반복이 있습니다(마지막 배치는 더 작습니다). 각 에포크 전에는 데이터를 **섞어서**(shuffle) 에포크마다 배치 구성이 달라지게 합니다.

배치는 얼마나 커야 할까요? 배치가 크면 그래디언트의 잡음이 줄고 GPU 같은 병렬 하드웨어를 효율적으로 쓸 수 있지만, 스텝마다 메모리가 더 많이 들고, 어느 크기를 넘어서면 정밀도가 높아져도 이득이 없어집니다. 배치가 작으면 잡음이 크지만 같은 계산량으로 더 많이 갱신할 수 있습니다. 배치 크기를 바꾸면 보통 학습률도 다시 조정해야 합니다. 언어 모델에서는 배치 크기를 보통 문장이 아니라 *토큰* 수로 세며, 큰 모델은 거대한 학습 데이터의 대부분을 한 번 또는 몇 번만 보는 경우가 많으므로 에포크라는 개념이 덜 중요합니다(제27장).

## 일반화: 훈련, 검증, 테스트 데이터셋

일반화를 측정하려면 모델이 학습에 사용하지 않은 데이터로 평가해야 합니다. 표준적인 방법은 데이터를 세 부분으로 나누는 것입니다.
- **훈련 데이터셋**(training set): 그래디언트를 계산하고 매개변수를 갱신하는 데 사용합니다.
- **검증 데이터셋**(validation set, 개발 데이터셋이라고도 함): 모델을 비교하고, 학습률 같은 하이퍼파라미터를 고르고, 학습을 언제 멈출지 정하는 데 사용합니다.
- **테스트 데이터셋**(test set): 마지막에 단 한 번 사용해 최종 품질을 보고합니다.

왜 두 부분이 아니라 세 부분일까요? 검증 점수를 보고 무언가를 고를 때마다 우리는 검증 데이터에 모델을 조금씩 맞추게 됩니다. 이런 선택이 쌓이면 검증 점수는 지나치게 낙관적이 됩니다. 테스트 데이터셋은 손대지 않은 채로 남아 있으므로 정직한 추정을 줍니다. 제39장에서는 같은 문제를 현대적인 형태로 보게 됩니다. 공개 벤치마크의 테스트 데이터가 언어 모델의 학습 데이터에 섞여 들어갈 수 있다는 문제입니다.

훈련 손실과 검증 손실을 비교하면 서로 반대되는 두 가지 문제를 진단할 수 있습니다.
- **과소적합**(underfitting): 두 손실이 모두 높습니다. 모델이 너무 단순하거나 충분히 오래 학습하지 않았습니다. 훈련 데이터조차 맞추지 못합니다.
- **과적합**(overfitting): 훈련 손실은 낮지만 검증 손실은 훨씬 높으며, 훈련 손실이 계속 떨어지는 동안 검증 손실은 오히려 *올라가는* 경우가 많습니다. 모델이 훈련 데이터를 외우고 있는 것입니다.

고전적인 예는 다항식 맞추기입니다. 곡선 $y = \sin 3x$에서 잡음이 섞인 점 15개를 뽑아, 계수가 13개(점의 개수와 거의 같음)인 12차 다항식을 맞춥니다. 계수의 크기에 대한 벌점 $\lambda \|\mathbf{w}\|^2$(다음 절에서 설명)을 더하고, $\lambda$ 값에 따라 무슨 일이 일어나는지 봅시다.

```python
import numpy as np

rng = np.random.default_rng(0)
x = np.sort(rng.uniform(-1, 1, 15))              # 훈련 점 15개
y = np.sin(3 * x) + 0.2 * rng.normal(size=15)    # 잡음이 섞인 목표값
xv = rng.uniform(-1, 1, 100)                     # 검증 점 100개
yv = np.sin(3 * xv) + 0.2 * rng.normal(size=100)

def poly(x):                                     # 특징 1, x, x^2, ..., x^12
    return np.vander(x, 13, increasing=True)

A, Av = poly(x), poly(xv)
for lam in [0.0, 1e-3, 1e-1, 10.0]:              # L2 벌점의 세기
    # ||A w - y||^2 + lam * ||w||^2 를 최소화 (릿지 회귀의 닫힌 해)
    w = np.linalg.solve(A.T @ A + lam * np.eye(13), A.T @ y)
    train = np.mean((A @ w - y) ** 2)
    val = np.mean((Av @ w - yv) ** 2)
    print(f"lambda={lam:<6} train {train:.3f}  val {val:.3f}  |w| {np.linalg.norm(w):.1f}")
```

벌점이 없으면 훈련 오차는 거의 0(약 0.001)이지만 검증 오차는 엄청나게 크고(수십), 계수 벡터의 노름은 만을 넘습니다. 곡선이 잡음 섞인 모든 점을 지나가면서 점과 점 사이에서 크게 요동치는 것입니다. $\lambda = 0.001$이면 훈련 오차는 조금 높아지지만(약 0.009) 검증 오차는 약 0.14로 떨어집니다. $\lambda = 10$이면 모델이 지나치게 단순해지도록 강제되어 과소적합이 일어나고, 두 오차가 모두 높습니다(약 0.2와 0.46). 좋은 일반화는 두 극단 사이에 있습니다.

## 정규화: 가중치 감쇠, 드롭아웃, 조기 종료

모델을 단순히 작게 만들지 않으면서 과적합을 줄이는 모든 기법을 **정규화**(regularization, 규제라고도 함)라고 합니다. 어디서나 쓰이는 기법이 네 가지 있습니다.

**가중치 감쇠(L2 정규화).** 큰 가중치에 대한 벌점을 손실에 더합니다.

$$L_{\text{total}}(\theta) = L(\theta) + \frac{\lambda}{2}\, \|\theta\|^2.$$

여기서 $\lambda \ge 0$은 벌점의 세기이고, $\|\theta\|^2$은 모든 가중치의 제곱합입니다. 벌점의 그래디언트는 $\lambda \theta$이므로 경사 하강법의 한 스텝은 다음과 같아집니다.

$$\theta \leftarrow \theta - \eta(\nabla L + \lambda\theta) = (1 - \eta\lambda)\,\theta - \eta\, \nabla L.$$

매 스텝 전에 가중치에 1보다 조금 작은 수가 곱해집니다. 데이터가 계속 밀어 주지 않으면 가중치는 0을 향해 "감쇠"합니다. 이것이 **가중치 감쇠**(weight decay)입니다. 작은 가중치는 더 매끄러운 함수를 만드는데, 다항식 예제에서 본 것이 바로 이것입니다. Adam에서는 그래디언트에 $\lambda\theta$를 더하는 방식이 잘 작동하지 않습니다. Adam이 그래디언트의 크기를 다시 조정하기 때문입니다. **AdamW**(로실로프(Loshchilov)와 후터(Hutter))는 대신 적응적 스텝과 별도로 가중치에 직접 감쇠를 적용합니다. 이렇게 "분리된" 가중치 감쇠가 트랜스포머의 표준 선택입니다.

**드롭아웃**(dropout). 학습 중에 층의 각 활성화 값을 확률 $p$(예: $p = 0.1$)로, 매 스텝 독립적으로 0으로 만들고, 살아남은 활성화 값에는 $1/(1 - p)$를 곱해 기댓값이 변하지 않게 합니다. 어떤 뉴런이든 사라질 수 있으므로 신경망은 특정 뉴런 하나에 의존할 수 없고, 그래서 중복된, 더 견고한 특징을 학습합니다. 평가할 때는 드롭아웃을 끕니다. PyTorch에서는 `model.train()`과 `model.eval()`로 두 모드를 전환하며, `model.eval()`을 잊는 것은 고전적인 버그입니다.

**조기 종료**(early stopping). 학습 중에 검증 손실을 정기적으로 측정하고, 검증 손실이 가장 좋았던 매개변수를 기억해 두었다가, 한동안 개선되지 않으면 학습을 멈춥니다. 이 기다리는 기간을 **인내**(patience)라고 합니다. 과적합은 보통 학습 시간이 길어질수록 커지기 때문에, 이 단순한 방법은 매우 효과적입니다.

**더 많은 데이터와 데이터 증강.** 과적합에 대한 가장 확실한 처방은 더 많은 데이터입니다. 새 데이터를 얻기 어렵다면 기존 예제를 변형한 복사본을 만들 수 있는데, 이를 **데이터 증강**(data augmentation)이라고 합니다. 이미지에서는 약간의 회전이나 잘라 내기, 텍스트에서는 예를 들어 바꿔 쓰기나 역번역을 사용합니다. 대규모 언어 모델은 학습 데이터가 매우 커서 고전적인 과적합이 덜 문제가 되지만, 반복된 데이터와 암기된 테스트 데이터는 여전히 중요합니다(제26장과 제39장).

## 완전한 학습 루프

아래 코드는 지금까지의 모든 것을 하나로 모읍니다. 훈련 데이터셋과 별도의 검증 데이터셋, 섞기가 적용된 미니배치, 가중치 감쇠가 있는 AdamW 옵티마이저, 드롭아웃, 조기 종료가 들어 있습니다. 모델은 잡음 섞인 훈련 점 20개에 비해 일부러 너무 크게 만들었습니다.

```python
import copy, torch, torch.nn as nn
from torch.utils.data import TensorDataset, DataLoader

torch.manual_seed(1)
X = torch.rand(220, 1) * 6 - 3                     # [-3, 3] 구간의 입력
Y = torch.sin(X) + 0.3 * torch.randn_like(X)       # 잡음 섞인 사인파
train = DataLoader(TensorDataset(X[:20], Y[:20]), batch_size=5, shuffle=True)
Xva, Yva = X[20:], Y[20:]                          # 검증 점 200개

model = nn.Sequential(nn.Linear(1, 256), nn.ReLU(), nn.Dropout(0.1),
                      nn.Linear(256, 256), nn.ReLU(), nn.Linear(256, 1))
opt = torch.optim.AdamW(model.parameters(), lr=3e-3, weight_decay=0.01)
best, best_epoch, patience = float("inf"), 0, 50

for epoch in range(1, 1001):
    model.train()                                  # 드롭아웃 켜기
    for xb, yb in train:                           # 스텝마다 미니배치 하나
        loss = nn.functional.mse_loss(model(xb), yb)
        opt.zero_grad(); loss.backward(); opt.step()
    model.eval()                                   # 드롭아웃 끄기
    with torch.no_grad():
        val = nn.functional.mse_loss(model(Xva), Yva).item()
    if val < best:                                 # 가장 좋은 모델을 기억
        best, best_epoch = val, epoch
        best_state = copy.deepcopy(model.state_dict())
    elif epoch - best_epoch >= patience:           # 조기 종료
        break

model.load_state_dict(best_state)
print(f"stopped at epoch {epoch}, best epoch {best_epoch}, val MSE {best:.3f}")
```

이 시드에서는 가장 좋은 검증 손실이 아주 일찍(10번째 에포크 무렵) 나옵니다. 그 뒤로는 훈련 손실이 계속 떨어지는 동안 검증 손실이 천천히 올라가므로, 50 에포크 뒤에 학습이 멈추고 가장 좋았던 매개변수가 복원됩니다. 목표값에 섞인 잡음의 분산은 $0.3^2 = 0.09$이므로, 어떤 모델도 검증 MSE를 0.09보다 크게 낮출 수는 없습니다.

거의 모든 실제 학습에 등장하는 도구가 두 가지 더 있으며, 이 책의 뒷부분에서 사용합니다. **학습률 스케줄**(learning rate schedule)은 학습 도중 $\eta$를 바꿉니다. 보통 $\eta$를 0 근처에서 키워 나가는 짧은 **웜업**(warmup) 뒤에, 예를 들어 코사인 곡선을 따라 천천히 줄입니다. **그래디언트 클리핑**(gradient clipping)은 그래디언트의 노름이 임계값 $c$를 넘을 때마다 $\mathbf{g} \leftarrow \mathbf{g} \cdot c / \|\mathbf{g}\|$로 크기를 줄여 기울기 폭발(제9장)을 막습니다. PyTorch에서는 `torch.nn.utils.clip_grad_norm_`입니다. 마지막으로 실전 습관 하나를 소개합니다. 새 모델을 전체 데이터로 학습시키기 전에, 작은 배치 하나에 거의 완벽하게 과적합할 수 있는지 확인하십시오. 그렇게 하지 못한다면 버그가 있는 것입니다.

## 요약
- 그래디언트는 무작위 미니배치에서 추정합니다. 반복은 갱신 한 번이고, 에포크는 훈련 데이터셋을 한 번 다 도는 것입니다.
- 일반화는 학습에 쓰지 않은 데이터로 측정합니다. 검증 데이터셋은 결정을 이끌고, 테스트 데이터셋은 최종적인 정직한 점수를 줍니다.
- 과소적합은 훈련 손실과 검증 손실이 모두 높은 상태이고, 과적합은 훈련 손실은 낮지만 검증 손실이 훨씬 높은 상태입니다.
- 가중치 감쇠는 매 스텝 가중치를 줄이며, AdamW는 이를 Adam의 적응적 스텝과 분리해 적용합니다.
- 드롭아웃은 학습 중에만 활성화 값을 무작위로 제거하고, 조기 종료는 검증 손실이 가장 좋았던 매개변수를 남깁니다.
- 학습률 웜업과 감소, 그래디언트 클리핑은 실제 학습을 안정적으로 만듭니다.

## 연습 문제
1. 검증 데이터셋과 테스트 데이터셋의 차이, 그리고 테스트 데이터셋으로 하이퍼파라미터를 고르는 것이 왜 잘못인지 자신의 말로 설명해 보십시오.
2. 데이터셋에 예제가 50,000개 있습니다. 배치 크기가 64라면 한 에포크에는 반복이 몇 번 있습니까? 10 에포크에는 몇 번입니까?
3. 가중치 감쇠를 쓰면 한 스텝마다 가중치에 $(1 - \eta\lambda)$가 곱해집니다. $\eta = 0.01$, $\lambda = 0.1$이고 손실의 그래디언트가 0이라면, 1,000 스텝 후 가중치는 몇 배로 줄어듭니까? (힌트: $(1 - a)^n \approx e^{-an}$.)
4. 학습 루프에서 드롭아웃을 없애고 `weight_decay=0.0`으로 설정한 뒤, 학습이 일찍 멈추지 않도록 `patience`를 1000으로 바꾸어 보십시오. 100 에포크마다 훈련 손실과 검증 손실을 출력하고 곡선의 모양을 설명해 보십시오.

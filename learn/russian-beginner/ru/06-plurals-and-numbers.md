# Урок 6. Множественное число; числа от 0 до 20

> **«Русский язык для начинающих»** · Уровень: A1 · **Вы узнаете:** множественное число (복수형): то́кен → то́кены, моде́ль → моде́ли · особые (특별한) формы · числа от 0 до 20 и номер телефона

В уроке 5 вы узнали род (성). Сегодня — **много** (여러 개): **кни́ги**, **статьи́**, **моде́ли**. Это **множественное число** (복수형). Окончаний (어미) мало, и род помогает (도와줍니다). И ещё числа (숫자) от 0 до 20.

В диалоге Дима и Минхо в комнате в общежитии (기숙사). У Минхо много книг!

## Диалог

**Ди́ма:** Ого́! Что э́то? Кни́ги?  
Ogó! Chto éto? Knígi?  
*우와! 이게 뭐야? 책이야?*

**Минхо́:** Да, э́то кни́ги и словари́.  
Da, éto knígi i slovarí.  
*응, 책하고 사전이야.*

**Ди́ма:** Оди́н, два, три… двена́дцать! Ты библиоте́ка?  
Odín, dva, tri… dvenádtsat'! Ty bibliotéka?  
*하나, 둘, 셋… 열둘! 너 도서관이야?*

**Минхо́:** Нет, я аспира́нт.  
Net, ya aspiránt.  
*아니, 대학원생이야.*

**Ди́ма:** А э́то? Журна́лы?  
A éto? Zhurnály?  
*그럼 이건? 잡지야?*

**Минхо́:** Нет, э́то статьи́. Они́ по-англи́йски.  
Net, éto stat'í. Oní po-anglíyski.  
*아니, 논문이야. 영어로 된 거야.*

**Ди́ма:** А там? Ноутбу́ки?  
A tam? Noutbúki?  
*저기는? 노트북이야?*

**Минхо́:** Да. Тут моде́ли и да́нные.  
Da. Tut modéli i dánnye.  
*응. 여기에 모델하고 데이터가 있어.*

**Ди́ма:** Поня́тно. А телефо́н?  
Ponyátno. A telefón?  
*그렇구나. 전화번호는?*

**Минхо́:** Во́семь, де́вять, оди́н, шесть, три, ноль, пять, два, четы́ре, семь, во́семь.  
Vósem', dévyat', odín, shest', tri, nol', pyat', dva, chetýre, sem', vósem'.  
*8-916-305-24-78.*

**Ди́ма:** Спаси́бо!  
Spasíbo!  
*고마워!*

## Грамматика

### 1. Множественное число

Сегодня — основная форма слова (기본형), как в словаре (사전에서). Это **именительный падеж** (주격). Окончания: **-ы**, **-и**, **-а**, **-я**.

| Один | Много | Примеры |
|---|---|---|
| согласный (м.) | **+ы** | студе́нт → студе́нты, то́кен → то́кены, журна́л → журна́лы |
| **-а** (ж.) | **-а → -ы** | ла́мпа → ла́мпы, ко́мната → ко́мнаты, програ́мма → програ́ммы |
| **-й** (м.) | **-й → -и** | музе́й → музе́и, трамва́й → трамва́и |
| **-ь** (м., ж.) | **-ь → -и** | моде́ль → моде́ли, нейросе́ть → нейросе́ти, слова́рь → словари́ |
| **-я** (ж.) | **-я → -и** | статья́ → статьи́, неде́ля → неде́ли |
| **-о** (ср.) | **-о → -а** | окно́ → о́кна, письмо́ → пи́сьма, сло́во → слова́ |
| **-е** (ср.) | **-е → -я** | мо́ре → моря́, зада́ние → зада́ния |

М. и ж. → **-ы / -и**. Ср. → **-а / -я**.

**Правило: г, к, х, ж, ш, щ, ч.** После этих букв мы не пишем **ы**. Мы пишем **и**:

| | |
|---|---|
| кни́га → кни́ги | ноутбу́к → ноутбу́ки |
| ру́чка → ру́чки | каранда́ш → карандаши́ |
| ша́пка → ша́пки | язы́к → языки́ |

**Ударение может меняться** (바뀔 수 있습니다): **окно́ → о́кна**, **письмо́ → пи́сьма**, **сло́во → слова́**, **мо́ре → моря́**, **стол → столы́**, **слова́рь → словари́**, **язы́к → языки́**. Но часто (자주) ударение то же: **то́кен → то́кены**, **моде́ль → моде́ли**.

- Э́то студе́нт. — Э́то студе́нты. — *학생이에요. — 학생들이에요.*
- Э́то то́кен. — Э́то то́кены. — *토큰이에요. — 토큰들이에요.*
- Где статья́? — Где статьи́? — *논문은 어디 있어요? — 논문들은 어디 있어요?*
- Тут моде́ли и да́нные. — *여기에 모델들과 데이터가 있어요.*
- Там о́кна. — *저기에 창문들이 있어요.*

### 2. Особые формы

| Один | Много | 한국어 |
|---|---|---|
| челове́к | **лю́ди** | 사람 — 사람들 |
| ребёнок | **де́ти** | 아이 — 아이들 |
| друг | **друзья́** | 친구 — 친구들 |
| брат | **бра́тья** | 형제 — 형제들 |
| дом | **дома́** | 집 — 집들 |
| го́род | **города́** | 도시 — 도시들 |
| профе́ссор | **профессора́** | 교수 — 교수들 |

- **Метро́**, **кафе́**, **ра́дио** — не меняются.
- Только множественное число: **да́нные** (데이터), **де́ньги** (돈), **очки́** (안경).

Много — это **они́**. **Э́то** не меняется.

- Где кни́ги? — Вот они́. — *책들은 어디 있어요? — 여기 있어요.*
- Где да́нные? — Вот они́. — *데이터는 어디 있어요? — 여기 있어요.*
- Кто э́то? — Э́то друзья́. — *이 사람들은 누구예요? — 친구들이에요.*
- Э́то профессора́, а э́то аспира́нты. — *이분들은 교수님들이고, 이 사람들은 대학원생들이에요.*
- А́нна и Ди́ма — студе́нты? — Нет, они́ аспира́нты. — *안나와 디마는 학생이에요? — 아니요, 대학원생이에요.*

### 3. Числа от 0 до 20

| | Число | Произношение | | Число | Произношение |
|---|---|---|---|---|---|
| 0 | ноль | nol' | 11 | оди́ннадцать | odínnadtsat' |
| 1 | оди́н | odín | 12 | двена́дцать | dvenádtsat' |
| 2 | два | dva | 13 | трина́дцать | trinádtsat' |
| 3 | три | tri | 14 | четы́рнадцать | chetýrnadtsat' |
| 4 | четы́ре | chetýre | 15 | пятна́дцать | pyatnádtsat' |
| 5 | пять | pyat' | 16 | шестна́дцать | shestnádtsat' |
| 6 | шесть | shest' | 17 | семна́дцать | semnádtsat' |
| 7 | семь | sem' | 18 | восемна́дцать | vosemnádtsat' |
| 8 | во́семь | vósem' | 19 | девятна́дцать | devyatnádtsat' |
| 9 | де́вять | dévyat' | 20 | два́дцать | dvádtsat' |
| 10 | де́сять | désyat' | | | |

**11–19:** число + **на** + **дцать** (= де́сять). **Оди́н + на + дцать = оди́ннадцать** (два **н**!). **Пять → пятна́дцать** (нет **ь**). Ударение на **-на́-**, но: **оди́ннадцать**, **четы́рнадцать**.

**Произношение:** **-дцать** = [tsat']: **два́дцать** [dvátsat']. **Шестна́дцать** — **т** не читаем: [shysnátsat'].

**Оди́н, одна́, одно́** — по роду: **оди́н стол** (м.), **одна́ кни́га** (ж.), **одно́ окно́** (ср.). После 2, 3, 4… слово меняется. Это уроки 13 и 16. Сейчас — только числа: номер телефона, номер комнаты.

**Плюс, ми́нус.** Вопрос: **Ско́лько бу́дет…?** (…은 얼마예요?)

- Ско́лько бу́дет два плюс три? — Пять. — *2 더하기 3은 얼마예요? — 5예요.*
- Де́сять плюс де́сять — два́дцать. — *10 더하기 10은 20이에요.*
- Пятна́дцать ми́нус шесть — де́вять. — *15 빼기 6은 9예요.*
- Ко́мната но́мер семна́дцать. — *17호실.*
- Оди́н стол, одна́ ру́чка, одно́ письмо́. — *책상 하나, 펜 하나, 편지 하나.*

### 4. И, а, не… а…

- **и** — просто (그냥) вместе: **кни́ги и словари́**.
- **а** — контраст (대조): **Тут кни́ги, а там статьи́.**
- **не… а…** — исправляем (바로잡습니다): **Э́то не журна́лы, а статьи́.** (잡지가 아니라 논문이에요.)

Вопросы **Что э́то? Кто э́то?** не меняются: **Кто э́то? — Э́то студе́нты.**

- Тут кни́ги, а там статьи́. — *여기는 책이고, 저기는 논문이에요.*
- Э́то не журна́лы, а статьи́. — *이건 잡지가 아니라 논문이에요.*
- Э́то не студе́нты, а аспира́нты. — *이 사람들은 학생이 아니라 대학원생이에요.*
- Кто э́то? — Э́то друзья́: А́нна и Ди́ма. — *이 사람들은 누구예요? — 친구들이에요. 안나하고 디마요.*

## Культура

**Номер телефона.** В России в номере 11 цифр (숫자): 8-916-305-24-78. Русские говорят группами (묶어서): *916*, *305*, *24*, *78* — это урок 13. Сейчас можно говорить по одной цифре, как Минхо. Учите свой номер!

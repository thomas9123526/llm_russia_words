# 제6과. 명사의 복수형; 숫자 0–20

> **초급 러시아어** · 수준: A1 · **배울 내용:** 명사의 복수형 만들기: то́кен → то́кены, моде́ль → моде́ли · 자주 쓰는 불규칙 복수형 · 숫자 0~20과 전화번호 말하기

5과에서 모든 명사에 성이 있다는 것을 배웠습니다. 오늘은 **둘 이상**의 사물에 대해 말하는 법을 배웁니다: **кни́ги**(책들), **статьи́**(논문들), **моде́ли**(모델들). 러시아어 복수형은 몇 개의 어미만으로 만들며, 이미 알고 있는 명사의 성이 어떤 어미를 쓸지 알려 줍니다. 또 0부터 20까지의 숫자도 배웁니다. 전화번호, 방 번호, 간단한 계산에 충분합니다.

**한국어 화자를 위한 팁.** 한국어에서는 '책'이라고만 해도 여러 권을 뜻할 수 있고, '-들'은 자주 생략합니다. 하지만 러시아어에서는 둘 이상이면 **반드시** 복수형을 써야 합니다. **Э́то кни́га**는 '책 한 권', **Э́то кни́ги**는 '책들(여러 권)'입니다.

대화에서 디마는 기숙사 방에서 민호의 짐 정리를 도와주다가, 민호가 가져온 책이 너무 많아서 놀랍니다.

Spasíbo!  
*고마워!*

## 문법

### 1. 명사의 복수형

이번 과에서는 사전에 실린 기본형(**주격** — 나중에 이 용어를 다시 만납니다)의 복수형을 배웁니다. 어미는 **-ы**, **-и**, **-а**, **-я** 네 가지뿐입니다.

| 단수의 끝 | 복수 | 예 |
|---|---|---|
| 자음 (남성) | **+ы** | студе́нт → студе́нты, то́кен → то́кены, журна́л → журна́лы |
| **-а** (여성) | **-а → -ы** | ла́мпа → ла́мпы, ко́мната → ко́мнаты, програ́мма → програ́ммы |
| **-й** (남성) | **-й → -и** | музе́й → музе́и, трамва́й → трамва́и |
| **-ь** (남성/여성) | **-ь → -и** | моде́ль → моде́ли, нейросе́ть → нейросе́ти, слова́рь → словари́ |
| **-я** (여성) | **-я → -и** | статья́ → статьи́, неде́ля → неде́ли |
| **-о** (중성) | **-о → -а** | окно́ → о́кна, письмо́ → пи́сьма, сло́во → слова́ |
| **-е** (중성) | **-е → -я** | мо́ре → моря́, зада́ние → зада́ния |

즉 남성·여성 명사는 **-ы / -и**, 중성 명사는 **-а / -я**를 붙입니다. 쉽게 외우는 방법: '단단한' 끝(자음, **-а**)은 **-ы**로, '부드러운' 끝(**-й, -ь, -я**)은 **-и**로 갑니다. 2과에서 배운 모음 짝(ы/и)과 같은 원리입니다.

**철자 규칙 (г, к, х, ж, ш, щ, ч).** 이 일곱 글자 뒤에는 절대 **ы**를 쓰지 않고 **и**를 씁니다. 그래서 이 글자들로 끝나거나 **-га, -ка, -ха, -жа, -ша, -ча, -ща**로 끝나는 명사는 **-и**를 붙입니다.

| | |
|---|---|
| кни́га → кни́ги | ноутбу́к → ноутбу́ки |
| ру́чка → ру́чки | каранда́ш → карандаши́ |
| ша́пка → ша́пки | язы́к → языки́ |

이 규칙은 앞으로 계속 나오니 일곱 글자 **г к х ж ш щ ч**를 지금 외워 두세요.

**복수형에서 강세가 이동하기도 합니다.** 다시 보세요: **окно́ → о́кна**, **письмо́ → пи́сьма**, **сло́во → слова́**, **мо́ре → моря́**, **стол → столы́**, **слова́рь → словари́**, **язы́к → языки́**. 간단한 규칙이 없으니 나올 때마다 외우세요. 대부분의 명사는 강세가 그대로입니다: **то́кен → то́кены**, **моде́ль → моде́ли**, **кни́га → кни́ги**.

- Э́то студе́нт. — Э́то студе́нты. — *학생이에요. — 학생들이에요.*
- Э́то то́кен. — Э́то то́кены. — *토큰이에요. — 토큰들이에요.*
- Где статья́? — Где статьи́? — *논문은 어디 있어요? — 논문들은 어디 있어요?*
- Тут моде́ли и да́нные. — *여기에 모델들과 데이터가 있어요.*
- Там о́кна. — *저기에 창문들이 있어요.*

### 2. 불규칙 복수형과 유용한 두 가지 사실

아주 자주 쓰는 몇몇 명사는 불규칙 복수형을 가집니다. 짝으로 외우세요.

| 단수 | 복수 | |
|---|---|---|
| челове́к | **лю́ди** | 사람 — 사람들 |
| ребёнок | **де́ти** | 아이 — 아이들 |
| друг | **друзья́** | 친구 — 친구들 |
| брат | **бра́тья** | 형제 — 형제들 |
| дом | **дома́** | 집 — 집들 |
| го́род | **города́** | 도시 — 도시들 |
| профе́ссор | **профессора́** | 교수 — 교수들 |

두 가지 사실을 더 기억하세요.

- **-о, -е, -и, -у로 끝나는 외래어**는 변하지 않습니다: **метро́**, **кафе́**, **ра́дио**는 복수형도 같습니다.
- **복수형으로만 쓰는** 명사도 있습니다. 여러분에게 가장 중요한 것은 **да́нные**(데이터)입니다. 그 밖에 **де́ньги**(돈), **очки́**(안경)도 있습니다. 한국어 '안경'은 하나지만 러시아어로는 렌즈가 두 개라서 복수라고 생각하면 쉽습니다.

**복수형의 대명사와 э́то.** 복수 명사는 사람이든 물건이든 모두 **они́**(그들, 그것들)로 받습니다. **Э́то**는 변하지 않습니다. '이것들은 ~이다'도 그냥 **э́то**입니다.

- Где кни́ги? — Вот они́. — *책들은 어디 있어요? — 여기 있어요.*
- Где да́нные? — Вот они́. — *데이터는 어디 있어요? — 여기 있어요.*
- Кто э́то? — Э́то друзья́. — *이 사람들은 누구예요? — 친구들이에요.*
- Э́то профессора́, а э́то аспира́нты. — *이분들은 교수님들이고, 이 사람들은 대학원생들이에요.*
- А́нна и Ди́ма — студе́нты? — Нет, они́ аспира́нты. — *안나와 디마는 학생이에요? — 아니요, 대학원생이에요.*

### 3. 숫자 0~20

| | 러시아어 | 발음 | | 러시아어 | 발음 |
|---|---|---|---|---|---|
| 0 | ноль | nol' | 11 | оди́ннадцать | odínnadtsat' |
| 1 | оди́н | odín | 12 | двена́дцать | dvenádtsat' |
| 2 | два | dva | 13 | трина́дцать | trinádtsat' |
| 3 | три | tri | 14 | четы́рнадцать | chetýrnadtsat' |
| 4 | четы́ре | chetýre | 15 | пятна́дцать | pyatnádtsat' |
| 5 | пять | pyat' | 16 | шестна́дцать | shestnádtsat' |
| 6 | шесть | shest' | 17 | семна́дцать | semnádtsat' |
| 7 | семь | sem' | 18 | восемна́дцать | vosemnádtsat' |
| 8 | во́семь | vósem' | 19 | девятна́дцать | devyatnádtsat' |
| 9 | де́вять | dévyat' | 20 | два́дцать | dvádtsat' |
| 10 | де́сять | désyat' | | | |

**11~19를 만드는 법.** 이 숫자들은 '열 위에 하나, 열 위에 둘…'이라는 옛 표현입니다: 일의 자리 숫자 + **-на-** + **-дцать**(**де́сять**에서 옴). 그래서 **оди́н + на + дцать = оди́ннадцать**(**н**이 두 개!), **две + на + дцать = двена́дцать**입니다. 5~9는 끝의 **ь**가 빠집니다: **пять → пятна́дцать**, **семь → семна́дцать**. 강세는 **оди́ннадцать**, **четы́рнадцать**를 빼고 모두 **-на́-**에 있습니다.

**발음.** **-дцать**는 [tsat']로 소리 납니다(дц는 한 소리 [ts]가 됩니다): **два́дцать** [dvátsat']. **шестна́дцать**에서는 **т**를 읽지 않습니다: [shysnátsat']. 강세 없는 모음은 평소처럼 약화됩니다: **двена́дцать** [dvinátsat'], **восемна́дцать** [vasimnátsat'].

**оди́н, одна́, одно́.** 숫자 '하나'는 대명사처럼 명사의 성에 맞춥니다: **оди́н стол**(남성), **одна́ кни́га**(여성), **одно́ окно́**(중성). 다른 숫자 뒤에서는 명사의 형태가 바뀝니다. 예를 들어 '책상 두 개'는 'два столы́'가 아닙니다. 이것은 13과와 16과에서 배웁니다. 지금은 숫자를 혼자서만 쓰세요: 수 세기, 전화번호와 방 번호, 계산.

**한국어 화자를 위한 팁.** 한국어에는 '하나, 둘'(고유어)과 '일, 이'(한자어) 두 체계가 있지만, 러시아어는 한 체계뿐입니다. 전화번호도, 나이도, 수 세기도 같은 숫자를 씁니다.

**계산.** **плюс**(더하기), **ми́нус**(빼기)를 쓰고, '같다'는 줄표로 나타냅니다. 물을 때는 고정 표현 **Ско́лько бу́дет…?**(…은 얼마예요?)를 씁니다.

- Ско́лько бу́дет два плюс три? — Пять. — *2 더하기 3은 얼마예요? — 5예요.*
- Де́сять плюс де́сять — два́дцать. — *10 더하기 10은 20이에요.*
- Пятна́дцать ми́нус шесть — де́вять. — *15 빼기 6은 9예요.*
- Ко́мната но́мер семна́дцать. — *17호실.*
- Оди́н стол, одна́ ру́чка, одно́ письмо́. — *책상 하나, 펜 하나, 편지 하나.*

### 4. 여러 사물에 대해 말하기: и, а, не… а…

복수 명사를 쓸 때는 단어를 이어 말하는 경우가 많습니다. 세 개의 작은 단어가 도움이 됩니다.

- **и** — '그리고, ~와/과', 단순히 더할 때: **кни́ги и словари́**(책과 사전).
- **а** — '그리고/그런데', 대조하거나 화제를 바꿀 때: **Тут кни́ги, а там статьи́.**(여기는 책이고, 저기는 논문이에요.) 한국어의 대조 '은/는'과 느낌이 비슷합니다.
- **не… а…** — '~이 아니라 ~이다', 상대의 말을 바로잡을 때: **Э́то не журна́лы, а статьи́.**(이건 잡지가 아니라 논문이에요.) 대화에서 민호가 두 문장으로 한 말을 한 문장으로 아주 자연스럽게 말하는 방법입니다.

질문은 단수와 같습니다. 대답이 복수여도 **Что э́то?**, **Кто э́то?**는 바뀌지 않습니다: **Кто э́то? — Э́то студе́нты.**

- Тут кни́ги, а там статьи́. — *여기는 책이고, 저기는 논문이에요.*
- Э́то не журна́лы, а статьи́. — *이건 잡지가 아니라 논문이에요.*
- Э́то не студе́нты, а аспира́нты. — *이 사람들은 학생이 아니라 대학원생이에요.*
- Кто э́то? — Э́то друзья́: А́нна и Ди́ма. — *이 사람들은 누구예요? — 친구들이에요. 안나하고 디마요.*

## 문화

**전화번호.** 러시아 휴대폰 번호는 11자리이고 **8**(국제 형식으로는 **+7**)로 시작합니다. 예: 8-916-305-24-78. 러시아 사람들은 보통 *916*, *305*, *24*, *78*처럼 묶어서 말하는데, 이때 999까지의 숫자가 필요합니다(13과). 지금은 민호처럼 한 자리씩 말해도 전혀 문제없습니다. 러시아 유심(SIM) 카드를 만들면(23과) 자기 번호를 자동으로 나올 때까지 소리 내어 연습하세요. 학과 사무실, 은행, 병원에서 꼭 물어봅니다.

## 복습

- 명사의 복수형을 만들 수 있습니다: **-ы**(студе́нты, ла́мпы), **-и**(моде́ли, статьи́, кни́ги), **-а / -я**(о́кна, зада́ния).
- 철자 규칙을 압니다: **г к х ж ш щ ч** 뒤에는 **ы**가 아니라 **и**를 씁니다.
- 불규칙 복수형 **лю́ди, де́ти, друзья́, дома́, города́, профессора́**와 복수 전용 명사 **да́нные**를 압니다.
- 0부터 20까지 세고 간단한 계산을 할 수 있습니다: **Два плюс три — пять.**
- 전화번호를 한 자리씩, 방 번호를 말할 수 있습니다: **Ко́мната но́мер пятна́дцать.**

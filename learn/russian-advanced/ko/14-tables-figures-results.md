*표 2. RuSciQA 테스트 세트에서의 답변 품질, % (세 번 실행의 평균 ± 표준편차). 열: 모델, 방법, EM, F1, 학습 파라미터 수. 행: без дообучения = 추가 학습 없음, полное дообучение = 전체 파인튜닝. 주: 추가 학습 없이 평가할 때는 그리디 디코딩을 사용했으므로 실행 간 편차가 없다. 최고 결과는 굵은 글씨로 표시하였다.*

Результаты экспериментов на тестовой выборке приведены в табл. 2. Как видно из таблицы, дообучение существенно повышает качество ответов для обеих моделей. Так, для модели размером 7 млрд параметров доля точных совпадений возрастает с 41,3 до 62,8 % при использовании LoRA и до 63,9 % при полном дообучении. Таким образом, LoRA уступает полному дообучению всего на 1,1 процентного пункта по EM, хотя число обучаемых параметров при этом сокращается более чем в 150 раз. По метрике F1 разница ещё меньше и составляет 0,8 п. п.; различие между двумя методами статистически незначимо (p > 0,05).

*테스트 세트에 대한 실험 결과는 표 2에 제시하였다. 표에서 볼 수 있듯이 추가 학습은 두 모델 모두에서 답변 품질을 크게 향상시킨다. 예컨대 70억 파라미터 모델의 정확 일치율은 LoRA를 사용하면 41.3%에서 62.8%로, 전체 파인튜닝을 하면 63.9%로 상승한다. 따라서 LoRA는 EM 기준으로 전체 파인튜닝보다 1.1%p 낮을 뿐이지만, 학습 파라미터 수는 150분의 1 이하로 줄어든다. F1 기준 차이는 더 작아 0.8%p이며, 두 방법 간 차이는 통계적으로 유의하지 않다(p > 0.05).*

Наилучший результат получен для модели размером 13 млрд параметров, дообученной с помощью LoRA: 67,1 % по EM и 79,0 % по F1. Эта модель превосходит меньшую модель с полным дообучением на 3,2 п. п. по EM и на 2,8 п. п. по F1. Стандартные отклонения по трём запускам не превышают 0,7 п. п., что свидетельствует об устойчивости полученных результатов.

*최고 결과는 LoRA로 추가 학습한 130억 파라미터 모델에서 얻었다: EM 67.1%, F1 79.0%. 이 모델은 전체 파인튜닝한 작은 모델보다 EM에서 3.2%p, F1에서 2.8%p 높다. 세 번 실행의 표준편차는 0.7%p를 넘지 않으며, 이는 결과가 안정적임을 보여 준다.*

На рис. 3 показана зависимость F1-меры от ранга адаптера r для модели размером 7 млрд параметров. При увеличении ранга с 4 до 16 качество монотонно растёт (с 72,9 до 75,4 %), однако дальнейшее увеличение ранга до 64 не приводит к заметному улучшению: значение F1 выходит на плато и даже незначительно снижается (75,1 % при r = 64). Следовательно, ранг r = 16 можно считать оптимальным компромиссом между качеством ответов и числом обучаемых параметров.

*그림 3은 70억 파라미터 모델에서 어댑터 랭크 r에 따른 F1 점수의 변화를 보여 준다. 랭크를 4에서 16으로 높이면 품질이 단조 증가하지만(72.9%에서 75.4%로), 랭크를 64까지 더 높여도 뚜렷한 개선은 없다. F1 값은 정체 구간에 들어서고 오히려 약간 낮아진다(r = 64에서 75.1%). 따라서 r = 16을 답변 품질과 학습 파라미터 수 사이의 최적 절충점으로 볼 수 있다.*

Анализ ошибок показал, что наибольшее число ошибок приходится на числовые вопросы (46 % всех ошибок лучшей модели), тогда как на фактические вопросы приходится лишь 17 %. Это согласуется с выводами ряда работ [12, 15], согласно которым языковые модели испытывают трудности с арифметическими операциями. Остальные 37 % ошибок связаны с открытыми вопросами, на которые модель, как правило, даёт неполный, но не ошибочный ответ; по-видимому, автоматические метрики в этом случае занижают реальное качество ответов.

*오류 분석 결과, 오류가 가장 많은 것은 수치형 질문이었고(최고 모델 전체 오류의 46%), 사실형 질문은 17%에 불과했다. 이는 언어 모델이 산술 연산에 어려움을 겪는다는 여러 선행 연구[12, 15]의 결론과 일치한다. 나머지 37%의 오류는 개방형 질문에서 나왔는데, 모델은 대체로 불완전하지만 틀리지는 않은 답을 내놓는다. 이 경우 자동 지표가 실제 답변 품질을 과소평가하는 것으로 보인다.*

## 문법

### 1. 표와 그림 가리키기

러시아어는 일상 사물처럼 표와 그림에 쓰는 전치사를 구별합니다. **в таблице**(в книге, в приложении처럼 "안에"), 그러나 **на рисунке**(на фотографии, на графике, на диаграмме, на слайде처럼 "위에"). 한국어로는 둘 다 "표에, 그림에"이므로 특히 주의하세요.

| 하고 싶은 말 | 러시아어 | 격 |
|---|---|---|
| 결과는 표 2에 제시되어 있다. | Результаты приведены в табл. 2. | в + 전치격 |
| 그림 3은 …의 변화를 보여 준다. | На рис. 3 показана зависимость… | на + 전치격 |
| 표 2에서 볼 수 있듯이 … | Как видно из табл. 2, … | из + 생격 |
| 그림 3으로부터 …임을 알 수 있다. | Из рис. 3 следует, что … | из + 생격 |
| 표 2에 따르면 … | Согласно данным табл. 2, … / Согласно табл. 2, … | согласно + 여격 |
| (표 2 참조) | (см. табл. 2) | — |

**동사.** 주로 주어와 일치하는 피동 형동사 단어미를 씁니다: результаты **приведены**, зависимость **показана**, примеры **представлены**, значения **даны**. 새로운 정보는 보통 *무엇이* 제시되었는가이므로 문장 끝에 둡니다(제3과의 주제–설명 원칙): На рис. 3 показана зависимость F1-меры от ранга. 결과를 먼저 말하고 위치를 알려 줄 때는 위치가 끝에 옵니다: Результаты приведены в табл. 2.

**약어와 소리 내어 읽기.** 본문에서는 табл. 2, рис. 3처럼 마침표와 띄어쓰기를 넣어 씁니다. 캡션에서는 Таблица를 줄이지 않고 씁니다. 소리 내어 읽을 때는 약어를 풀고, 번호는 명사 뒤에 주격 기수사로 읽습니다: в таблице два, на рисунке три. 서수사로 읽지 않습니다.

**캡션.** 러시아 논문에서는 보통 표 제목은 표 위에(Таблица 2. …), 그림 캡션은 그림 아래에(Рис. 3. …) 둡니다. 한국 학술지 관행과 비슷합니다. 표 주석에 유용한 문장: Лучшие результаты выделены полужирным шрифтом. — *최고 결과는 굵은 글씨로 표시하였다.*

### 2. 결과 비교하기

대부분의 비교는 두 동사가 담당하며, 둘 다 *누구를, 무엇에서, 얼마만큼*이라는 고정된 자리를 갖습니다.

| 동사 | 누구를/누구에게 | 무엇에서 | 얼마만큼 |
|---|---|---|---|
| превосходи́ть | + 대격: превосходит меньшую модель | по + 여격: по F1 | на + 대격: на 2,8 п. п. |
| уступа́ть | + 여격: уступает полному дообучению | по + 여격: по EM | на + 대격: на 1,1 п. п. |
| отстава́ть | от + 생격: отстаёт от лучшей системы | по + 여격 | на + 대격 |

- Эта модель превосходит меньшую модель на 3,2 п. п. по EM. — *이 모델은 EM에서 작은 모델보다 3.2%p 높다.*
- LoRA уступает полному дообучению всего на 1,1 п. п. — *LoRA는 전체 파인튜닝보다 1.1%p 낮을 뿐이다.*

уступать는 여기서 "양보하다"가 아니라 "뒤지다"의 뜻이고 여격을 지배한다는 점을 기억하세요. 그 밖의 유용한 표현: выше / ниже, чем у…; по сравнению с + 조격; разница (различие) между X и Y составляет…; в N раз меньше; различие статистически значимо / незначимо.

**퍼센트인가, 퍼센트포인트인가?** 정확도가 60%에서 70%로 올랐다면 **на 10 процентных пунктов**(절대 차이, 10%p) 오른 것입니다. **на 10 %**라고 쓰면 엄밀히는 상대적 증가(60 → 66)를 뜻합니다. 러시아 심사자들도 이 차이를 지적합니다. 약어는 п. п.입니다. 일치는 일반적인 수사 규칙을 따릅니다.

| 수 | 형태 |
|---|---|
| 1, 21, 31 | на 1 процентный пункт |
| 2–4, 22–24 | на 2 процентных пункта |
| 5–20, 25… | на 5 процентных пунктов |
| 모든 소수 | на 1,1 процентного пункта; на 3,2 процентного пункта |

소수 뒤의 명사는 분수 부분에 걸리므로 단수 생격입니다(одна целая одна десятая *процентного пункта*). 2,5 процента, 0,7 процента라고 쓰는 것도 같은 이유입니다.

### 3. 경향과 의존 관계

그림을 설명하려면 변화 동사, 정도 부사, 그리고 몇 가지 틀이 필요합니다.

| 의미 | 동사 | 부사 |
|---|---|---|
| 오른다 | растёт, возрастает (возро́с, возросла́, возросло́), увеличивается, повышается | монотонно, резко, плавно |
| 내린다 | снижается, уменьшается, падает | незначительно, заметно, существенно |
| 유지된다 | остаётся практически неизменным, выходит на плато, колеблется в пределах 75–76 % | практически, примерно |
| 최고점 | достигает максимума при r = 16 | |

틀:
- **зависимость** X(생격) **от** Y(생격): зависимость F1-меры от ранга адаптера. 한국어 "Y에 따른 X의 변화"와 어순이 반대입니다.
- **при увеличении / с ростом** + 생격: При увеличении ранга с 4 до 16 качество монотонно растёт. С ростом размера модели прирост снижается.
- **не приводит к** + 여격: Дальнейшее увеличение ранга не приводит к заметному улучшению.
- **чем …, тем …**: Чем больше модель, тем меньше эффект от дообучения.
- **приходиться на** + 대격 (몫이 ~에 해당하다): Наибольшее число ошибок приходится на числовые вопросы.
- **свидетельствовать о** + 전치격: Это свидетельствует об устойчивости результатов (모음 앞에서 о → об).

возрасти의 과거형에 주의하세요: возрос, возросла, возросло, возросли — 남성형에는 -л-이 없습니다. Точность возросла с 41,3 до 62,8 %. Число ошибок снизилось на треть.

## 학습 팁

좋은 결과 단락은 일반에서 구체로 나아갑니다. (1) 결과가 어디에 있는가(в табл. 2), (2) 주된 경향(дообучение существенно повышает качество), (3) 이를 뒷받침하는 핵심 수치(с 41,3 до 62,8 %), (4) 예외나 의외의 점(LoRA почти не уступает полному дообучению), (5) 필요하면 완곡 표현을 곁들인 해석(по-видимому, …). 표 전체를 말로 다시 옮기지 마세요. 비교 두세 개를 골라 두 값이 아니라 차이를 제시하세요.

## 기억하는 네트워크

다음 두 짧은 문장을 생각해 봅시다.

- "The dog bit the man." (개가 사람을 물었다.)
- "The man bit the dog." (사람이 개를 물었다.)

두 문장은 정확히 같은 단어로 이루어져 있습니다. 제4장의 단어 주머니(bag-of-words) 모델은 두 문장을 똑같이 보며, 제5장의 단어 임베딩 평균을 입력으로 받는 단순한 순방향 신경망도 마찬가지입니다. 그러나 의미는 정반대입니다. 차이는 전적으로 단어의 **순서**(word order)에 있습니다.

제2부에서 만든 네트워크는 고정된 크기의 벡터 하나를 입력으로 받아 출력 하나를 냅니다. 언어는 이 형태에 잘 맞지 않습니다. 문장마다 길이가 다르고, 단어의 의미는 앞에 무엇이 왔는지에 따라 달라집니다. 모든 임베딩을 이어 붙여 하나의 긴 벡터로 만들 수도 있지만, 그러면 7단어 문장과 12단어 문장은 서로 다른 입력 크기를 필요로 하고, 네트워크는 2번 위치의 "dog"와 5번 위치의 "dog"가 무엇을 뜻하는지 따로따로 배워야 합니다.

**순환 신경망**(recurrent neural network, RNN)은 이 문제를 자연스럽게 해결합니다. RNN은 사람이 문장을 읽듯이 시퀀스를 읽습니다. 즉 왼쪽에서 오른쪽으로 한 번에 토큰 하나씩 읽습니다. 각 토큰을 읽은 뒤에는 **은닉 상태**(hidden state)라고 부르는 작은 내부 요약을 갱신합니다. 은닉 상태는 네트워크의 기억입니다. 지금까지 읽은 모든 것에 대한 정보를 담고 있습니다. 다음 토큰이 들어오면 네트워크는 그것을 이 기억과 결합하여 새로운 기억을 만듭니다.

핵심 아이디어는 매 단계에서 같은 작은 네트워크를 사용한다는 것입니다. 문장이 토큰 3개이든 300개이든 상관없습니다. 같은 연산을 계속 반복해서 적용하면 됩니다. "순환"이라는 말이 여기서 나옵니다. 한 단계의 출력이 다음 단계의 입력으로 되돌아 들어가기 때문입니다.

## 점화식: 하나의 공식, 여러 단계

입력 시퀀스를 $x_1, x_2, \dots, x_T$라고 합시다. 각 $x_t$는 벡터이며, 보통 위치 $t$에 있는 토큰의 임베딩입니다(제5장). 인덱스 $t$를 **타임 스텝**(time step)이라고 부르지만, 여기서 물리적 시간과는 관계가 없습니다. 단순히 "시퀀스 안의 위치"를 뜻합니다.

RNN은 크기가 $d_h$인 벡터인 은닉 상태 $h_t$를 유지합니다. $h_0 = 0$에서 시작하여 매 단계마다 다음을 계산합니다.

$$h_t = \tanh\left(W_{xh}\, x_t + W_{hh}\, h_{t-1} + b_h\right)$$

여기서

- $x_t \in \mathbb{R}^{d_{in}}$은 단계 $t$의 입력입니다.
- $h_{t-1} \in \mathbb{R}^{d_h}$는 이전 은닉 상태입니다.
- $W_{xh}$는 입력을 변환하는 $d_h \times d_{in}$ 행렬입니다.
- $W_{hh}$는 이전 기억을 변환하는 $d_h \times d_h$ 행렬입니다.
- $b_h$는 편향 벡터입니다.
- $\tanh$는 쌍곡탄젠트 활성화 함수(제7장)로, 모든 성분을 $-1$과 $1$ 사이로 유지합니다.

단계 $t$에서 예측이 필요하면(예를 들어 다음 토큰에 대한 확률 분포) 출력층을 추가합니다.

$$y_t = \operatorname{softmax}\left(W_{hy}\, h_t + b_y\right)$$

이것은 제7장의 작은 신경망에 입력 하나, 즉 자기 자신의 이전 상태가 추가된 것과 정확히 같습니다.

$W_{xh}$, $W_{hh}$, $b_h$에는 인덱스 $t$가 없다는 점에 주목하십시오. 매 단계에서 같은 파라미터가 사용됩니다. 이를 시간에 걸친 **가중치 공유**(weight sharing)라고 합니다. 여기에는 두 가지 중요한 결과가 따릅니다. 첫째, 파라미터 수가 시퀀스 길이에 의존하지 않습니다. 둘째, 네트워크가 어떤 패턴(예: "형용사 뒤에는 흔히 명사가 온다")에 대해 배운 것은 어느 위치에서든 적용할 수 있습니다.

다음은 NumPy로 작성한 순전파입니다.

```python
import numpy as np

rng = np.random.default_rng(0)
d_in, d_h, T = 3, 4, 5                   # 입력 크기, 은닉 크기, 시퀀스 길이

W_xh = rng.normal(0, 0.5, (d_h, d_in))   # 입력 -> 은닉
W_hh = rng.normal(0, 0.5, (d_h, d_h))    # 은닉 -> 은닉 ("기억" 가중치)
b_h = np.zeros(d_h)

xs = rng.normal(size=(T, d_in))          # 입력 벡터 5개로 이루어진 시퀀스
h = np.zeros(d_h)                        # 초기 은닉 상태 h_0
for t, x in enumerate(xs, start=1):
    h = np.tanh(W_xh @ x + W_hh @ h + b_h)   # 매 단계 같은 가중치
    print(f"h_{t} =", np.round(h, 3))

# 기울기가 여러 단계를 거슬러 흐를 때 얼마나 줄어드는지:
# 0.5 같은 인수(작은 도함수)를 반복해서 곱한다
for steps in [1, 5, 10, 20, 50]:
    print(steps, "steps back:", 0.5 ** steps)
```

이 반복문이 RNN의 전부입니다. 최종 $h_5$는 다섯 입력 모두에 의존합니다. 각 단계가 $h$를 통해 정보를 앞으로 전달하기 때문입니다.

## 네트워크 펼치기와 학습

RNN은 시간 축으로 **펼쳐서**(unrolling) 그려 보면 이해하기 쉽습니다. 고리가 달린 상자 하나 대신, 타임 스텝마다 상자의 복사본을 하나씩 그리고 왼쪽에서 오른쪽으로 연결합니다.

```
 x_1        x_2        x_3
  |          |          |
[RNN] -h_1-> [RNN] -h_2-> [RNN] -h_3-> ...
  |          |          |
 y_1        y_2        y_3
```

모든 복사본은 같은 가중치를 공유합니다. 펼치고 나면 RNN은 타임 스텝마다 "층"이 하나씩 있는 매우 깊은 순방향 신경망일 뿐입니다. 따라서 제8장과 제9장의 도구로 학습할 수 있습니다. 각 단계에서 손실을 계산하고(언어 모델링이라면 다음 토큰의 교차 엔트로피), 손실을 모두 더한 뒤, 펼친 그래프를 따라 역전파를 수행합니다. 이 절차를 **시간에 따른 역전파**(backpropagation through time, BPTT)라고 합니다. 가중치가 공유되므로 $W_{hh}$에 대한 기울기는 모든 타임 스텝에서 나온 기울기의 합입니다.

매우 긴 텍스트에서 수천 단계를 펼치면 메모리가 너무 많이 듭니다. 실제로는 **절단된 BPTT**(truncated BPTT)를 사용합니다. 텍스트를 예컨대 100토큰 단위의 조각으로 자르고, 은닉 상태는 한 조각에서 다음 조각으로 넘겨 주되, 역전파는 각 조각 안에서만 수행합니다.

RNN은 여러 구성으로 사용할 수 있습니다.

- **다대일**(many-to-one): 문장 전체를 읽고 마지막 은닉 상태 $h_T$로 분류합니다(예: 감성 분석).
- **정렬된 다대다**: 언어 모델링이나 품사 태깅처럼 매 단계마다 출력을 냅니다.
- **정렬되지 않은 다대다**: 기계 번역처럼 한 시퀀스를 읽고 길이가 다른 다른 시퀀스를 생성합니다. 이것이 제13장의 주제입니다.

알아 둘 만한 확장이 두 가지 있습니다. **양방향 RNN**(bidirectional RNN)은 하나의 RNN을 왼쪽에서 오른쪽으로, 다른 하나를 오른쪽에서 왼쪽으로 실행한 뒤 두 은닉 상태를 이어 붙입니다. 그러면 각 위치가 왼쪽 문맥과 오른쪽 문맥을 모두 볼 수 있습니다. **다층 RNN**(stacked RNN)은 여러 RNN 층을 쌓습니다. 1층의 은닉 상태가 2층의 입력이 됩니다.

## 기울기 소실과 기울기 폭발

이론적으로 RNN은 아주 먼 과거의 정보도 기억할 수 있습니다. 실제로는 단순한 RNN은 수십 단계보다 긴 의존 관계를 학습하는 데 어려움을 겪습니다. "The keys that I left on the table in the kitchen yesterday *are* gone."(어제 부엌 식탁 위에 둔 열쇠들이 없어졌다)이라는 문장을 봅시다. "is"가 아니라 "are"를 고르려면 모델은 많은 중간 토큰을 지나서도 "keys"라는 단어를 기억해야 합니다. 이것이 **장거리 의존성**(long-range dependency)입니다.

문제는 학습 과정에서 나타납니다. "keys"가 "are"에 영향을 준다는 것을 배우려면, "are" 단계의 손실에서 나온 기울기가 "keys" 단계까지 거슬러 올라가야 합니다. 연쇄 법칙(제9장)에 따르면 $h_t$에서 $h_k$로 거슬러 흐르는 기울기는 많은 야코비 행렬의 곱입니다.

$$\frac{\partial h_t}{\partial h_k} = \prod_{j=k+1}^{t} \frac{\partial h_j}{\partial h_{j-1}} = \prod_{j=k+1}^{t} \operatorname{diag}\!\left(1 - h_j^2\right) W_{hh}$$

여기서 $\operatorname{diag}(1 - h_j^2)$는 $\tanh$의 도함수를 대각 행렬로 쓴 것이고, 곱에는 $t - k$개의 인수가 있습니다. 1차원의 경우를 생각해 보십시오. 비슷한 크기의 수를 계속 반복해서 곱하는 셈입니다. 전형적인 인수가 1보다 작으면 곱은 지수적으로 줄어듭니다. 위 코드의 마지막 줄들은 $0.5^{20}$이 이미 약 $10^{-6}$임을 보여 줍니다. 이것이 **기울기 소실**(vanishing gradient) 문제입니다. 먼 토큰에서 오는 신호가 너무 작아져서 가중치가 거의 배우지 못합니다. 전형적인 인수가 1보다 크면 곱은 지수적으로 커지고, **기울기 폭발**(exploding gradient) 문제가 생깁니다. 거대한 갱신이 학습을 망가뜨리고 `NaN` 값을 만들 수도 있습니다.

$\tanh$의 도함수는 최대 1이며 흔히 그보다 훨씬 작기 때문에, 소실이 더 흔한 경우입니다. 이 분석은 Bengio, Simard, Frasconi(1994)가, 이후 Pascanu, Mikolov, Bengio(2013)가 명확하게 설명했습니다.

기울기 폭발에는 간단한 실용적 해결책이 있습니다. 바로 **그래디언트 클리핑**(gradient clipping)입니다. 매 갱신 전에 전체 기울기 벡터 $g$의 노름을 계산하고, 그것이 임계값 $\tau$보다 크면 크기를 다시 조정합니다.

$$g \leftarrow g \cdot \frac{\tau}{\lVert g \rVert} \quad \text{만약 } \lVert g \rVert > \tau$$

갱신 방향은 그대로이고 길이만 제한됩니다. 기울기 소실은 더 어렵습니다. 신중한 초기화가 조금 도움이 되지만, 진짜 해결책은 구조를 바꾸어 정보가 매번 작은 인수와 곱해지지 않고도 여러 단계를 흐를 수 있게 하는 것입니다. 제12장에서 보겠지만, LSTM과 GRU가 바로 이 일을 합니다.

## RNN의 장점과 한계

RNN은 오랫동안 언어 모델링, 음성 인식, 기계 번역의 주된 도구였습니다. 장점은 분명합니다. 임의 길이의 시퀀스를 다룰 수 있고, 위치에 걸쳐 파라미터를 공유하며, 생성할 때 새 단계마다 드는 비용이 같습니다. 과거 전체가 고정 크기 벡터 $h_t$ 하나로 압축되어 있기 때문입니다.

같은 성질이 약점이기도 합니다. 첫째, 고정 크기의 은닉 상태는 병목입니다. 긴 텍스트에 대해 모델이 아는 모든 것이 수백 개의 숫자 안에 들어가야 합니다. 둘째, 계산이 **순차적**입니다. $h_{t-1}$보다 먼저 $h_t$를 계산할 수 없으므로, 문장의 토큰들을 GPU에서 병렬로 처리할 수 없습니다. 셋째, 클리핑을 하더라도 단순 RNN은 먼 정보를 잘 기억하지 못합니다.

제3부의 나머지는 이 문제들을 하나씩 고쳐 나가는 이야기입니다. LSTM과 GRU(제12장)는 기억을 고칩니다. 인코더–디코더 모델(제13장)은 RNN을 번역에 적용하면서 병목을 드러냅니다. 어텐션(제14장)은 병목을 없애고, 셀프 어텐션(제15장)은 마침내 순환 자체를 없앱니다. 이것이 제4부의 트랜스포머로 이어집니다.

## 요약

- RNN은 시퀀스를 한 단계씩 읽고, 지금까지 읽은 모든 것을 요약하는 은닉 상태 $h_t$를 유지합니다.
- 갱신식 $h_t = \tanh(W_{xh} x_t + W_{hh} h_{t-1} + b_h)$는 매 타임 스텝에서 같은 가중치를 사용합니다(가중치 공유).
- 학습할 때는 네트워크를 시간 축으로 펼치고 시간에 따른 역전파(BPTT)를 적용하며, 흔히 조각 단위로 절단합니다.
- 여러 단계를 거쳐 흐르는 기울기는 많은 인수의 곱이므로 소실되거나 폭발하기 쉽습니다.
- 그래디언트 클리핑은 기울기 폭발을 해결하지만, 기울기 소실에는 LSTM과 GRU 같은 새로운 구조가 필요합니다.
- RNN은 순차적이며 과거를 고정 크기 벡터로 압축하므로, 속도와 장거리 기억에 한계가 있습니다.

## 연습 문제

1. "The dog bit the man"과 "The man bit the dog"가 단어 주머니 모델에서는 같은 표현을 얻지만 RNN에서는 서로 다른 최종 은닉 상태를 얻을 수 있는 이유를 자신의 말로 설명하십시오.
2. 어떤 RNN의 입력 크기는 $d_{in} = 50$, 은닉 크기는 $d_h = 128$입니다. $W_{xh}$, $W_{hh}$, $b_h$에 들어 있는 파라미터는 모두 몇 개입니까? 문장이 토큰 10개일 때와 1,000개일 때 이 수가 달라집니까?
3. 1차원의 경우, 역방향 단계마다 기울기에 0.9가 곱해진다고 합시다. 몇 단계 후에 기울기가 원래 크기의 1% 미만으로 떨어집니까? 인수가 1.1이라면 몇 단계 후에 100배가 됩니까?
4. 위 코드를 고쳐 모든 은닉 상태를 $T \times d_h$ 배열에 저장하도록 하십시오. 그다음 NumPy 벡터를 받아 크기가 조정된 벡터를 돌려주는 함수 `clip(g, tau)`로 그래디언트 클리핑을 구현하십시오.

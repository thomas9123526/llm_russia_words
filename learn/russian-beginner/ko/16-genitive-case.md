# 제16과. У меня нет…: 생격 1

> **초급 러시아어** · 수준: A2 · **배울 내용:** 없는 것 말하기: У меня́ нет… · 명사 단수 생격 어미 · 누구의 것인지, 어디 출신인지 말하기: кабине́т Ива́на Петро́вича, Я из Коре́и

## 대화

*В дека́нате* (학장실(교학과)에서). 민호가 비서 올가 니콜라예브나를 찾아갑니다.

**О́льга Никола́евна:** Здра́вствуйте! Вы Минхо́ Ким, аспира́нт из Коре́и?\
*안녕하세요! 한국에서 온 박사과정생 김민호 씨죠?*

**Минхо́:** Да, здра́вствуйте! Вот мой па́спорт.\
*네, 안녕하세요! 여기 제 여권입니다.*

**О́льга Никола́евна:** Спаси́бо. А где ва́ша фотогра́фия?\
*고마워요. 그런데 사진은 어디 있어요?*

**Минхо́:** Извини́те, у меня́ нет фотогра́фии.\
*죄송합니다, 사진이 없어요.*

**О́льга Никола́евна:** Ничего́. За́втра, пожа́луйста.\
*괜찮아요. 내일 가져오세요.*

**Минхо́:** Хорошо́. А где кабине́т Ива́на Петро́вича?\
*알겠습니다. 그런데 이반 페트로비치 교수님 연구실은 어디예요?*

**О́льга Никола́евна:** Его́ кабине́т — ко́мната два́дцать два. Но сего́дня его́ нет.\
*교수님 연구실은 22호실이에요. 그런데 오늘은 안 계세요.*

**Минхо́:** Его́ нет? А где он?\
*안 계세요? 어디 계신데요?*

**О́льга Никола́евна:** Он на конфере́нции.\
*학회에 가셨어요.*

**Минхо́:** Поня́тно. И ещё вопро́с: у меня́ в ко́мнате нет интерне́та.\
*알겠습니다. 질문이 하나 더 있는데요, 제 방에 인터넷이 안 돼요.*

**О́льга Никола́евна:** Э́то не здесь. Вот телефо́н администра́тора общежи́тия.\
*그건 여기 담당이 아니에요. 여기 기숙사 관리자 전화번호예요.*

**Минхо́:** Большо́е спаси́бо!\
*정말 감사합니다!*

**О́льга Никола́евна:** Пожа́луйста. До свида́ния!\
*천만에요. 안녕히 가세요!*

## 문법

### 1. 생격: 어미

여러분은 이미 네 가지 격을 알고 있습니다. 주격(사전형), 전치격(**в библиоте́ке**), 대격(**чита́ю кни́гу**), 그리고 몇 번 "숨어 있던" 생격도 보았습니다: **два рубля́, пять часо́в, Ско́лько вре́мени?** 이제 **생격**을 제대로 배울 차례입니다.

생격은 **кого́?**(누구의?)와 **чего́?**(무엇의?)에 답합니다. 기본 의미는 "**~의**"입니다. 또 **없는 것**을 나타낼 때도 씁니다. 한국어 조사 **의**와 비슷하지만, 훨씬 더 많은 곳에서 쓰입니다.

단수 어미는 다음과 같습니다.

| 성 | 주격 끝 | 생격 | 예 |
|---|---|---|---|
| 남성 | 자음 | **-а** | компью́тер → компью́тера, брат → бра́та, па́спорт → па́спорта |
| 남성 | **-ь**, **-й** | **-я** | слова́рь → словаря́, руководи́тель → руководи́теля, музе́й → музе́я |
| 중성 | **-о** | **-а** | окно́ → окна́, письмо́ → письма́, молоко́ → молока́ |
| 중성 | **-е** | **-я** | зада́ние → зада́ния, общежи́тие → общежи́тия |
| 여성 | **-а** | **-ы** | ка́рта → ка́рты, вода́ → воды́, А́нна → А́нны |
| 여성 | **-я** | **-и** | статья́ → статьи́, Коре́я → Коре́и, фотогра́фия → фотогра́фии |
| 여성 | **-ь** | **-и** | тетра́дь → тетра́ди, ночь → но́чи |

간단히 외우는 법: **남성·중성 → -а / -я, 여성 → -ы / -и.**

세 가지 규칙을 더 기억하세요.

- **철자 규칙** (제6과 복수형에서 배웠습니다): **г, к, х, ж, ш, ч, щ** 뒤에는 **ы**가 아니라 **и**를 씁니다: кни́га → кни́ги, ру́чка → ру́чки. 하지만 ка́рта → ка́рты, маши́на → маши́ны.
- **강세가 옮겨 가는 단어**가 있습니다: слова́рь → словаря́, вода́ → воды́, письмо́ → письма́. 이런 단어는 단어장에 표시해 두었습니다.
- **변하지 않는 단어**도 있습니다: 모음으로 끝나는 외래어 **ко́фе, метро́, кафе́**와 **Минхо́** 같은 외국 이름입니다. 그리고 **вре́мя**는 불규칙으로 **вре́мени**가 됩니다.

### 2. У меня́ нет…: 없음

제11과에서 **У меня́ есть…**(나에게 ~이 있다)를 배웠습니다. "없다"라고 하려면 **есть**를 **нет**으로 바꾸고, 물건을 **생격**으로 씁니다.

| 있다 (주격) | 없다 (생격) |
|---|---|
| У меня́ есть слова́рь. | У меня́ нет словаря́. |
| У меня́ есть фотогра́фия. | У меня́ нет фотогра́фии. |
| У меня́ есть вре́мя. | У меня́ нет вре́мени. |
| У меня́ есть ко́фе. | У меня́ нет ко́фе. |

한국어에서는 "사전**이** 있다 / 사전**이** 없다"처럼 조사가 같지만, 러시아어는 "없다"일 때 형태가 바뀝니다. 이 점이 가장 중요합니다.

**у** + 사람도 그 자체로 생격 구문입니다. 대명사 형태는 이미 알고 있지요. 전치사 뒤에서 **него́, неё, них**에는 **н-**이 붙는다는 점에 주의하세요.

| 대명사 | "~에게 있다 / 없다" |
|---|---|
| я | у меня́ |
| ты | у тебя́ |
| он | у него́ |
| она́ | у неё |
| мы | у нас |
| вы | у вас |
| они́ | у них |

명사는 그냥 생격을 쓰면 됩니다: **у А́нны**(안나에게), **у бра́та**(형/동생에게), **у Ди́мы**, **у Минхо́**(변화 없음).

- У А́нны нет вре́мени. — *안나는 시간이 없다.*
- У него́ нет компью́тера. — *그는 컴퓨터가 없다.*
- У нас нет интерне́та. — *우리는 인터넷이 없다.*

**нет**은 "~이 없다", "~이 여기 없다"라는 뜻도 됩니다. 사람이 자리에 없다고 할 때도 이렇게 말합니다.

- Здесь нет интерне́та. — *여기는 인터넷이 없다.*
- Ива́на Петро́вича нет. — *이반 페트로비치 교수님은 안 계신다.*
- Сего́дня его́ нет. — *오늘 그는 없다(안 계신다).*
- А́нны нет до́ма. — *안나는 집에 없다.*

**과거**에서는 **нет**이 **не́ было**가 됩니다. 물건의 성과 상관없이 항상 이 중성 형태입니다.

- Вчера́ у меня́ не́ было вре́мени. — *어제 나는 시간이 없었다.*
- У нас не́ было интерне́та. — *우리는 인터넷이 없었다.*
- Ива́на Петро́вича не́ было на семина́ре. — *이반 페트로비치 교수님은 세미나에 안 계셨다.*

### 3. 누구의 것? 어디 출신?

**소유.** "디마의 방", "교수님의 논문"이라고 할 때는 소유자를 물건 **뒤에** 생격으로 놓습니다. 한국어와 순서가 반대입니다. 한국어: 디마**의** 방 — 소유자가 앞. 러시아어: **ко́мната Ди́мы** — 소유자가 뒤.

- ко́мната Ди́мы — *디마의 방*
- кабине́т Ива́на Петро́вича — *이반 페트로비치의 연구실*
- статья́ А́нны — *안나의 논문*
- телефо́н администра́тора — *관리자의 전화번호*
- па́спорт студе́нта — *학생의 여권*
- мо́дель Минхо́ — *민호의 모델*

부칭이 있으면 이름과 부칭이 모두 바뀝니다: **Ива́н Петро́вич → Ива́на Петро́вича**. **чей? чья?**(제11과)로 묻고 생격으로 대답하세요: Чья э́то статья́? — Э́то статья́ А́нны.

**어디 출신? — из + 생격.** 전치사 **из**는 "~에서(안에서 밖으로)"라는 뜻이고, 항상 생격을 씁니다. 한국어 "~에서 왔어요"의 "에서"입니다.

- Отку́да вы? — Я из Коре́и. — *어디에서 오셨어요? — 한국에서 왔어요.*
- А́нна из Росси́и. — *안나는 러시아 사람이다(러시아 출신이다).*
- Ди́ма из Москвы́. — *디마는 모스크바 출신이다.*
- Ли из Кита́я. — *리는 중국 출신이다.*
- Том из А́нглии. — *톰은 영국 출신이다.*

한 나라 이름으로 세 가지 격을 비교해 보세요: **Я из Коре́и** (생격: ~에서), **Я жил в Коре́е** (전치격: ~에(서)), **Я хорошо́ зна́ю Коре́ю** (대격: ~을/를).

## 발음

어미 **-ого**와 **-его**에서 **г**는 **[v]**로 읽습니다: **его́** [yevó, 예보], **него́** [nevó], **ничего́** [nichevó, 니치보], **кого́** [kavó], **чего́** [chevó]. **сего́дня** [sevódnya, 시보드냐]도 마찬가지입니다. 러시아어에서 철자와 발음이 크게 다른 몇 안 되는 경우입니다. [yegó]라고 하면 알아듣기는 하지만, 글자를 하나하나 읽는 것처럼 들립니다.

## 복습

- 단수 생격 어미를 압니다: 남성·중성 **-а/-я**, 여성 **-ы/-и**.
- 없는 것을 말할 수 있습니다: **У меня́ нет словаря́. У меня́ нет вре́мени.**
- 누군가가 자리에 없다고 말할 수 있습니다: **Ива́на Петро́вича нет. Сего́дня его́ нет.**
- 과거에 대해 말할 수 있습니다: **Вчера́ у меня́ не́ было интерне́та.**
- 누구의 것인지 말할 수 있습니다: **ко́мната Ди́мы, кабине́т Ива́на Петро́вича.**

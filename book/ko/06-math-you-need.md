## 시작하는 질문

제5장에서 우리는 *cat*(고양이)과 *dog*(개)라는 단어를 벡터로 표현했고, 비슷한 단어는 "가까운" 벡터를 가진다고 말했습니다. 그런데 숫자의 목록에서 "가깝다"는 것은 무슨 뜻일까요? 또 언어 모델이 다음 단어를 예측할 때, 가공되지 않은 점수의 목록을 어떻게 합이 1인 확률로 바꿀까요?

이 두 질문 안에 이 책의 수학이 거의 다 들어 있습니다. 신경망은 대부분 세 가지로 이루어집니다. 벡터(숫자의 목록), 행렬(벡터를 변환하는 숫자의 표), 그리고 확률(불확실성을 나타내는 0과 1 사이의 숫자)입니다. 신경망을 *학습*시키려면 미적분학의 아이디어가 하나 더 필요한데, 바로 도함수입니다. 이 장에서는 각각을 작은 예제로 소개합니다. 수학자가 될 필요는 없습니다. 다만 이후의 모든 장에서 이 표기법을 사용하므로, 표기를 편하게 읽을 수 있어야 합니다.

## 벡터와 내적

**벡터**(vector)는 순서가 있는 숫자의 목록입니다. 벡터는 굵은 소문자로 씁니다. 예를 들면 다음과 같습니다.

$$\mathbf{a} = (0.9,\ 0.1,\ 0.4).$$

이 숫자들을 벡터의 **성분**(components)이라고 하고, 성분의 개수를 **차원**(dimension)이라고 합니다. 이 벡터의 차원은 3이며, $\mathbf{a} \in \mathbb{R}^3$이라고 씁니다. "$\mathbf{a}$는 세 개의 실수로 이루어진 벡터"라고 읽습니다. 실제 임베딩은 수백에서 수천 차원을 가지지만, 모든 것은 3차원에서와 똑같이 작동합니다.

벡터는 두 가지 방식으로 볼 수 있습니다. 기하학적으로 벡터는 원점에서 공간의 한 점까지 이어지는 화살표입니다. 데이터로서 벡터는 어떤 대상에 대한 설명이며, 각 성분은 하나의 특징을 측정합니다. 두 관점 모두 유용합니다.

두 벡터에 대한 가장 중요한 연산은 **내적**(dot product)입니다. 성분끼리 짝지어 곱한 뒤 결과를 모두 더합니다.

$$\mathbf{a} \cdot \mathbf{b} = \sum_{i=1}^{n} a_i b_i = a_1 b_1 + a_2 b_2 + \dots + a_n b_n.$$

여기서 $n$은 차원이고, $a_i$와 $b_i$는 $i$번째 성분입니다. $\mathbf{a}$를 *cat*의 벡터, $\mathbf{b} = (0.8,\ 0.2,\ 0.5)$를 *dog*의 벡터라고 합시다. 그러면 다음과 같습니다.

$$\mathbf{a} \cdot \mathbf{b} = 0.9 \cdot 0.8 + 0.1 \cdot 0.2 + 0.4 \cdot 0.5 = 0.72 + 0.02 + 0.20 = 0.94.$$

내적은 두 벡터가 비슷한 방향을 가리키고 성분이 클 때 커집니다. 두 벡터가 수직이면 0이 되고, 대략 반대 방향을 가리키면 음수가 됩니다.

벡터의 길이를 **노름**(norm)이라고 합니다. 일반적인 (유클리드) 노름은 다음과 같습니다.

$$\|\mathbf{a}\| = \sqrt{\mathbf{a} \cdot \mathbf{a}} = \sqrt{a_1^2 + \dots + a_n^2}.$$

내적을 두 노름으로 나누면 길이의 영향은 사라지고 방향만 남습니다. 이것이 제5장에서 사용한 **코사인 유사도**(cosine similarity)입니다.

$$\cos(\mathbf{a}, \mathbf{b}) = \frac{\mathbf{a} \cdot \mathbf{b}}{\|\mathbf{a}\|\,\|\mathbf{b}\|}.$$

우리 예제에서 $\|\mathbf{a}\| = \sqrt{0.98} \approx 0.990$, $\|\mathbf{b}\| = \sqrt{0.93} \approx 0.964$이므로 코사인 값은 $0.94 / 0.955 \approx 0.985$입니다. 1에 가까운 값이므로 두 화살표는 거의 같은 방향을 가리킵니다. 내적을 잘 기억해 두십시오. 제15장에서 보겠지만, 어텐션의 핵심은 "쿼리" 벡터와 "키" 벡터 사이의 내적입니다.

## 행렬: 벡터를 변환하는 기계

**행렬**(matrix)은 숫자를 직사각형 모양으로 배열한 표입니다. 행이 $m$개, 열이 $n$개인 행렬의 **형태**(shape)는 $m \times n$이며, $W \in \mathbb{R}^{m \times n}$이라고 씁니다. $i$행 $j$열의 원소는 $W_{ij}$입니다.

핵심 연산은 **행렬–벡터 곱셈**(matrix–vector multiplication)입니다. 행렬의 각 행이 벡터와 내적을 계산합니다.

$$(W\mathbf{x})_i = \sum_{j=1}^{n} W_{ij}\, x_j.$$

따라서 $m \times n$ 행렬은 $n$차원 벡터를 $m$차원 벡터로 바꿉니다. 하나의 기계라고 생각하면 됩니다. 벡터가 들어가면 새로운 벡터가 나옵니다. 예를 들어 다음과 같습니다.

$$W = \begin{pmatrix} 1 & 0 & -1 \\ 0.5 & 0.5 & 0.5 \end{pmatrix}, \qquad W\mathbf{a} = \begin{pmatrix} 0.9 - 0.4 \\ 0.5\,(0.9 + 0.1 + 0.4) \end{pmatrix} = \begin{pmatrix} 0.5 \\ 0.7 \end{pmatrix}.$$

첫 번째 행은 "특징 1이 특징 3보다 얼마나 더 큰가"를 측정하고, 두 번째 행은 모든 특징의 전체 크기를 일정한 배율로 측정합니다. 각 행은 작은 검출기이고, 출력 벡터는 각 검출기가 찾아낸 값을 나열한 것입니다. 제7장에서 보겠지만, 이것이 바로 신경망의 층이 하는 일입니다.

**행렬 곱셈**(matrix multiplication) $C = AB$는 같은 규칙을 여러 열에 한꺼번에 적용합니다: $C_{ij} = \sum_k A_{ik} B_{kj}$. 이 곱셈은 안쪽 크기가 일치할 때만 정의됩니다. $(m \times k)$와 $(k \times n)$을 곱하면 $(m \times n)$이 됩니다. 신경망 코드의 버그는 대부분 형태 불일치에서 생기므로, 모든 텐서 옆에 형태를 적어 두는 습관이 좋습니다.

두 가지 용어를 더 알아 둡시다. **전치**(transpose) $W^\top$는 행과 열을 맞바꾸므로, $m \times n$ 행렬은 $n \times m$ 행렬이 됩니다. 코드에서는 여러 벡터의 묶음을 행렬 $X$의 행으로 저장하는 경우가 많습니다. $X$의 형태는 (예제 수) $\times$ (차원)입니다. 그러면 $XW^\top$ 하나로 모든 예제를 한 번에 변환할 수 있습니다. 컴퓨터, 특히 GPU는 바로 이 연산을 매우 빠르게 처리하며, 이것이 신경망이 실용화된 큰 이유 중 하나입니다. **텐서**(tensor)는 이런 배열을 부르는 일반적인 이름입니다. 벡터는 1차원 텐서, 행렬은 2차원 텐서이고, 임베딩으로 이루어진 문장들의 묶음은 3차원 텐서입니다.

## 확률: 불확실성을 기술하기

언어 모델은 다음 단어를 결코 확실하게 알지 못합니다. 대신 각 후보에 **확률**(probability)을 부여합니다. 유한한 결과 집합 위의 **확률 분포**(probability distribution)는 다음 조건을 만족하는 숫자의 목록 $p_1, \dots, p_K$입니다.

$$p_k \ge 0 \quad \text{그리고} \quad \sum_{k=1}^{K} p_k = 1.$$

"The cat sat on the" 다음에 모델은 *mat*에 0.6, *floor*에 0.3, *moon*에 0.1의 확률을 줄 수 있습니다.

**조건부 확률**(conditional probability) $P(A \mid B)$는 $B$를 이미 알고 있을 때 $A$가 일어날 확률입니다. 언어 모델은 바로 조건부 확률을 계산하는 기계, 즉 $P(\text{다음 단어} \mid \text{이전 단어들})$을 계산하는 기계입니다. 제1장에서 보았듯이, **확률의 연쇄 법칙**(chain rule of probability)을 사용하면 이 조각들로 문장 전체의 확률을 만들 수 있습니다.

$$P(w_1, \dots, w_T) = \prod_{t=1}^{T} P(w_t \mid w_1, \dots, w_{t-1}).$$

여기서 $w_t$는 $t$번째 단어, $T$는 문장의 길이이며, $\prod$는 "모든 항을 곱한다"는 뜻입니다.

값 $x_k$를 확률 $p_k$로 가지는 양 $x$의 **기댓값**(expected value)은 확률로 가중한 평균 $\mathbb{E}[x] = \sum_k p_k x_k$입니다. 신경망을 학습시킨다는 것은 데이터 전체에 대한 *기대* 오차를 작게 만드는 것이므로, 이 표기는 자주 등장합니다.

신경망은 어떻게 확률 분포를 만들어 낼까요? 마지막 층은 **로짓**(logits)이라고 부르는 임의의 실수를 출력합니다. 로짓은 음수일 수도 있고, 합이 1일 필요도 없습니다. **소프트맥스**(softmax) 함수가 이를 변환합니다.

$$\operatorname{softmax}(\mathbf{z})_k = \frac{e^{z_k}}{\sum_{j=1}^{K} e^{z_j}}.$$

지수 함수 $e^{z}$는 모든 수를 양수로 만들고, 합으로 나누면 전체 합이 1이 됩니다. 로짓이 클수록 확률도 항상 큽니다. 로짓 $(2.0,\ 1.0,\ 0.1)$의 소프트맥스는 대략 $(0.659,\ 0.242,\ 0.099)$입니다.

## 로그와 도함수

많은 확률을 곱하면 값이 매우 빠르게 작아집니다. 0.1을 쉰 번 곱하면 $10^{-50}$이 됩니다. 그래서 우리는 **로그**(logarithm)를 사용합니다. 로그는 곱을 합으로 바꾸며($\log(ab) = \log a + \log b$), 증가 함수이므로 확률이 클수록 로그 확률도 항상 큽니다. 이 책에서 $\log$는 자연로그(밑이 $e$)를 뜻합니다. 확률의 로그는 항상 $\le 0$이고, $-\log p$는 $p$가 작을 때 커집니다. 제8장에서 이 양 $-\log p$는 언어 모델의 손실 함수가 됩니다.

마지막 도구는 **도함수**(derivative)입니다. 하나의 숫자에 대한 함수 $f(w)$가 있을 때, 도함수 $f'(w)$(또는 $\frac{df}{dw}$)는 $w$를 조금 바꿀 때 $f$가 얼마나 빨리 변하는지를 알려 줍니다.

$$f(w + \Delta) \approx f(w) + f'(w)\,\Delta \quad (\Delta \text{가 작을 때}).$$

예를 들어 $f(w) = (w - 3)^2$이면 $f'(w) = 2(w - 3)$입니다. $w = 1$에서 도함수는 $-4$이므로, $w$를 늘리면 $f$는 작아집니다. 이것이 학습의 핵심 아이디어 전부입니다. 가중치에 따라 달라지는 오차가 있고, 도함수는 각 가중치를 어느 방향으로 움직여야 하는지 알려 줍니다.

신경망에는 수백만 개의 가중치가 있으므로 각각에 대한 도함수가 필요합니다. **편도함수**(partial derivative) $\frac{\partial f}{\partial w_i}$는 다른 변수를 고정한 채 한 변수에 대해 구한 도함수입니다. 편도함수들을 하나의 벡터로 모은 것이 **그래디언트**(gradient, 기울기)입니다.

$$\nabla f = \left( \frac{\partial f}{\partial w_1}, \dots, \frac{\partial f}{\partial w_n} \right).$$

그래디언트는 $f$가 가장 빠르게 증가하는 방향을 가리킵니다. 제8장에서는 오차를 줄이기 위해 그래디언트의 *반대* 방향으로 걸어가고, 제9장에서는 미분의 **연쇄 법칙**(chain rule)을 이용해 그래디언트를 효율적으로 계산하는 방법을 배웁니다. $y = f(g(x))$이면 $\frac{dy}{dx} = f'(g(x))\, g'(x)$입니다.

## 같은 아이디어를 코드로

NumPy를 사용하면 위의 모든 숫자를 몇 줄로 확인할 수 있습니다.

```python
import numpy as np

# 장난감 같은 3차원 단어 벡터
cat = np.array([0.9, 0.1, 0.4])
dog = np.array([0.8, 0.2, 0.5])

# 내적과 코사인 유사도
dot = cat @ dog
cos = dot / (np.linalg.norm(cat) * np.linalg.norm(dog))
print("dot:", round(dot, 3), "cosine:", round(cos, 3))   # 0.94, 0.985

# 2x3 행렬은 3차원 벡터를 2차원 벡터로 바꾼다
W = np.array([[1.0, 0.0, -1.0],
              [0.5, 0.5,  0.5]])
print("W @ cat:", W @ cat)                               # [0.5 0.7]

# 소프트맥스는 로짓을 확률로 바꾼다
def softmax(z):
    z = z - z.max()          # 최댓값을 빼면 오버플로를 막을 수 있다
    e = np.exp(z)
    return e / e.sum()

p = softmax(np.array([2.0, 1.0, 0.1]))
print("probabilities:", p.round(3), "sum:", p.sum())     # [0.659 0.242 0.099]

# w = 1에서 f(w) = (w - 3)^2 의 수치 미분
f = lambda w: (w - 3) ** 2
h = 1e-5
print("derivative:", round((f(1 + h) - f(1 - h)) / (2 * h), 3))  # -4.0
```

`z - z.max()` 줄에 주목하십시오. 모든 로짓에서 같은 수를 빼도 소프트맥스는 변하지 않습니다(분수에서 $e^{-c}$가 약분됩니다). 하지만 이렇게 하면 로짓이 클 때 $e^{z}$가 오버플로되는 것을 막을 수 있습니다. 실제 라이브러리도 똑같이 합니다.

## 요약
- 벡터는 숫자의 목록입니다. 내적 $\sum_i a_i b_i$는 두 벡터가 얼마나 일치하는지 측정하고, 코사인 유사도는 길이의 영향을 제거합니다.
- $m \times n$ 행렬은 $n$차원 벡터를 $m$차원 벡터로 변환하며, 각 행은 검출기처럼 작동합니다.
- 확률 분포는 합이 1인 음이 아닌 숫자의 목록입니다. 언어 모델은 다음 토큰의 조건부 확률을 계산합니다.
- 소프트맥스는 임의의 로짓을 확률 분포로 바꿉니다.
- 로그는 곱을 합으로 바꾸어 아주 작은 확률도 다루기 쉽게 만듭니다.
- 도함수와 그 다변수 형태인 그래디언트는 오차를 줄이려면 가중치를 어떻게 바꿔야 하는지 알려 줍니다.

## 연습 문제
1. 길이가 서로 다른 단어 임베딩을 비교할 때 단순한 내적이 아니라 코사인 유사도를 사용하는 이유를 자신의 말로 설명해 보십시오.
2. $(1, 2, 0)$과 $(2, 1, 1)$의 내적과 코사인 유사도를 손으로 계산한 뒤, NumPy로 답을 확인해 보십시오.
3. 행렬 $A$의 형태는 $4 \times 3$, 행렬 $B$의 형태는 $3 \times 5$입니다. $AB$의 형태는 무엇입니까? $BA$는 정의됩니까? 그 이유는 무엇입니까?
4. 모든 로짓에 같은 상수 $c$를 더해도 소프트맥스가 변하지 않음을 보이십시오. 그다음 $(0, 0, \ln 2)$의 소프트맥스를 계산해 보십시오.

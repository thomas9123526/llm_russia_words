# 제15과. 초록과 결론 쓰기

> **연구자를 위한 고급 러시아어** · 수준: C1 · **배울 내용:** 러시아어 초록(аннотация)의 단계, 시제, 넣지 말아야 할 것 · 결론 절 구성하기: 결과, 의의, 한계, 향후 연구 · 전형적인 영어 초록 표현을 자연스러운 러시아어로 옮기기

## 본문

제13과와 제14과의 논문이 거의 완성되었습니다. 이반 페트로비치 교수: «Аннотацию пишут последней, а читают первой» ("초록은 가장 나중에 쓰고, 가장 먼저 읽힌다"). 아래는 민호가 쓴 초록과 논문의 마지막 절입니다. 데이터셋, 결과, 학술지는 이 교재를 위해 만든 예시입니다.

**Дообучение больших языковых моделей для ответов на вопросы по русскоязычным научным текстам: набор данных RuSciQA и сравнение методов**

**Аннотация.** Настоящая работа посвящена адаптации больших языковых моделей (БЯМ) к ответам на вопросы по русскоязычным научным текстам. Несмотря на быстрый прогресс в этой области, качество работы БЯМ с научными текстами на русском языке остаётся недостаточно изученным, а открытые наборы данных для его оценки практически отсутствуют. В работе представлен новый набор данных RuSciQA, содержащий 6 200 пар «вопрос — ответ», составленных на основе аннотаций статей по информатике и прикладной математике. На этом наборе проведено сравнение полного дообучения и дообучения с помощью адаптеров низкого ранга (LoRA) для двух открытых моделей размером 7 и 13 млрд параметров. Показано, что LoRA уступает полному дообучению не более чем на 1,1 процентного пункта по доле точных совпадений, сокращая при этом число обучаемых параметров более чем в 150 раз. Наилучший результат (79,0 % по F1-мере) достигнут моделью размером 13 млрд параметров, дообученной с помощью LoRA. Анализ ошибок показал, что основные трудности у моделей вызывают вопросы, требующие числовых рассуждений. Набор данных и код будут опубликованы в открытом доступе.

*러시아어 과학 텍스트 질의응답을 위한 대규모 언어 모델의 추가 학습: RuSciQA 데이터셋과 방법 비교*

*초록. 본 연구는 대규모 언어 모델(LLM)을 러시아어 과학 텍스트에 대한 질의응답에 적응시키는 문제를 다룬다. 이 분야가 빠르게 발전하고 있음에도 러시아어 과학 텍스트에서 LLM의 성능은 아직 충분히 연구되지 않았으며, 이를 평가할 공개 데이터셋도 거의 없다. 본 연구에서는 컴퓨터 과학 및 응용 수학 논문의 초록을 바탕으로 작성한 질문–답변 쌍 6,200개로 이루어진 새로운 데이터셋 RuSciQA를 제시한다. 이 데이터셋에서 파라미터 70억 개와 130억 개 규모의 두 공개 모델에 대해 전체 파인튜닝과 저랭크 어댑터(LoRA)를 이용한 추가 학습을 비교하였다. 그 결과 LoRA는 정확 일치율에서 전체 파인튜닝보다 최대 1.1%p 낮을 뿐이면서 학습 파라미터 수를 150분의 1 이하로 줄임을 보였다. 최고 결과(F1 79.0%)는 LoRA로 추가 학습한 130억 파라미터 모델이 달성하였다. 오류 분석 결과, 모델이 가장 어려워하는 것은 수치 추론이 필요한 질문이었다. 데이터셋과 코드는 공개할 예정이다.*

**Ключевые слова:** большие языковые модели, дообучение, LoRA, ответы на вопросы, набор данных, русский язык.

*핵심어: 대규모 언어 모델, 추가 학습, LoRA, 질의응답, 데이터셋, 러시아어.*

**5. Заключение**

В работе рассмотрена задача ответов на вопросы по русскоязычным научным текстам с помощью больших языковых моделей. Основные результаты работы состоят в следующем.

1. Создан набор данных RuSciQA, включающий 6 200 пар «вопрос — ответ» с согласованностью разметки 0,81 по коэффициенту каппа Коэна.
2. Проведено систематическое сравнение полного дообучения и дообучения с помощью LoRA. Показано, что при сопоставимом качестве LoRA требует на два порядка меньше обучаемых параметров.
3. Установлено, что при ранге адаптера выше 16 качество выходит на плато; следовательно, дальнейшее увеличение ранга нецелесообразно.
4. Выявлено, что почти половина ошибок приходится на числовые вопросы.

*5. 결론. 본 연구에서는 대규모 언어 모델을 이용한 러시아어 과학 텍스트 질의응답 과제를 다루었다. 주요 결과는 다음과 같다. 1. 코언의 카파 기준 주석 일치도 0.81의 질문–답변 쌍 6,200개를 포함하는 데이터셋 RuSciQA를 구축하였다. 2. 전체 파인튜닝과 LoRA 추가 학습을 체계적으로 비교하였다. 비슷한 품질에서 LoRA가 필요로 하는 학습 파라미터 수가 두 자릿수(100배) 이상 적음을 보였다. 3. 어댑터 랭크가 16을 넘으면 품질이 정체되므로 랭크를 더 높이는 것은 적절하지 않음을 확인하였다. 4. 오류의 거의 절반이 수치형 질문에서 발생함을 밝혔다.*

Практическая значимость работы состоит в том, что предложенный подход позволяет адаптировать языковую модель к научной предметной области на одном графическом процессоре. Полученные результаты могут быть использованы при разработке систем поиска и анализа научной информации на русском языке.

*본 연구의 실용적 의의는 제안한 접근법으로 GPU 한 장만으로도 언어 모델을 과학 분야에 적응시킬 수 있다는 데 있다. 이 결과는 러시아어 과학 정보 검색·분석 시스템 개발에 활용될 수 있다.*

Вместе с тем работа имеет ряд ограничений. Во-первых, набор данных охватывает лишь две научные области. Во-вторых, оценка проводилась только с помощью автоматических метрик, которые не всегда отражают качество развёрнутых ответов.

*다만 본 연구에는 몇 가지 한계가 있다. 첫째, 데이터셋이 두 개의 학문 분야만을 포괄한다. 둘째, 평가는 자동 지표로만 이루어졌는데, 자동 지표가 서술형 답변의 품질을 항상 반영하는 것은 아니다.*

В дальнейшем планируется расширить набор данных за счёт статей по гуманитарным и естественным наукам, а также дополнить автоматическую оценку экспертной. Перспективным направлением представляется также исследование методов, повышающих точность ответов на числовые вопросы.

*향후에는 인문학과 자연과학 논문을 추가하여 데이터셋을 확장하고, 자동 평가를 전문가 평가로 보완할 계획이다. 수치형 질문에 대한 답변 정확도를 높이는 방법에 관한 연구도 유망한 방향으로 보인다.*

## 문법

### 1. 초록: 단계, 시제, 빼야 할 것

러시아어 초록은 논문 전체를 압축한 것입니다. 보통 여섯 단계로 이루어지며, 단계마다 표지 표현이 있습니다.

| 단계 | 표지 표현 | 본문에서 |
|---|---|---|
| 1. 주제 | Работа посвящена + 여격; В статье рассматривается… | Настоящая работа посвящена адаптации… |
| 2. 문제 | Несмотря на…; однако; остаётся недостаточно изученным; практически отсутствуют | Несмотря на быстрый прогресс… |
| 3. 기여 | В работе представлен / предлагается / разработан… | В работе представлен новый набор данных… |
| 4. 방법, 데이터 | проведено сравнение / исследование…; на материале… | На этом наборе проведено сравнение… |
| 5. 결과 | Показано, что…; Установлено, что…; достигнут…; Анализ показал, что… | Показано, что LoRA уступает… |
| 6. 의의, 공개 | Полученные результаты могут быть использованы…; будут опубликованы | Набор данных и код будут опубликованы… |

**시제와 형태.** 논문 자체에 관한 것은 현재 시제입니다(работа посвящена, в работе предлагается). 수행한 일은 완료상 피동 형동사 단어미로, 보통 주어 없이 동사를 앞에 둡니다: Проведено сравнение…, Показано, что…, Достигнут результат… 무인칭 **Показано, что…**는 영어 *We show that…*, 한국어 논문의 "~임을 보였다"에 해당하는 러시아어의 표준 표현입니다.

**빼야 할 것.** 러시아어 초록은 본문 없이도 이해되어야 하므로 보통 다음을 넣지 않습니다.
- 참고 문헌 번호([12, 15]);
- 표·그림 참조(как видно из табл. 2);
- 풀이 없는 약어: 처음에는 전체 용어를 쓰고 괄호 안에 약어를 씁니다 — большие языковые модели (БЯМ);
- В статье будут рассмотрены некоторые вопросы…("몇 가지 문제를 살펴볼 것이다")처럼 내용 없는 약속 — *무엇을* 밝혔는지 쓰세요.

반대로 구체적인 수치는 환영받습니다: на 1,1 процентного пункта, 79,0 % по F1-мере. 분량 요건과 절의 정확한 명칭(аннотация, реферат, резюме)은 학술지마다 다르므로 반드시 해당 학술지의 투고 규정을 확인하세요.

**압축.** 초록을 짧게 유지하려면 절을 형동사구와 동명사로 바꿉니다(제2과, 제7과).
- Мы собрали набор данных. Он содержит 6 200 пар. → Представлен набор данных, содержащий 6 200 пар.
- LoRA уступает полному дообучению на 1,1 п. п. При этом LoRA сокращает число параметров в 150 раз. → LoRA уступает полному дообучению на 1,1 п. п., сокращая при этом число параметров в 150 раз.

### 2. 결론 절: 결과, 의의, 한계, 향후 연구

마지막 절은 **Заключение**(학위 논문과 많은 논문) 또는 **Выводы**(흔히 번호 목록)라고 합니다. 초록과 달리 논문의 절을 언급할 수 있고, 한계를 밝혀야 합니다. 표준 구성은 다음과 같습니다.

| 부분 | 표현 |
|---|---|
| 수행한 일 | В работе рассмотрена задача…; В работе исследован… |
| 주요 결과 | Основные результаты работы состоят в следующем.; В работе получены следующие результаты: |
| 의의 | Практическая значимость работы состоит в том, что…; Полученные результаты могут быть использованы при + 전치격 |
| 한계 | Вместе с тем работа имеет ряд ограничений.; К ограничениям работы относится…; Ограничение работы состоит в том, что… |
| 향후 연구 | В дальнейшем планируется + 동사 원형; Перспективным направлением представляется + 주격; Представляет интерес + 주격 |

**번호 붙인 결과**는 보통 뒤따르는 명사와 일치하는 피동 형동사 단어미로 시작합니다.

| 형태 | 예 |
|---|---|
| 남성 | Создан набор данных… / Разработан метод… |
| 여성 | Предложена модель… / Разработана методика… |
| 중성 | Проведено сравнение… / Проведено исследование… |
| 복수 | Получены результаты… / Выявлены закономерности… |
| 무인칭(중성) + что | Показано, что… / Установлено, что… / Выявлено, что… |

한국어 논문의 "~을 구축하였다, ~을 확인하였다"를 러시아어로는 이렇게 주어 없는 피동형으로 씁니다.

**병렬 구조.** и로 연결된 항목은 형태가 같아야 합니다. 동명사와 동사 원형을 섞는 것은 전형적인 오류입니다: *планируется расширение набора данных и проверить метод*. 동사 원형 둘(планируется расширить набор данных и проверить метод)이나 명사 둘(планируются расширение набора данных и проверка метода)로 쓰세요.

**한계를 밝히는 것은 정상입니다.** 러시아 심사자와 학위 논문 심사 위원회(диссертационный совет)는 한계를 기대합니다. во-первых, во-вторых로 담담하게 제시하고, 가능하면 각 한계를 향후 연구와 연결하세요.

### 3. 영어 초록에서 러시아어 초록으로

많은 학술지가 러시아어 초록과 영어 초록을 함께 요구합니다. 단어 대 단어로 옮기지 말고 러시아어 관습을 따르세요.

| English | Русский |
|---|---|
| This paper addresses / is devoted to… | Работа посвящена + 여격 (전치사 없음!) |
| In this paper, we propose… | В работе предлагается… / В статье предложен… |
| We show that… | Показано, что… |
| a novel method | новый метод |
| outperforms state-of-the-art approaches | превосходит существующие подходы / лучшие известные результаты |
| significantly improves | существенно повышает (статистически значимо — 검정을 했을 때만) |
| achieves 79.0 F1 | достигает 79,0 % по F1-мере |
| To the best of our knowledge, … | Насколько нам известно, … |
| Our code and data are publicly available. | Код и данные находятся в открытом доступе. |
| Future work will… | В дальнейшем планируется… |

세 가지를 조심하세요. **посвящена**는 전치사 없이 여격을 씁니다(посвящена оценке, ×*посвящена к оценке*). **превосходить**는 над 없이 대격을 씁니다(*превосходит над*은 "superior over"의 직역). 소수점은 쉼표입니다(79,0 %).

## 학습 팁

초록은 맨 나중에, 결론에서 출발해 쓰세요. Заключение의 번호 붙은 결과를 하나씩 한 절로 압축해 5단계에 넣고, Заключение의 첫 문장은 1단계에, 의의 문장은 6단계에 씁니다. 그런 다음 1절의 목록으로 점검하세요: 참고 문헌 없음, 표 없음, 풀이 없는 약어 없음, 구체적 수치 최소 하나. 마지막으로 러시아어 초록과 영어 초록을 나란히 읽어 보세요. 내용은 같아야 하지만 각각 그 언어의 관습을 따라야 합니다.

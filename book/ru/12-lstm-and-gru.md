## Память с переключателями

Представьте, что вы читаете длинный роман и делаете заметки на одном листе бумаги. Простая RNN из главы 11 ведёт себя как читатель, который после каждого предложения переписывает весь лист заново по старым заметкам и новому предложению. После сотни переписываний детали из первой главы почти исчезают: каждое переписывание немного их размывает.

Более умный читатель делает три разных действия. Он **стирает** заметки, которые больше не нужны («герой в Москве» — но теперь он переехал в Казань). Он **добавляет** новые важные факты. А когда ему задают вопрос, он **зачитывает** только нужную часть заметок. Большая часть листа от предложения к предложению просто остаётся без изменений.

В этом и состоит идея сети **долгой краткосрочной памяти** (long short-term memory, LSTM), которую предложили Хохрайтер и Шмидхубер (1997). Название звучит странно, но означает оно «краткосрочную память (скрытое состояние RNN), которая может сохраняться долго». Механизм забывания добавили немного позже Герс, Шмидхубер и Камминс (2000). Именно эта версия LSTM используется сегодня.

Переключатели, которые стирают, добавляют и зачитывают, называются **вентилями** (gates). Вентиль — это вектор чисел от 0 до 1, который получается с помощью сигмоиды (глава 7). Мы поэлементно умножаем другой вектор на вентиль. Там, где вентиль близок к 1, значение проходит; там, где он близок к 0, значение блокируется. Сигмоида гладкая, поэтому вентили дифференцируемы. Сеть учится, *когда* открывать и закрывать их, с помощью обычного градиентного спуска.

## Устройство ячейки LSTM

На каждом временном шаге LSTM хранит не один вектор, а два:

- **состояние ячейки** (cell state) $c_t$ — это «лист заметок», долгосрочная память;
- скрытое состояние $h_t$ — то, что ячейка показывает внешнему миру и следующему слою.

На шаге $t$ ячейка получает вход $x_t$ и предыдущее скрытое состояние $h_{t-1}$. По ним она вычисляет три вентиля и один вектор-кандидат. Обозначим через $[h_{t-1}, x_t]$ конкатенацию двух векторов, а через $\sigma$ — сигмоиду:

$$f_t = \sigma\left(W_f [h_{t-1}, x_t] + b_f\right) \quad \text{(вентиль забывания)}$$

$$i_t = \sigma\left(W_i [h_{t-1}, x_t] + b_i\right) \quad \text{(входной вентиль)}$$

$$o_t = \sigma\left(W_o [h_{t-1}, x_t] + b_o\right) \quad \text{(выходной вентиль)}$$

$$\tilde{c}_t = \tanh\left(W_c [h_{t-1}, x_t] + b_c\right) \quad \text{(значения-кандидаты)}$$

Затем ячейка обновляет свою память и свой выход:

$$c_t = f_t \odot c_{t-1} + i_t \odot \tilde{c}_t$$

$$h_t = o_t \odot \tanh(c_t)$$

Здесь $\odot$ обозначает **поэлементное умножение** (element-wise multiplication), которое также называют произведением Адамара: $(a \odot b)_k = a_k b_k$. Прочитаем уравнения словами:

- **Вентиль забывания** (forget gate) $f_t$ решает для каждой компоненты памяти, какую долю старого значения $c_{t-1}$ сохранить.
- **Значения-кандидаты** (candidate values) $\tilde{c}_t$ — это новая информация, предложенная на основе текущего входа. Её значения лежат в интервале $(-1, 1)$.
- **Входной вентиль** (input gate) $i_t$ решает, какую долю кандидата записать в память.
- **Выходной вентиль** (output gate) $o_t$ решает, какие части памяти показать в виде $h_t$.

Каждая из четырёх матриц $W$ имеет размер $d_h \times (d_h + d_{in})$. На практике их хранят как одну большую матрицу размера $4d_h \times (d_h + d_{in})$, а результат делят на четыре части. Именно так устроен код ниже:

```python
import numpy as np

def sigmoid(z):
    return 1 / (1 + np.exp(-z))

rng = np.random.default_rng(0)
d_in, d_h = 3, 4
# Одна большая матрица для всех четырёх частей: забывание, вход, выход, кандидат
W = rng.normal(0, 0.5, (4 * d_h, d_in + d_h))
b = np.zeros(4 * d_h)
b[:d_h] = 1.0                                # смещение вентиля забывания = 1: «по умолчанию помнить»

def lstm_step(x, h, c):
    z = W @ np.concatenate([x, h]) + b
    f = sigmoid(z[0*d_h:1*d_h])              # вентиль забывания
    i = sigmoid(z[1*d_h:2*d_h])              # входной вентиль
    o = sigmoid(z[2*d_h:3*d_h])              # выходной вентиль
    g = np.tanh(z[3*d_h:4*d_h])              # значения-кандидаты
    c = f * c + i * g                        # обновляем состояние ячейки
    h = o * np.tanh(c)                       # новое скрытое состояние
    return h, c, f

h, c = np.zeros(d_h), np.zeros(d_h)
for x in rng.normal(size=(5, d_in)):
    h, c, f = lstm_step(x, h, c)
    print("forget gate:", np.round(f, 2), " c:", np.round(c, 2))

m, n = 100, 256                              # число параметров: вход m, скрытое состояние n
for name, k in [("RNN", 1), ("GRU", 3), ("LSTM", 4)]:
    print(name, k * (n * (m + n) + n))
```

(В этом коде векторы склеиваются в порядке $[x_t, h_{t-1}]$. Порядок не важен, если он везде одинаковый.) Обратите внимание на строку `b[:d_h] = 1.0`. Если инициализировать смещение вентиля забывания положительным значением, $f_t$ в начале обучения близко к 1. Тогда только что инициализированная LSTM по умолчанию помнит. Этот простой приём широко используется и обычно улучшает обучение.

## Почему LSTM помнит дольше

Вспомним из главы 11 причину затухающих градиентов. В простой RNN состояние полностью пересчитывается на каждом шаге, $h_t = \tanh(W_{hh} h_{t-1} + \dots)$. При каждом шаге назад градиент умножается на матрицу $W_{hh}$ и на производную $\tanh$.

Посмотрим ещё раз на обновление ячейки $c_t = f_t \odot c_{t-1} + i_t \odot \tilde{c}_t$. Новая память — это масштабированная старая память *плюс* что-то новое. Если проследить только этот прямой путь от $c_{t-1}$ к $c_t$ (и пренебречь меньшими косвенными путями через вентили), производная получается очень простой:

$$\frac{\partial c_t}{\partial c_{t-1}} \approx \operatorname{diag}(f_t)$$

На этом пути нет ни матрицы весов, ни производной $\tanh$. Через много шагов градиент умножается только на вентили забывания: $f_{k+1} \odot f_{k+2} \odot \dots \odot f_t$. Когда сеть хочет сохранить какую-то информацию, она учится делать соответствующие компоненты $f$ близкими к 1. Тогда градиент может пройти назад через сотни шагов почти без затухания. В исходной статье этот прямой, в основном аддитивный путь назван «каруселью постоянной ошибки» (constant error carousel). Та же идея — пропускать информацию по аддитивному пути — вернётся в другой форме как **остаточная связь** (residual connection) трансформера (глава 18).

Разберём пример в одномерном случае. Пусть $c_{t-1} = 2.0$, $f_t = 0.9$, $i_t = 0.2$ и $\tilde{c}_t = -0.5$. Тогда $c_t = 0.9 \cdot 2.0 + 0.2 \cdot (-0.5) = 1.8 - 0.1 = 1.7$. Бо́льшая часть старой памяти сохраняется, и к ней добавляется небольшая поправка. За 20 шагов при $f = 0.9$ старое содержимое умножается на $0.9^{20} \approx 0.12$, а при $f = 0.99$ — примерно на $0.82$. Сеть сама управляет длиной своей памяти.

LSTM не устраняет проблему полностью: вентили всё равно являются сигмоидами, и очень длинные зависимости остаются трудными. Но на практике LSTM может учить зависимости длиной в сотни шагов там, где простая RNN не справляется уже после нескольких десятков. Взрывающиеся градиенты по-прежнему возможны, поэтому обрезка градиентов всё ещё применяется.

## GRU: более лёгкая альтернатива

**Управляемый рекуррентный блок** (gated recurrent unit, GRU), который предложили Чо и соавторы (2014), сохраняет главную идею вентилей, но упрощает конструкцию. В нём нет отдельного состояния ячейки, есть только $h_t$. Вместо трёх вентилей используются два:

$$z_t = \sigma\left(W_z [h_{t-1}, x_t] + b_z\right) \quad \text{(вентиль обновления)}$$

$$r_t = \sigma\left(W_r [h_{t-1}, x_t] + b_r\right) \quad \text{(вентиль сброса)}$$

$$\tilde{h}_t = \tanh\left(W_h [r_t \odot h_{t-1}, x_t] + b_h\right)$$

$$h_t = (1 - z_t) \odot h_{t-1} + z_t \odot \tilde{h}_t$$

**Вентиль обновления** (update gate) $z_t$ играет роль одновременно вентиля забывания и входного вентиля: новое состояние — это интерполяция между старым состоянием и кандидатом. Если $z_t \approx 0$, старое состояние копируется вперёд без изменений. Это тот же аддитивный путь, который помогает LSTM. **Вентиль сброса** (reset gate) $r_t$ решает, какую часть старого состояния использовать при вычислении кандидата. Когда $r_t \approx 0$, блок «забывает» прошлое и ведёт себя так, будто начал читать заново. (Будьте внимательны: в некоторых библиотеках, включая PyTorch, роли $z_t$ и $1 - z_t$ в последнем уравнении поменяны местами. Модель та же, отличается только соглашение.)

Как они соотносятся по размеру? У простой RNN один блок весов размера $d_h \times (d_h + d_{in})$ плюс смещение. У GRU три таких блока, у LSTM — четыре. Последние строки кода печатают эти числа для размера входа 100 и размера скрытого состояния 256 (с одним вектором смещения на блок): 91 392 для RNN, 274 176 для GRU и 365 568 для LSTM.

Что же выбрать? Эмпирические сравнения (например, Чунг и соавторы, 2014; Юзефович и соавторы, 2015) показали, что обе модели явно превосходят простую RNN, но ни одна не выигрывает на всех задачах. GRU меньше и немного быстрее. LSTM чуть выразительнее и чаще использовалась по умолчанию. Обе модели можно делать многослойными и двунаправленными, точно как в главе 11.

## LSTM в истории языковых моделей

Несколько лет рекуррентные сети с вентилями были стандартным способом моделировать язык. Языковые модели на LSTM давали гораздо более низкую перплексию (глава 4), чем модели на n-граммах. Первые успешные системы нейронного машинного перевода были построены из LSTM — мы увидим это в главе 13. Контекстные векторные представления слов, такие как ELMo (Петерс и соавторы, 2018), получались из глубокой двунаправленной LSTM.

Однако вентили решили только проблему памяти. Две другие проблемы из главы 11 остались. Вычисления по-прежнему последовательные: для $h_t$ нужно $h_{t-1}$, поэтому длинные последовательности нельзя обрабатывать параллельно. И всё прошлое по-прежнему сжимается в один вектор фиксированного размера. Следующие две главы показывают, как механизм внимания устраняет второе ограничение, а глава 15 — как самовнимание устраняет первое.

## Итоги

- Вентили — это векторы значений из интервала $(0, 1)$, полученные с помощью сигмоиды. Они управляют потоком информации через поэлементное умножение.
- LSTM хранит состояние ячейки $c_t$ и использует вентили забывания, входа и выхода: $c_t = f_t \odot c_{t-1} + i_t \odot \tilde{c}_t$, $h_t = o_t \odot \tanh(c_t)$.
- Аддитивное обновление ячейки даёт градиенту путь без матриц весов, поэтому информация может сохраняться сотни шагов.
- Если инициализировать смещение вентиля забывания положительным значением, LSTM по умолчанию помнит.
- GRU объединяет ячейку и скрытое состояние и использует вентили обновления и сброса. У неё примерно три четверти параметров LSTM.
- Рекуррентные сети с вентилями исправляют память, но остаются последовательными и по-прежнему сжимают прошлое в вектор фиксированного размера.

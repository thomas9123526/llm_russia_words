## 모델은 자신이 틀렸다는 것을 어떻게 알까?

제7장의 끝에서 우리는 무작위 가중치를 가진 신경망을 만들었고, 그 출력에는 아무 의미가 없었습니다. 이 신경망에 "The cat sat on the"라는 문장을 보여 주었더니 다음 단어 *mat*에 겨우 0.01의 확률을 주었다고 합시다. 우리는 이것이 나쁘다는 것을 압니다. 하지만 컴퓨터에는 두 가지 질문에 대한 정확한 답이 필요합니다. *얼마나* 나쁜가? 그리고 더 좋아지려면 각 가중치를 *어느 방향으로* 움직여야 하는가?

첫 번째 질문의 답은 **손실 함수**(loss function)입니다. 손실 함수는 모델의 예측과 정답을 받아 음이 아닌 숫자 하나를 돌려주는데, 예측이 나쁘면 크고 좋으면 작습니다. 두 번째 질문의 답은 **경사 하강법**(gradient descent)입니다. 모든 가중치에 대한 손실의 도함수를 계산하고(제6장), 각 가중치를 손실이 줄어드는 방향으로 조금씩 움직입니다. 이 두 아이디어는 뉴런 두 개짜리 장난감 신경망부터 대규모 언어 모델까지, 모든 신경망 학습의 엔진입니다.

## 손실 함수: 오차를 하나의 숫자로 측정하기

모델의 모든 매개변수(가중치와 편향)를 하나의 벡터 $\theta$(그리스 문자 "세타")로 모읍니다. 매개변수가 $\theta$인 모델은 입력 $x$를 예측 $\hat{y} = f_\theta(x)$로 보냅니다. 학습 데이터에는 입력과 정답의 쌍 $(x_i, y_i)$가 $N$개 들어 있으며, 정답을 **목표값**(targets) 또는 **레이블**(labels)이라고 합니다. 데이터 전체에 대한 손실은 예제당 손실의 평균입니다.

$$L(\theta) = \frac{1}{N} \sum_{i=1}^{N} \ell(f_\theta(x_i),\ y_i).$$

여기서 $\ell$은 예제 하나의 손실입니다. 학습이란 $L(\theta)$를 작게 만드는 $\theta$를 찾는 것입니다.

**평균 제곱 오차.** 목표값이 실수일 때(가격, 온도, 점수를 예측할 때) 보통은 **평균 제곱 오차**(mean squared error, MSE)를 사용합니다.

$$L_{\text{MSE}} = \frac{1}{N} \sum_{i=1}^{N} (\hat{y}_i - y_i)^2.$$

차이 $\hat{y}_i - y_i$는 예제 $i$에서의 오차입니다. 제곱을 하면 모든 오차가 양수가 되고, 큰 오차는 작은 오차보다 훨씬 무겁게 벌을 받습니다. 오차 2는 오차 1보다 네 배의 비용이 듭니다.

**교차 엔트로피.** 목표값이 클래스일 때, 예를 들어 어휘 집합에서 다음 토큰을 고를 때, 모델은 $K$개의 클래스에 대한 확률 분포 $p$를 출력합니다(소프트맥스를 통해, 제6장). 정답 클래스의 번호를 $c$라고 합시다. **교차 엔트로피 손실**(cross-entropy loss)은 다음과 같습니다.

$$\ell_{\text{CE}} = -\log p_c.$$

정답 클래스의 확률만 중요합니다. 모델이 정답에 확률 1을 주면 손실은 $-\log 1 = 0$입니다. 확률이 작으면 손실은 커집니다: $-\log 0.5 \approx 0.69$, $-\log 0.01 \approx 4.6$. 제6장의 로짓 $(2.0,\ 1.0,\ 0.1)$을 다시 보면, 소프트맥스는 $(0.659,\ 0.242,\ 0.099)$입니다. 정답이 첫 번째 클래스라면 손실은 $-\log 0.659 \approx 0.417$이고, 세 번째 클래스라면 $-\log 0.099 \approx 2.317$입니다. 모델은 가능성이 낮다고 생각한 답에 "놀라고", 손실은 이 놀라움을 측정합니다.

왜 하필 이런 공식일까요? 이 공식은 **최대 우도**(maximum likelihood)라는 원리에서 나옵니다. 좋은 모델이라면 우리가 실제로 관찰한 데이터에 높은 확률을 주어야 합니다. 데이터 전체의 확률은 예제별 확률의 곱입니다. 로그를 취하면(제6장) 곱이 합으로 바뀌고, 앞에 음의 부호를 붙이면 "최대화"가 "최소화"로 바뀝니다. 따라서 평균 교차 엔트로피를 최소화하는 것은 데이터의 우도를 최대화하는 것과 같습니다. 그래서 교차 엔트로피를 **음의 로그 우도**(negative log-likelihood)라고도 부릅니다.

언어 모델에서는 텍스트의 모든 위치가 하나의 분류 문제입니다. 앞의 토큰들로부터 토큰 $w_t$를 예측해야 합니다. 학습 손실은 모든 위치에 대한 평균입니다.

$$L = -\frac{1}{T} \sum_{t=1}^{T} \log P_\theta(w_t \mid w_1, \dots, w_{t-1}).$$

이것은 제4장에서 만난 것과 같은 양입니다. **퍼플렉서티**(perplexity)는 단순히 $e^{L}$입니다. 손실이 2.0인 모델의 퍼플렉서티는 $e^{2} \approx 7.4$로, 매 스텝마다 약 일곱 개의 토큰 중 하나를 균등하게 고르는 것만큼 불확실하다는 뜻입니다. 손실을 줄이는 것과 퍼플렉서티를 줄이는 것은 같은 목표입니다.

## 경사 하강법: 비탈 아래로 걸어가기

손실을 하나의 지형이라고 상상해 봅시다. 땅 위의 각 점은 매개변수 $\theta$의 한 가지 선택이고, 그 점의 높이는 $L(\theta)$입니다. 우리는 안개 속 어딘가에 서 있어서 발밑의 경사만 느낄 수 있습니다. 내려가려면 가장 가파르게 내려가는 방향으로 한 걸음 내딛습니다. 제6장에서 배웠듯이 그래디언트 $\nabla L$은 가장 가파르게 *올라가는* 방향을 가리키므로, 우리는 그 반대 방향으로 걸어갑니다.

$$\theta \leftarrow \theta - \eta\, \nabla_\theta L(\theta).$$

여기서 $\leftarrow$는 "~로 바꾼다"는 뜻이고, $\nabla_\theta L$은 매개변수에 대한 손실의 그래디언트이며, $\eta$(그리스 문자 "에타")는 **학습률**(learning rate)로, 보폭을 조절하는 작은 양수입니다. 이런 갱신 한 번을 **스텝**(step) 또는 **반복**(iteration)이라고 합니다. 우리는 이것을 여러 번 되풀이합니다.

매개변수가 하나인 예제를 풀어 봅시다. $L(w) = (w - 3)^2$이라고 하면 최솟값은 $w = 3$에 있습니다. 도함수는 $L'(w) = 2(w - 3)$입니다. $w = 0$, $\eta = 0.1$에서 시작합니다.

| 스텝 | $w$ | $L(w)$ | $L'(w)$ |
|---|---|---|---|
| 0 | 0 | 9 | −6 |
| 1 | 0.6 | 5.76 | −4.8 |
| 2 | 1.08 | 3.69 | −3.84 |
| 3 | 1.464 | 2.36 | −3.07 |
| 5 | 2.017 | 0.97 | −1.97 |

스텝마다 $w$는 3에 가까워지고, 경사가 완만해질수록 보폭은 작아집니다. 실제로 여기서는 매 스텝마다 $w - 3$에 $1 - 2\eta = 0.8$이 곱해지므로, $t$ 스텝 후에는 $w_t = 3 - 3 \cdot 0.8^t$입니다.

실제 신경망은 이렇게 단순하지 않습니다. 손실 지형은 **비볼록**(non-convex)이어서 골짜기, 평평한 영역, 안장점이 많습니다. 경사 하강법은 가장 낮은 점이 아니라 *어떤* 충분히 낮은 점을 찾습니다. 놀랍게도 대규모 신경망에서는 실제로 이 방법이 대개 매우 잘 작동합니다.

## 학습률: 너무 작지도, 너무 크지도 않게

학습률은 가장 중요한 **하이퍼파라미터**(hyperparameter), 즉 학습하는 것이 아니라 우리가 직접 정하는 설정값입니다. 우리 예제에서 $w - 3$은 매 스텝마다 $(1 - 2\eta)$배가 됩니다. 값에 따라 어떤 일이 일어나는지 보십시오.

- $\eta = 0.01$: 배율은 0.98입니다. 학습이 수렴하지만 매우 느립니다.
- $\eta = 0.1$: 배율은 0.8입니다. 빠르고 매끄럽게 **수렴**(convergence)합니다.
- $\eta = 0.9$: 배율은 $-0.8$입니다. $w$가 매 스텝마다 최솟값을 넘어 반대편으로 뛰어가지만, 그래도 수렴합니다.
- $\eta = 1.1$: 배율은 $-1.2$입니다. 뛸 때마다 이전보다 멀리 뛰므로 학습이 **발산**(divergence)합니다. 손실이 한없이 커집니다.

실제 신경망에서도 같은 그림이 여러 차원에서 동시에 나타납니다. 학습률이 너무 작으면 계산을 낭비하고, 너무 크면 손실이 요동치거나 폭발합니다. 학습률이 너무 크다는 흔한 신호는 손실이 갑자기 `nan`이 되는 것입니다. 제9장에서는 보폭을 스스로 조정하는 Adam 같은 옵티마이저를, 제10장에서는 학습 도중 $\eta$를 바꾸는 학습률 스케줄을 소개합니다.

유용한 사실을 하나 더 알아 둡시다. 소프트맥스 뒤에 교차 엔트로피를 쓰면, 로짓에 대한 그래디언트가 놀랍도록 간단한 모양이 됩니다.

$$\frac{\partial \ell_{\text{CE}}}{\partial z_k} = p_k - y_k.$$

여기서 $y_k$는 정답 클래스에서 1이고 나머지에서 0입니다(**원-핫**(one-hot) 벡터). 우리 예제에서 첫 번째 클래스가 정답이라면 그래디언트는 $(0.659 - 1,\ 0.242,\ 0.099) = (-0.341,\ 0.242,\ 0.099)$입니다. 따라서 경사 하강법은 정답 클래스의 로짓은 올리고 나머지는 내리며, 각각 얼마나 틀렸는지에 비례해서 움직입니다.

## 코드로 보는 경사 하강법

$y = 2x + 1$에서 만든, 잡음이 섞인 점들에 직선 $\hat{y} = wx + b$를 맞춰 봅시다. 손실은 MSE이고, 편도함수는 다음과 같습니다.

$$\frac{\partial L}{\partial w} = \frac{2}{N} \sum_i (\hat{y}_i - y_i)\, x_i, \qquad \frac{\partial L}{\partial b} = \frac{2}{N} \sum_i (\hat{y}_i - y_i).$$

```python
import numpy as np

# 장난감 데이터: y = 2x + 1 에 약간의 잡음을 더함
rng = np.random.default_rng(0)
x = rng.uniform(-1, 1, size=100)
y = 2.0 * x + 1.0 + 0.1 * rng.normal(size=100)

w, b = 0.0, 0.0                  # 0에서 시작
lr = 0.1                         # 학습률
for step in range(201):
    err = (w * x + b) - y        # 예측값 빼기 목표값
    loss = np.mean(err ** 2)     # 평균 제곱 오차
    if step % 50 == 0:
        print(f"step {step:3d}  loss {loss:.4f}  w {w:.3f}  b {b:.3f}")
    grad_w = 2 * np.mean(err * x)    # dL/dw
    grad_b = 2 * np.mean(err)        # dL/db
    w -= lr * grad_w                 # 그래디언트 반대 방향으로 한 스텝
    b -= lr * grad_b
```

출력을 보면 손실이 약 2.87에서 약 0.009로 떨어지고, 매개변수는 $w \approx 1.99$, $b \approx 0.99$에 가까워집니다. 정확히 2와 1에 도달하지 않는 것은 데이터에 잡음이 있기 때문입니다. 손실은 잡음 수준(약 $0.1^2 = 0.01$) 아래로 내려갈 수 없습니다.

PyTorch에서 교차 엔트로피는 함수 하나입니다. 이 함수는 확률이 아니라 가공되지 않은 로짓을 받고, 내부에서 수치적으로 안정적인 방식으로 소프트맥스를 적용합니다.

```python
import torch
import torch.nn.functional as F

logits = torch.tensor([[2.0, 1.0, 0.1]])            # 예제 하나, 클래스 세 개
print(F.cross_entropy(logits, torch.tensor([0])))   # 정답 클래스 0: 0.417
print(F.cross_entropy(logits, torch.tensor([2])))   # 정답 클래스 2: 2.317
```

여기서는 그래디언트를 손으로 계산했습니다. 매개변수가 수백만 개이고 층이 많은 신경망에서는 불가능한 일입니다. 제9장에서는 이 모든 도함수를 자동으로 계산하는 알고리즘인 역전파를 배웁니다.

## 요약
- 손실 함수는 예측의 품질을 하나의 숫자로 바꾸며, 학습은 데이터에 대한 그 평균을 최소화합니다.
- 평균 제곱 오차는 실수 목표값에, 교차 엔트로피 $-\log p_c$는 클래스에 사용합니다.
- 교차 엔트로피를 최소화하는 것은 최대 우도와 같으며, 언어 모델에서 퍼플렉서티는 $e^{L}$입니다.
- 경사 하강법은 $\theta \leftarrow \theta - \eta \nabla L$을 반복하여 매개변수를 그래디언트 반대 방향으로 움직입니다.
- 학습률은 보폭을 조절합니다. 너무 작으면 느리고, 너무 크면 진동하거나 발산합니다.
- 소프트맥스와 교차 엔트로피를 함께 쓰면 로짓에 대한 그래디언트는 $p - y$입니다.

## 연습 문제
1. 교차 엔트로피 손실이 왜 정답 클래스의 확률에만 의존하는지, 그리고 그 확률이 0에 가까워지면 손실이 어떻게 되는지 자신의 말로 설명해 보십시오.
2. 어떤 언어 모델의 테스트 텍스트에 대한 평균 교차 엔트로피가 3.0입니다. 퍼플렉서티는 얼마입니까? 퍼플렉서티 20에 해당하는 손실은 얼마입니까?
3. $L(w) = (w - 3)^2$에서 $w = 0$으로 시작해 $\eta = 0.9$로 세 스텝을 손으로 계산해 보십시오. 그다음 $\eta = 1.1$로 세 스텝을 계산하고, 무엇이 보이는지 설명해 보십시오.
4. 위 코드에서 `lr = 0.01`과 `lr = 1.2`를 시도해 보십시오. 첫 번째 경우 손실이 0.02 아래로 내려가려면 몇 스텝이 필요합니까? 두 번째 경우에는 무슨 일이 일어나며, 그 이유는 무엇입니까?

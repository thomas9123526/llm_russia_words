# 제3과. 생격 심화: 복수 생격과 수사 (1 / 2–4 / 5+)

> **중급 러시아어** · 수준: A2 · **배울 내용:** 생격의 모든 용법 · 복수 생격 만드는 법 · 수사와 명사: 1 / 2–4 / 5+

## 대화

*디마와 민호가 기숙사 부엌에서 아침을 먹고 있습니다.*

**Дима:** Минхо, сколько у тебя сегодня пар?
*디마: 민호야, 오늘 수업 몇 개 있어?*

**Минхо:** Три па́ры: две лекции и один семина́р.
*민호: 세 개. 강의 두 개, 세미나 하나.*

**Дима:** А сколько студентов в твоей гру́ппе?
*디마: 너희 반에는 학생이 몇 명이야?*

**Минхо:** Двенадцать челове́к: пять студентов из России, четыре студе́нтки из Кита́я и три аспира́нта из Кореи.
*민호: 열두 명. 러시아에서 온 학생 다섯 명, 중국에서 온 여학생 네 명, 한국에서 온 대학원생 세 명.*

**Дима:** Интересно! А что вы делаете на семинаре?
*디마: 재미있네! 세미나에서는 뭐 해?*

**Минхо:** Мы читаем статьи о моделях. На этой неде́ле у нас пять статей.
*민호: 모델에 관한 논문을 읽어. 이번 주에는 논문이 다섯 편이야.*

**Дима:** Пять статей за неделю? Это много!
*디마: 일주일에 논문 다섯 편? 많다!*

**Минхо:** Да. И для моей модели нужно много данных. Мне нужен миллио́н текстов.
*민호: 응. 그리고 내 모델에는 데이터가 많이 필요해. 텍스트가 백만 개 필요해.*

**Дима:** Миллион текстов! А сколько это токенов?
*디마: 텍스트 백만 개! 그럼 토큰으로는 몇 개야?*

**Минхо:** Приме́рно два миллиа́рда токенов.
*민호: 대략 20억 토큰.*

**Дима:** Без хорошего компьютера это трудно.
*디마: 좋은 컴퓨터 없이는 어렵겠다.*

**Минхо:** Да. Но на нашей кафедре восемь новых се́рверов.
*민호: 응. 그래도 우리 학과에 새 서버가 여덟 대 있어.*

**Дима:** Отлично! Ну, уда́чи!
*디마: 잘됐다! 그럼, 행운을 빌어!*

## 문법

생격은 주격 다음으로 **가장 자주 쓰이는 격**입니다. 학술 러시아어에서는 어디에나 있습니다: *обучение модели*(모델의 학습), *количество токенов*(토큰의 수), *результаты эксперимента*(실험의 결과). 한국어 '의'를 떠올리면 되는데, 러시아어는 순서가 반대라는 점에 주의하세요: **'모델의 학습' = обучение модели**(학습 + 모델의). 이번 과에서는 생격의 모든 용법과 복수 생격을 배우고, 수사와 함께 쓰는 법을 익힙니다.

### 1. 생격을 쓰는 경우

| 용법 | 예문 |
|---|---|
| ~의, 소유 | статья́ Ива́на Петро́вича, да́нные ка́федры, коли́чество то́кенов |
| 부재: нет, не́ было, не бу́дет | У меня́ нет словаря́. Вчера́ не́ было ле́кции. За́втра не бу́дет семина́ра. |
| 수량: мно́го, ма́ло, ско́лько, не́сколько | мно́го да́нных, ма́ло вре́мени, не́сколько стате́й |
| 수사 뒤 (3절) | два студе́нта, пять студе́нтов |
| 전치사 у, из, от, до, для, без, по́сле, о́коло, кро́ме, во вре́мя 뒤 | из Кита́я, для мое́й моде́ли, без компью́тера, по́сле семина́ра, о́коло университе́та |
| 날짜: "~월의" | два́дцать седьмо́е ноября́ — 11월 27일 |

*нет*의 과거와 미래는 **не́ было**와 **не бу́дет**입니다. 주어가 없으므로 성이나 수에 따라 변하지 않습니다. 없는 것은 생격으로 씁니다: *У меня не было словаря. В комнате не было студентов.*

### 2. 복수 생격 만들기

**단수 주격의 마지막 글자**를 보세요. 그것이 어미를 알려 줍니다.

| 단수 주격의 끝 | 복수 생격 | 예 |
|---|---|---|
| 경자음 (남성) | **-ов** | студе́нт → студе́нтов, то́кен → то́кенов, текст → те́кстов |
| -й (남성) | **-ев** | музе́й → музе́ев, трамва́й → трамва́ев |
| -ц (남성) | **-ев** (강세 없음) / **-о́в** (강세 있음) | ме́сяц → ме́сяцев, оте́ц → отцо́в |
| ж, ш, ч, щ (남성) | **-ей** | врач → враче́й, нож → ноже́й, каранда́ш → карандаше́й, това́рищ → това́рищей |
| -ь (남성·여성) | **-ей** | слова́рь → словаре́й, рубль → рубле́й, тетра́дь → тетра́дей, нейросе́ть → нейросете́й |
| -а (여성), -о (중성) | **어미 없음** | ко́мната → ко́мнат, кни́га → книг, па́ра → пар, сло́во → слов |
| 자음 + -я (여성) | **-ь** | неде́ля → неде́ль |
| -ья (여성) | **-ей** | статья́ → стате́й, семья́ → семе́й |
| -ия (여성), -ие (중성) | **-ий** | ле́кция → ле́кций, зда́ние → зда́ний, оконча́ние → оконча́ний |
| -е (-ие 제외, 중성) | **-ей** | мо́ре → море́й, по́ле → поле́й |

**어미 없음 + 모음 삽입.** 어미가 없어져서 끝에 자음 두 개가 남으면, 그 사이에 **о**나 **е**가 들어가는 경우가 많습니다:

- студе́нтка → студе́нток, оши́бка → оши́бок, де́вушка → де́вушек, ру́чка → ру́чек
- письмо́ → пи́сем, окно́ → о́кон, сестра́ → сестёр

**불규칙·특수 형태** (외워 두세요):

| 단수 주격 | 복수 주격 | 복수 생격 |
|---|---|---|
| челове́к | лю́ди | люде́й (수사 뒤: челове́к) |
| год | го́ды | лет (수사와 мно́го 뒤) |
| ребёнок | де́ти | дете́й |
| друг | друзья́ | друзе́й |
| брат | бра́тья | бра́тьев |
| день | дни | дней |
| раз (번, 회) | разы́ | раз |
| — | де́ньги (돈) | де́нег |

복수 생격 형용사는 모든 성에서 **-ых / -их**입니다(제2과): *много новых студентов, нет хороших словарей, несколько интересных статей*.

### 3. 수사와 명사: 1 / 2–4 / 5+

수사 뒤에서 명사는 세 가지 형태 중 하나가 됩니다. **수의 마지막 단어만 중요합니다**: 21은 1처럼, 23은 3처럼, 25는 5처럼 씁니다. 단, **11, 12, 13, 14**는 항상 복수 생격입니다.

| 수 | 명사 형태 | 예 |
|---|---|---|
| 1, 21, 31, 101 … | 단수 주격 | оди́н студе́нт, одна́ статья́, одно́ сло́во, два́дцать оди́н то́кен |
| 2, 3, 4, 22–24, 32–34 … | 단수 생격 | два студе́нта, две статьи́, три сло́ва, два́дцать два то́кена |
| 5–20, 25–30, 100, 1000 … | 복수 생격 | пять студе́нтов, оди́ннадцать стате́й, сто слов |
| мно́го, ма́ло, ско́лько, не́сколько | 복수 생격(셀 수 있는 것) / 단수 생격(셀 수 없는 것) | мно́го стате́й, не́сколько дней, мно́го вре́мени, ма́ло воды́ |

한국어에서는 "학생 다섯 명", "논문 두 편"처럼 수 뒤에 단위 명사(명, 편, 개)를 붙이지만, 러시아어에는 단위 명사가 없고 대신 **명사의 어미가 수에 따라 바뀝니다**. "1 / 2–4 / 5+" 세 칸만 기억하면 됩니다.

**1과 2의 성.** *Один*은 명사와 성이 일치합니다: *оди́н семина́р, одна́ ле́кция, одно́ зда́ние*. *Два*는 남성·중성 명사, *две*는 여성 명사와 씁니다: *два семина́ра, два сло́ва*, 그러나 *две ле́кции*.

**Тысяча, миллион, миллиард**는 그 자체가 명사입니다. 이것들도 1 / 2–4 / 5+ 규칙을 따르고, 그 뒤의 명사는 항상 복수 생격입니다:

- одна́ ты́сяча рубле́й, две ты́сячи рубле́й, пять ты́сяч рубле́й
- оди́н миллио́н те́кстов, два миллио́на те́кстов, пять миллио́нов те́кстов
- два миллиа́рда то́кенов

숫자와 아주 자주 쓰이는 세 단어:

| | 1 | 2–4 | 5+ |
|---|---|---|---|
| год | оди́н год | два го́да | пять лет |
| челове́к | оди́н челове́к | два челове́ка | пять челове́к |
| день | оди́н день | два дня | пять дней |

그래서: *Мне тридцать пять лет. В группе двенадцать человек.* (수사 없이: *много людей*.)

**수사와 형용사.** 5 이상 뒤에서 형용사는 명사처럼 복수 생격입니다: *пять новых студентов, восемь новых серверов*. 2–4 뒤에서 남성·중성 명사는 형용사가 복수 생격입니다: *два новых студента, три больших здания*. 여성 명사와는 복수 주격이 더 흔합니다: *две новые статьи*.

이번 과는 주어나 목적어 자리의 수사만 다룹니다. 전치사 뒤에서는 수사 자체도 변합니다(*из двух групп, о пяти статьях*). 이런 형태는 나중에 배웁니다.

## 문화

러시아 대학에서 수업 한 단위는 **па́ра**('쌍')라고 부릅니다. 예전에 45분 수업 두 개를 붙여서 했기 때문입니다. 한 *пара*는 **90분**이고, 보통 중간에 짧은 휴식이 있습니다. 학생들은 *У меня сегодня три пары*(오늘 수업이 세 개 있어), *Первая пара начинается в девять*(1교시는 9시에 시작해)라고 말합니다. 시간표(*расписа́ние*)도 시간이 아니라 пара 단위로 짜여 있습니다. 한국 대학의 '1교시, 2교시'와 비슷하지만 한 교시가 훨씬 깁니다. 대학원생(*аспира́нт*)은 학부생보다 수업이 적지만 직접 세미나를 가르치는 경우가 많습니다.

## 복습

- 생격을 언제 쓰는지 압니다: '~의', нет / не было / не будет, 수량, 수사, 전치사.
- 복수 생격을 만들 수 있습니다: -ов, -ев, -ей, -ий, 또는 어미 없음(모음 삽입).
- 수사와 명사를 함께 쓸 수 있습니다: *один студент, два студента, пять студентов*.
- 특수 형태 *пять лет, пять человек, много людей, много денег*을 압니다.
- 데이터 규모를 말할 수 있습니다: *миллион текстов, два миллиарда токенов*.

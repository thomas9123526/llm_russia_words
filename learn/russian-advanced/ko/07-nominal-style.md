## 본문

민호는 러시아 학술지에 낼 논문을 준비하고 있습니다. 아래는 "데이터와 학습" 절의 일부와 지도 교수가 여백에 적은 메모입니다. 먼저 러시아어를 읽고, 각 단락 뒤의 번역으로 확인하세요.

**2. Подготовка данных и обучение модели**

Для решения поставленной задачи был сформирован корпус русскоязычных научных текстов объёмом около двух миллиардов токенов (здесь и далее все числа приводятся в качестве примера). Формирование корпуса включало несколько этапов: сбор текстов из открытых источников, удаление дубликатов, фильтрацию по качеству и нормализацию разметки.

*제기된 과제를 해결하기 위해 약 20억 토큰 규모의 러시아어 학술 텍스트 코퍼스를 구축하였다(이하 모든 수치는 예시이다). 코퍼스 구축은 공개 출처로부터의 텍스트 수집, 중복 제거, 품질 필터링, 마크업 정규화의 여러 단계로 이루어졌다.*

На этапе фильтрации осуществлялась проверка каждого документа по ряду критериев. Удалению подвергались тексты с высокой долей неалфавитных символов, а также документы длиной менее ста слов. В результате фильтрации объём корпуса сократился примерно на треть.

*필터링 단계에서는 각 문서를 여러 기준에 따라 검사하였다. 비알파벳 문자의 비율이 높은 텍스트와 100단어 미만의 문서는 삭제 대상이 되었다. 필터링 결과 코퍼스 규모는 약 3분의 1 줄어들었다.*

Токенизация проводилась с помощью токенизатора, обученного на том же корпусе. Выбор размера словаря обусловлен компромиссом между скоростью обработки и качеством представления редких слов. Увеличение словаря приводит к сокращению длины последовательностей, однако сопровождается ростом числа параметров во входном слое модели.

*토큰화는 같은 코퍼스로 학습한 토크나이저를 사용하여 수행하였다. 어휘 크기의 선택은 처리 속도와 희귀어 표현 품질 사이의 절충에 따른 것이다. 어휘를 늘리면 시퀀스 길이가 줄어들지만, 모델 입력층의 파라미터 수 증가가 수반된다.*

Дообучение базовой модели выполнялось в два этапа. На первом этапе проводилось дополнительное предобучение на собранном корпусе, на втором — настройка модели на инструкциях. В ходе обучения осуществлялся контроль значения функции потерь на отложенной выборке. При отсутствии улучшения на трёх контрольных точках подряд обучение прекращалось.

*기반 모델의 미세 조정은 두 단계로 수행하였다. 첫 단계에서는 수집한 코퍼스로 추가 사전 학습을, 둘째 단계에서는 인스트럭션 튜닝을 실시하였다. 학습 중에는 홀드아웃 세트에서 손실 함수 값을 모니터링하였다. 체크포인트 세 개 연속으로 개선이 없으면 학습을 중단하였다.*

Оценка качества модели проводилась на двух наборах данных. Для обеспечения сопоставимости результатов все модели оценивались в одинаковых условиях. Сравнение с исходной моделью позволяет определить вклад каждого этапа дообучения в итоговое качество.

*모델 품질 평가는 두 개의 데이터셋에서 수행하였다. 결과의 비교 가능성을 확보하기 위해 모든 모델을 동일한 조건에서 평가하였다. 원래 모델과 비교하면 미세 조정 각 단계가 최종 품질에 기여한 정도를 파악할 수 있다.*

## 문법

러시아어 학술 문체는 행동을 명사로 표현하기를 좋아합니다. "우리는 데이터를 정제했다" 대신 очистка данных(데이터 정제), "정확도가 올라간다" 대신 рост точности(정확도의 상승)라고 씁니다. 이것을 **명사적 문체**(именной стиль)라고 합니다. 적당히 쓰면 글이 간결하고 비인칭적이 되지만, 지나치면 아무도 읽을 수 없는 생격의 사슬이 생깁니다. 이 과에서는 두 측면을 모두 살펴봅니다.

> **한국어 팁:** 한국어 논문도 "분석을 수행하였다", "검증을 실시하였다"처럼 한자어 명사 + 기능 동사를 즐겨 씁니다. 러시아어 провести анализ, осуществить проверку가 바로 이 구조입니다. 또 한국어에서 "~의 ~의 ~의"가 이어지면 읽기 어렵듯, 러시아어에서도 생격이 줄줄이 이어지면 읽기 어렵습니다.

### 1. 동사 파생 명사의 형성

동사 파생 명사(отглагольное существительное)는 행동이나 과정을 가리킵니다. 이미 обучение, исследование, решение 같은 단어를 많이 알고 있습니다. 주요 형태는 다음과 같습니다.

| 접미사 | 성 | 예 |
|---|---|---|
| -ние / -ение / -ание | ср. | обучать → обучение; использовать → использование; создать → создание; описать → описание; сократить → сокращение |
| -тие | ср. | развить → развитие; открыть → открытие |
| -ка | ж. | проверить → проверка; оценить → оценка; обработать → обработка; разработать → разработка; разметить → разметка; настроить → настройка |
| -ция (-ировать / -овать 동사) | ж. | токенизировать → токенизация; генерировать → генерация; оптимизировать → оптимизация; фильтровать → фильтрация; нормализовать → нормализация |
| 접미사 없음 | м. | расти → рост; выбрать → выбор; анализировать → анализ; отобрать → отбор; перейти → переход; сдвинуть → сдвиг |

기억할 점:

- **자음 교체**는 동사와 같은 규칙을 따릅니다: сократить → сокращение (т → щ), снизить → снижение (з → ж), повысить → повышение (с → ш), ускорить → ускорение, увеличить → увеличение.
- **상(相)이 사라집니다.** сокращение словаря는 과정("어휘를 줄이는 중")도, 결과("줄인 뒤")도 뜻할 수 있습니다. 문맥이나 전치사(в ходе, после)가 어느 쪽인지 알려 줍니다.
- 한 상의 짝에서 **명사가 두 개** 나오기도 합니다: оценивание(평가하는 과정)과 оценка(평가; 점수, 추정치). 논문에서는 оценка가 훨씬 흔합니다.
- 많은 동사 파생 명사에는 구체적인 둘째 뜻이 있습니다: разметка = 주석 작업 / 주석 자체, предложение = 제안하기 / 문장, 제안.

### 2. 동사구를 명사구로 바꾸기

동사를 명사로 바꾸면 주변 단어의 형태도 바뀝니다. 다음 규칙으로 거의 모든 경우를 처리할 수 있습니다.

| 동사구 | 명사구 | 규칙 |
|---|---|---|
| обучать **модель** | обучение **модели** | 직접 목적어(대격) → 생격 |
| **точность** растёт | рост **точности** | 자동사의 주어 → 생격 |
| **эксперты** размечают данные | разметка данных **экспертами** | 행위자 → 조격 (목적어는 생격) |
| влиять **на качество** | влияние **на качество** | 전치사는 그대로 |
| зависеть **от размера** | зависимость **от размера** | 전치사는 그대로 |
| соответствовать **требованиям** | соответствие **требованиям** | 여격은 그대로 |
| управлять **процессом** | управление **процессом** | 조격은 그대로 |
| **быстро** растёт | **быстрый** рост | 부사 → 형용사 |
| **значительно** сократить | **значительное** сокращение | 부사 → 형용사 |

동사 파생 명사 뒤에 자연스러운 생격 "자리"는 하나뿐입니다. 동사에 주어와 목적어가 모두 있으면 목적어가 생격을 차지하고 행위자는 조격으로 갑니다: эксперты оценили ответы → оценка ответов экспертами(전문가들에 의한 답변 평가).

**기능 동사.** 동사 파생 명사는 보통 자체 의미가 거의 없는 동사와 함께 쓰입니다. 한국어 "수행하다, 실시하다, 미치다"에 해당합니다. 짝으로 외우세요.

| 기능 동사 + 명사 | 뜻 | 예 |
|---|---|---|
| проводить / провести + acc. | 수행하다, 실시하다 | провести анализ, эксперимент, сравнение |
| осуществлять / осуществить + acc. | 수행하다 (더 격식적) | осуществлять контроль, проверку |
| выполнять / выполнить + acc. | 수행하다 | выполнять обучение, оценку |
| оказывать / оказать влияние на + acc. | ~에 영향을 미치다 | оказывать влияние на качество |
| принимать / принять участие в + prep. | ~에 참여하다 | принять участие в разметке |
| вносить / внести вклад в + acc. | ~에 기여하다 | внести вклад в изучение моделей |
| подвергаться + dat. | ~을 받다, ~의 대상이 되다 | подвергаться обработке, удалению, анализу |
| приводить / привести к + dat. | ~을 초래하다, ~으로 이어지다 | приводить к росту, к снижению |
| сопровождаться + instr. | ~이 수반되다 | сопровождаться ростом затрат |
| обеспечивать / обеспечить + acc. | 확보하다, 보장하다 | обеспечить сопоставимость результатов |

**종속절 대신 전치사구.** 종속절 하나를 "전치사 + 동사 파생 명사"로 압축할 수 있습니다. 학술 문체의 가장 전형적인 특징 중 하나입니다. 한국어의 "~ 시", "~ 과정에서", "~ 후", "~을 위해"와 비슷합니다.

| 명사구 | 대신하는 절 |
|---|---|
| **при** обучении модели (prep.) | когда модель обучается (모델 학습 시) |
| **в ходе** экспериментов (gen.) | пока проводились эксперименты (실험 과정에서) |
| **после** завершения обучения (gen.) | после того как обучение завершилось (학습 완료 후) |
| **до** начала обучения (gen.) / **перед** обучением (instr.) | до того как / перед тем как начали обучение (학습 전) |
| **в результате** фильтрации (gen.) | так как данные отфильтровали, … (필터링 결과) |
| **с целью** / **для** повышения точности (gen.) | чтобы повысить точность (정확도 향상을 위해) |
| **за счёт** сокращения словаря (gen.) | так как словарь сократили (향상의 메커니즘: ~ 덕분에) |
| **путём** расширения словаря (gen.) | тем, что расширили словарь (방법: ~을 통해) |
| **при отсутствии** улучшения (gen.) | если улучшения нет (개선이 없을 경우) |
| **по завершении** обучения (gen.) | когда обучение завершилось (학습이 끝나면) |

**по завершении**의 철자(по + 전치격, 어미 -и)에 주의하세요. 원어민도 자주 틀립니다.

### 3. 명사 사슬과 끊는 방법

동사 파생 명사는 생격을 하나 데려오고, 그 생격이 또 동사 파생 명사라서 자기 생격을 데려옵니다. 그 결과가 **명사 사슬**입니다.

- исследование влияния изменения размера словаря токенизатора — 토크나이저의 어휘의 크기의 변화의 영향의 연구

생격이 두세 개 이어지는 것은 러시아어에서 정상입니다(размер словаря токенизатора). 네 개부터는 독자가 너무 많은 것을 기억해야 합니다. 또 다른 위험은 **중의성**입니다.

- Оценка ответов модели экспертов… — 누구의 답변이고 누구의 평가인가? "전문가들의 모델"로도, "전문가들에 의한 평가"로도 읽힙니다.

사슬을 끊는 다섯 가지 방법:

| 방법 | 고치기 전 | 고친 후 |
|---|---|---|
| 명사 대신 동사 | Целью является исследование влияния размера словаря на скорость | Цель — исследовать, как размер словаря влияет на скорость |
| 생격 대신 형용사 | качество перевода текстов машиной | качество машинного перевода |
| 전치사 | алгоритм поиска ошибок разметки данных | алгоритм поиска ошибок в разметке данных |
| который 절 | анализ ошибок модели перевода научных текстов | анализ ошибок, которые модель допускает при переводе научных текстов |
| 행위자 + 형동사 | оценка ответов модели экспертов | оценка ответов модели, проведённая экспертами |

실용적인 규칙: **단계는 명사로, 주장은 동사로.** 방법의 단계(сбор, фильтрация, токенизация, оценка)는 그것에 "대해" 말하므로 명사가 자연스럽습니다. 연구 결과와 목적은 동사로 표현하는 편이 좋습니다: Мы показываем, что…; Цель работы — исследовать, как…

## 문화

**Канцелярит.** 작가 코르네이 추콥스키가 1960년대에 병명을 본떠 канцелярит(관청병)이라는 말을 만들었습니다. 공문서에서 일상 러시아어로 퍼진 관료적 문체를 가리키는 말입니다. 그 증상은 바로 명사적 문체의 과잉입니다: осуществление проведения проверки(검사의 실시의 수행), имеет место снижение(감소가 발생한다), 문장마다 является + 명사. 러시아의 편집자와 지도 교수는 이 단어를 경고로 사용하며, 이반 페트로비치의 메모가 전형적인 예입니다. 학술 문체는 канцелярит가 아닙니다. 좋은 러시아어 논문은 말을 줄여 줄 때만 동사 파생 명사를 쓰고, 무게만 더할 때는 버립니다. 동사로 더 짧게 말할 수 있다면 동사를 쓰세요.

점검표:
- 단계를 가리키는 동사 파생 명사가 세 개 이상인가 (сбор, обработка, фильтрация, токенизация…);
- 기능 동사 구문이 하나 이상인가 (проводиться, выполняться + 동사 파생 명사);
- 전치사 명사구가 하나 이상인가 (для / с целью, в результате, при, в ходе);
- 생격이 서너 개 넘게 이어지는 사슬이 없는가;
- осуществлять / осуществляться를 한 번 이하로 썼는가;
- «я» 대신 비인칭 또는 피동 형태를 썼는가.

## 복습

- -ние, -тие, -ка, -ция, 무접미사 형태의 동사 파생 명사를 만들고 그 성을 알 수 있습니다.
- 동사구를 명사구로 바꿀 수 있습니다: 목적어와 자동사 주어 → 생격, 행위자 → 조격, 전치사는 유지, 부사 → 형용사.
- 주요 기능 동사를 압니다: проводить анализ, оказывать влияние на, вносить вклад в, подвергаться обработке, приводить к.
- 절을 при / в ходе / после / с целью / за счёт / путём + 동사 파생 명사로 압축하고, по завершении를 바르게 씁니다.
- 명사 사슬이나 중의적인 생격을 찾아 동사, 형용사, 전치사, 형동사로 끊을 수 있습니다.
- канцелярит가 무엇이고 어떻게 피하는지 압니다.

# 제12과. 비교급과 최상급 (больше, лучше, самый эффективный)

> **중급 러시아어** · 수준: B1 · **배울 내용:** 단순 비교급(быстрее, лучше)과 чем 또는 생격으로 비교하는 법 · 합성 비교급(более эффективный) · 최상급(самый точный, лучше всех)

## 대화

*세미나. 민호가 실험 결과를 발표하고 있습니다.*

**Минхо:** На этом слайде вы видите результаты. Наша модель работает быстре́е, чем ба́зовая.
*이 슬라이드에서 결과를 보실 수 있습니다. 저희 모델은 베이스라인보다 빠르게 작동합니다.*

**Анна:** Наско́лько быстрее?
*얼마나 더 빨라요?*

**Минхо:** Приме́рно в два ра́за. И она точне́е старой модели на три проце́нта.
*약 두 배입니다. 그리고 기존 모델보다 3퍼센트 더 정확합니다.*

**Иван Петрович:** А какая модель са́мая точная?
*그럼 가장 정확한 모델은 어느 것인가요?*

**Минхо:** Самая точная — большая модель, но она гора́здо ме́дленнее и доро́же.
*가장 정확한 것은 대형 모델이지만, 훨씬 느리고 비용이 많이 듭니다.*

**Анна:** Значит, ваш метод бо́лее эффекти́вный?
*그러니까 당신 방법이 더 효율적이라는 거죠?*

**Минхо:** Да. Для маленьких данных это самый эффективный метод из тех, которые мы проверили.
*네. 소규모 데이터에서는 저희가 검증한 방법 중 가장 효율적인 방법입니다.*

**Иван Петрович:** Хорошо. Но на русских текстах результаты ху́же, чем на английских. Почему?
*좋아요. 그런데 러시아어 텍스트에서는 결과가 영어보다 나쁘네요. 왜 그렇죠?*

**Минхо:** Потому что русских данных у нас ме́ньше. Чем бо́льше данных, тем лу́чше результат.
*러시아어 데이터가 더 적기 때문입니다. 데이터가 많을수록 결과가 좋아집니다.*

**Иван Петрович:** Это одна из самых важных пробле́м. Попро́буйте собрать больше данных как мо́жно скоре́е.
*그게 가장 중요한 문제 중 하나예요. 되도록 빨리 데이터를 더 모아 보세요.*

**Минхо:** Хорошо, Иван Петрович. Спасибо за сове́т!
*알겠습니다, 교수님. 조언 감사합니다!*

## 문법

### 1. 단순 비교급: быстрее, лучше

단순 비교급은 형용사 어간에 **-ее**를 붙여 만듭니다. 한국어의 "더 ~한"에 해당합니다:

| 형용사 | 비교급 |
|---|---|
| бы́стрый — 빠른 | быстре́е |
| но́вый — 새로운 | нове́е |
| то́чный — 정확한 | точне́е |
| сло́жный — 복잡한 | сложне́е |
| интере́сный — 재미있는 | интере́снее |
| эффекти́вный — 효율적인 | эффекти́внее |
| ме́дленный — 느린 | ме́дленнее |

알아야 할 세 가지:
- **변하지 않습니다.** 성, 수, 격이 없습니다: *модель быстрее, метод быстрее, модели быстрее*.
- **부사와 형태가 같습니다:** *быстро → быстрее*. *Модель быстрее*(모델이 더 빠르다)도, *модель работает быстрее*(더 빠르게 작동한다)도 됩니다.
- **강세:** 짧은 형용사는 보통 강세가 -е́е로 옮겨 갑니다(*быстре́е, нове́е, точне́е*). 긴 형용사는 어간에 그대로 남습니다(*интере́снее, эффекти́внее, ме́дленнее*). 구어에서는 -ей도 들립니다: *быстрей*.

**불규칙 비교급**은 자음이 바뀌고 **-е**로 끝납니다. 중요한 것은 외워야 합니다:

| ма́ленький, ма́ло | ме́ньше |
| дорого́й | доро́же |
| дешёвый | деше́вле |

### 2. 비교하는 법: чем 또는 생격

"~보다"를 말하는 방법이 두 가지 있습니다.

**가) чем + 같은 형태** (чем 앞에 쉼표):
*Наша модель работает быстрее, чем базовая.* — 저희 모델은 베이스라인보다 빠르게 작동합니다.
*Анна говорит по-английски лучше, чем Дима.* — 안나는 디마보다 영어를 잘한다.
*На русских текстах результаты хуже, чем на английских.* — 러시아어 텍스트에서 결과가 영어 텍스트보다 나쁘다.

**나) чем 없이 생격** (더 짧고, 명사와 대명사에서 아주 많이 씀). 한국어 "~보다"가 조사로 붙는 것과 비슷합니다:
*Наша модель быстрее базовой.* — 저희 모델은 베이스라인보다 빠르다.
*Москва больше Казани.* — 모스크바는 카잔보다 크다.
*Мой брат старше меня.* — 우리 형은 나보다 나이가 많다.

생격은 주격인 두 명사나 대명사를 비교할 때만 씁니다. 비교하는 것이 전치사구(*на русских текстах — на английских*), 부사, 절일 때는 반드시 **чем**을 씁니다.

**얼마나 더?**
- *гораздо, намного* — 훨씬: *гораздо медленнее, намного лучше*
- *немного, чуть* — 조금: *немного дороже*
- *ещё* — 더욱: *ещё быстрее*
- 차이는 **на + 대격**: *на три процента точнее* — 3% 더 정확한; *на два года старше* — 두 살 더 많은
- 배수는 **в … раза**: *в два раза быстрее* — 두 배 빠른; *в три раза больше* — 세 배 많은

**~할수록 더 ~하다: чем …, тем …**
*Чем больше данных, тем лучше результат.* — 데이터가 많을수록 결과가 좋다.
*Чем больше модель, тем дольше обучение.* — 모델이 클수록 학습이 오래 걸린다.

### 3. 합성 비교급: более эффективный

비교급을 만드는 두 번째 방법은 **более**("더") 또는 **менее**("덜") + 형용사 원형입니다. 이때 형용사는 정상적으로 **격변화하므로**, 이 형태는 **명사 앞**과 모든 격에서 씁니다:

*Нам нужен более эффективный метод.* — 우리에게는 더 효율적인 방법이 필요하다.
*Минхо работает с более современной моделью.* — 민호는 더 최신 모델로 작업한다.
*Это менее сложная задача.* — 이것은 덜 복잡한 과제이다.

명사 뒤(술어)에서는 두 형태 모두 가능합니다: *Этот метод эффективнее* = *Этот метод более эффективный*. 말할 때는 단순형이, 학술문에서는 합성형이 더 흔합니다.

두 형태를 섞지 마세요: ~~более лучше~~, ~~более быстрее~~. *лучше*나 *лучший*를 쓰면 됩니다.

**лучший, худший**는 격변화하는 형용사로 "더 좋은/가장 좋은", "더 나쁜/가장 나쁜"이라는 뜻입니다: *лучший результат* — 최고의 결과; *в худшем случае* — 최악의 경우.

### 4. 최상급: самый точный

**самый + 형용사** = "가장 ~한". 두 단어가 함께 격변화합니다:
*Это самая точная модель.* — 이것이 가장 정확한 모델이다.
*Минхо живёт в самом старом общежитии.* — 민호는 가장 오래된 기숙사에 산다.
*Мы говорили о самой новой модели.* — 우리는 가장 최신 모델에 대해 이야기했다.

**"가장 ~한 것 중 하나"** = **один (одна, одно) из самых + 복수 생격**:
*Это одна из самых важных проблем.* — 이것은 가장 중요한 문제 중 하나이다.
*BERT — одна из самых известных моделей.* — BERT는 가장 유명한 모델 중 하나이다.

**"~중에서"**: *самый эффективный метод из тех, которые мы проверили* — 우리가 검증한 것 중 가장 효율적인 방법.

**비교급 + всех / всего** = 부사의 최상급:
- **всех** (모든 사람보다): *Анна знает Python лучше всех.* — 안나가 파이썬을 제일 잘한다.
- **всего** (모든 것보다): *Больше всего я люблю читать.* — 나는 독서를 제일 좋아한다.

**как можно + 비교급** = "가능한 한 ~하게": *как можно скорее* — 되도록 빨리; *как можно больше данных* — 가능한 한 많은 데이터.

학술문에서는 **-ейший / -айший**로 끝나는 문어체 최상급도 보게 됩니다: *важнейший*(가장 중요한), *новейший*(최신의), *крупнейший*(최대의). 알아볼 수 있으면 충분하고, 말할 때는 *самый*를 쓰세요.

## 학습 팁

**논문이나 발표에서 결과 비교하기.** 표와 그래프를 설명할 때 도움이 되는 표현입니다:
- *Модель А работает лучше, чем модель Б.* — 모델 A가 모델 B보다 성능이 좋다.
- *по сравнению с базовой моделью* — 베이스라인 모델과 비교하여 (по сравнению с + 조격)
- *точность выше на 3 %* — 정확도가 3% 높다 (읽기: *на три процента*)
- *в два раза быстрее* — 두 배 빠르다
- *лучший результат* — 최고 결과
자신의 연구에 대해 이런 문장을 하나 써 보고 소리 내어 연습해 보세요.

## 복습

- 사물을 비교할 수 있습니다: *Наша модель быстрее базовой. Анна говорит по-английски лучше, чем Дима.*
- 차이의 정도를 말할 수 있습니다: *в два раза быстрее, на три процента точнее, гораздо дороже.*
- 명사 앞에 합성형을 쓸 수 있습니다: *Нам нужен более эффективный метод.*
- 최고를 말할 수 있습니다: *самая точная модель, одна из самых важных проблем, лучше всех.*
- "~할수록 더 좋다"를 말할 수 있습니다: *Чем больше данных, тем лучше результат.*
- 세미나에서 실험 결과를 설명할 수 있습니다.

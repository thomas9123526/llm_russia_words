## 문법

### 1. 소수: целая, десятая, сотая

**쓰기.** 러시아어는 소수점으로 **쉼표**를, 천 단위 구분으로 **띄어쓰기**를 씁니다: 0,5(0.5가 아님), 50 000, 1 300 000,25. 코드나 영어 논문에서는 여전히 점을 보게 되지만, 러시아어 텍스트에서는 항상 쉼표를 쓰세요.

**읽기.** 소수는 분수처럼 읽습니다. 정수 부분 + **це́лая**(часть가 여성이므로 여성형 "전체의"), 그다음 소수 부분 + **деся́тая / со́тая / ты́сячная**(10분의, 100분의, 1000분의). 두 단어 모두 수사 뒤의 명사와 같은 규칙을 따릅니다.

| 수 | "정수" | "10분의" 등 |
|---|---|---|
| 1, 21, 31… | одна́ це́лая | одна́ деся́тая |
| 2, 3, 4 | две / три / четы́ре це́лых | две деся́тых |
| 0, 5–20… | ноль / пять це́лых | пять деся́тых |

여성형 одна́, две를 쓰는 것을 잊지 마세요.

| 표기 | 읽기 |
|---|---|
| 0,5 | ноль це́лых пять деся́тых |
| 1,2 | одна́ це́лая две деся́тых |
| 2,35 | две це́лых три́дцать пять со́тых |
| 3,14 | три це́лых четы́рнадцать со́тых |
| 0,01 | ноль це́лых одна́ со́тая |
| 0,001 | ноль це́лых одна́ ты́сячная |
| 12,7 | двена́дцать це́лых семь деся́тых |

**소수 뒤의 명사는 마지막 숫자와 상관없이 항상 단수 생격입니다**: 0,5 секу́нды, 2,5 проце́нта, 1,3 миллиа́рда, 87,5 проце́нта. "87.5**의** 퍼센트"처럼 생각하세요.

**일상 회화**에서는 줄여 말합니다: 0,5 → «ноль пять», 2,5 → «два и пять». 코드를 불러 주는 프로그래머는 «ноль то́чка ноль ноль оди́н»(0.001)라고도 합니다. 세미나에서는 완전한 형태가 더 전문적으로 들립니다. 1,5에는 특별한 단어가 있습니다: полтора́(+ 단수 생격): полтора́ часа́, полтора́ миллио́на.

**10의 거듭제곱**은 머신러닝에서 자주 나옵니다: 10⁻⁴ — де́сять в ми́нус четвёртой сте́пени; 10⁹ — де́сять в девя́той сте́пени. сте́пень가 여성이므로 서수도 여성 전치격(в четвёртой)입니다.

### 2. 퍼센트와 비교

**проце́нт**는 일반 규칙(제3과)을 따릅니다: 1, 21, 31 → проце́нт; 2–4, 22–24 → проце́нта; 5–20, 25–30 → проце́нтов; 소수 뒤 → проце́нта.

| | |
|---|---|
| 1 % | оди́н проце́нт |
| 3 % | три проце́нта |
| 12 % | двена́дцать проце́нтов |
| 21 % | два́дцать оди́н проце́нт |
| 44 % | со́рок четы́ре проце́нта |
| 0,5 % | ноль це́лых пять деся́тых проце́нта |

**결과를 말하는 핵심 표현:**
- **на** + 대격 = "~만큼": Моде́ль на 3 % (три проце́нта) лу́чше. То́чность вы́росла на 5 % (пять проце́нтов).
- **с** + 생격 … **до** + 생격 = "~에서 ~까지": То́чность вы́росла с восьми́десяти до девяно́ста проце́нтов.
- **в … раз(а)** = "~배": в два ра́за быстре́е(두 배 빠르다), в де́сять раз бо́льше(열 배 많다). 2–4 뒤에는 ра́за, 5 이상 뒤에는 раз.
- **бо́лее / ме́нее** + 생격 = "~이상 / ~이하"(문어): бо́лее ста языко́в.

두 퍼센트 사이의 차이는 **процентный пункт**(퍼센트포인트)입니다: То́чность вы́росла на 2 проце́нтных пу́нкта (п. п.). 꼼꼼한 저자들이 쓰는 표현으로, 좋은 논문에서 보게 됩니다.

**생격과 전치격의 수사.** с, до, бо́лее, о, на(장소) 뒤에서는 수사가 격변화합니다. 가장 자주 필요한 형태는 다음과 같습니다.

| 주격 | 생격 | 전치격 |
|---|---|---|
| два / три / четы́ре | двух / трёх / четырёх | двух / трёх / четырёх |
| пять, во́семь, де́сять | пяти́, восьми́, десяти́ | пяти́, восьми́, десяти́ |
| два́дцать, три́дцать | двадцати́, тридцати́ | двадцати́, тридцати́ |
| со́рок | сорока́ | сорока́ |
| во́семьдесят | восьми́десяти | восьми́десяти |
| девяно́сто | девяно́ста | девяно́ста |
| сто | ста | ста |

- на восьми́ видеока́ртах — *GPU 8개에서*
- в двух экспериме́нтах — *두 번의 실험에서*
- бо́лее ста языко́в — *100개 이상의 언어*

### 3. 큰 수

| 표기 | 단어 | 약어 |
|---|---|---|
| 1 000 | ты́сяча | тыс. |
| 1 000 000 | миллио́н | млн |
| 1 000 000 000 | миллиа́рд | млрд |
| 1 000 000 000 000 | триллио́н | трлн |

주의: 영어 *billion* = 러시아어 **миллиа́рд**입니다. "биллио́н"이라는 단어는 쓰지 않습니다. "7B 모델"은 моде́ль на 7 млрд пара́метров(읽기: на семь миллиа́рдов пара́метров) 또는 간단히 в моде́ли семь миллиа́рдов пара́метров입니다. миллио́н, миллиа́рд, триллио́н은 남성 명사, ты́сяча는 여성 명사이며, 모두 수사 규칙을 따릅니다: два миллиа́рда, пять миллиа́рдов; две ты́сячи, пять ты́сяч. 그 뒤의 명사는 복수 생격입니다: семь миллиа́рдов **пара́метров**, два триллио́на **то́кенов**.

### 4. 수식 소리 내어 읽기

| 수식 | 읽기 |
|---|---|
| a + b | а плюс бэ |
| a − b | а ми́нус бэ |
| a · b | а умно́жить на бэ |
| a / b | а, делённое на бэ (*또는:* а раздели́ть на бэ) |
| a = b | а равно́ бэ |
| a ≈ b | а приблизи́тельно равно́ бэ |
| a > b, a < b | а бо́льше бэ, а ме́ньше бэ |
| x², x³ | икс в квадра́те, икс в ку́бе |
| xⁿ | икс в сте́пени эн |
| √x | ко́рень из икс |
| f(x) | эф от икс |
| xᵢ | икс и́тое |
| Σ | су́мма |
| log x | логари́фм икс |

**문자 이름.** 라틴 문자: a — а, b — бэ, c — цэ, d — дэ, e — е, f — эф, i — и, k — ка, L — эль, m — эм, n — эн, p — пэ, q — ку, s — эс, t — тэ, w — дубль-вэ, x — икс, y — и́грек, z — зет. 그리스 문자: α — а́льфа, β — бе́та, ε — э́псилон, η — э́та, θ — тэ́та, λ — ля́мбда, μ — мю, σ — си́гма. 문자 이름은 격변화하지 않습니다: ко́рень из икс, бо́льше бэ.

**равно́, бо́льше, ме́ньше 뒤의 숫자.** 정확한 말투에서는 равно́ 뒤의 숫자는 여격, бо́льше / ме́ньше 뒤는 생격을 씁니다: два плюс два равно́ четырём; икс бо́льше нуля́. 문자는 격변화하지 않으므로 문자일 때는 문제가 없습니다.

## 학습 팁

한국어 화자가 빠지기 쉬운 함정이 두 가지 있습니다. 첫째, 한국어는 0.5처럼 점을 쓰지만 러시아어는 쉼표를 씁니다. 그래서 러시아어에서 1,500은 "천오백"이 아니라 1.5입니다! 천오백은 1 500으로 씁니다. 둘째, 한국어는 큰 수를 네 자리씩(만, 억) 묶지만 러시아어는 세 자리씩 묶습니다: 70억 = 7 миллиа́рдов, 1조 = 1 триллио́н, 5만 = 50 ты́сяч. LLM 논문을 읽을 때는 단어가 아니라 자릿수를 거쳐서 바꾸세요.

5. Но́вая моде́ль в два ра́за быстре́е.

**연습 7.**
1. Одна́ це́лая три деся́тых миллиа́рда.
2. Три́дцать шесть часо́в.
3. На восьми́.
4. Де́сять проце́нтов да́нных.
5. На две це́лых три деся́тых проце́нта.
6. Ноль це́лых пять деся́тых секу́нды.

## 복습

- 소수를 쉼표로 쓰고 це́лая / деся́тая / со́тая / ты́сячная로 읽을 수 있습니다.
- 소수 뒤의 명사를 단수 생격으로 씁니다: 2,5 проце́нта, 0,5 секу́нды.
- 결과를 보고할 수 있습니다: на 3 % лу́чше, с восьми́десяти до девяно́ста проце́нтов, в два ра́за быстре́е.
- тыс., млн, млрд, трлн을 알고, *billion* = миллиа́рд라는 것을 압니다.
- 간단한 수식을 소리 내어 읽을 수 있습니다: а равно́ эн, делённое на эм; икс в квадра́те; ко́рень из икс.
